# 食物系统

这页说明食物分成哪几类、品质高低意味着什么，再带你进对应的分类页查配方。

## 食物品质分级

食物分四个品质。品质越高，效果越强，材料也越稀有。

| 品质 | 特点 | 代表食物 |
| --- | --- | --- |
| <span style="color:#9ca3af;font-weight:700">普通</span> | 基础饱食，无效果或弱效果 | 煎蛋、吐司、奶酪 |
| <span style="color:#22c55e;font-weight:700">精良</span> | 有实用的日常效果 | 草莓甜筒、热狗、棉花糖 |
| <span style="color:#3b82f6;font-weight:700">稀有</span> | 强力的战斗效果 | 大火腿、牛肉炖、汉堡 |
| <span style="color:#f59e0b;font-weight:700">传说</span> | 终极增益，材料极稀有 | 七彩蛋羹、煎龙蛋 |

## 怎么查效果

- 想知道某道菜吃什么效果：进上面的分类页，每道菜都标了饥饿值、饱和度和效果。
- 想按效果反查食物：进[食物速查表](./reference)，表里能按生命恢复、抗性、抗火、速度分组找。
- 想知道和什么一起吃更划算：速查表底部有搭配组合和使用场景。

::: tip 饮品返还容器
啤酒喝完返还空瓶，珍珠奶茶喝完返还空桶。
:::
