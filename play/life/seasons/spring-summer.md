# 春季与夏季

这页说明上半年两个季节会给世界带来什么变化，以及每个季节该做什么准备。

## 春季

春季是最温和的季节。寒冬过后，全世界重新长满花草。

| 项目 | 内容 |

| 开始时间 | 每年 3 月 4 日 |
| 视觉 | 森林树叶晕出粉嫩色调，水面与天空带柔和的浅蓝滤镜 |
| 粒子 | 樱花花瓣从树叶间缓缓飘落 |
| 环境 | 冬季的积雪与冰块逐渐消融，各色花朵随处可见 |
| 生物 | 羊、牛、猪、兔子、鸡成群出现，每群带 3~5 只幼崽 |
| 夜间 | 森林里出现成群萤火虫，蜜蜂的出现概率大幅提升 |
| 温度 | 四季中最温和，体感偏凉到舒适 |
| 昼夜 | 白天与夜晚的时长基本持平 |

### 春季的生物群系差异

- 丛林生物群系的丛林树叶保留原本的翠绿，不会被粉色覆盖。
- 部分生物群系不会遍地开花，只会轻微调整色彩。
- 温度差异依然明显：沙漠照样炎热，冰冻苔原照样寒冷。

### 积雪慢慢融化

春季早期，积雪和冰块消融得很慢，而且是一块一块地化。

进入春季后期，消融速度明显加快，整个世界很快褪去冬装。

### 樱花树叶

春季中期，1.20 与更高版本的玩家会看到橡树树叶变成樱花树叶的样子。

- 这只是一层画面效果，树本身还是橡树。
- 破坏这些树叶，掉落的仍然是普通橡树树叶。

## 夏季

夏季白昼漫长，气温升到全年最高，作物长得最快。

| 项目 | 内容 |
| --- | --- |
| 开始时间 | 每年 6 月 4 日 |
| 视觉 | 树木与草皮变成浓郁的鲜绿，水面与天空带明亮的浅蓝滤镜 |
| 粒子 | 白天落叶纷飞，夜里能看到流星与萤火虫 |
| 环境 | 春季的花朵全部消失，各地随机长出浆果丛，降雨极少 |
| 作物 | 上方没有方块遮挡的作物，生长速度翻倍 |
| 生物 | 原本只在丛林出现的动物遍布各地；夜间僵尸被尸壳替代 |
| 温度 | 全年最热，体感炎热到酷热 |
| 昼夜 | 昼长夜短，白天约 13 分钟，夜晚约 7 分钟 |

### 夏季的生物群系差异

- 寒冷生物群系褪去雪白，草皮换上平原的绿色。
- 炎热生物群系仍是绿色，但透出干燥的质感。

### 作物双倍生长

农田上方不留任何方块，作物就能以 2 倍速度成熟。

- 小麦、胡萝卜、土豆、南瓜、西瓜都能享受这个加速。
- 玻璃、树叶、木板等任何方块都会挡住加速效果。
- 露天农田自然满足条件，室内农田会失去加速。

::: tip 夏季看流星
流星在夏季夜晚的天空出现，午夜前后最清楚。渲染距离不小于 10 才看得到。
:::
