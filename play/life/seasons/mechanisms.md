## 体温怎么算

界面上显示的是当前环境的空气温度。系统每 2 秒重新计算一次体温。

季节决定基础温度：夏季最热，冬季最冷，春季与秋季居中。

## 影响体温的因素

### 生物群系

生物群系的影响最大。

| 生物群系 | 温度修正 |
| --- | --- |
| 恶地、沙漠 | +15℃ |
| 丛林 | +12℃ |
| 热带草原 | +10℃ |
| 其他常见生物群系 | 0℃ |
| 山地、针叶林 | -4℃ |
| 积雪与冰冻生物群系 | -12℃ |

### 天气与时间

| 条件 | 温度修正 |
| --- | --- |
| 晴朗 | 0℃ |
| 雨或雪 | -4℃ |
| 雷暴 | -5℃ |
| 白天 | +0~+3℃ |
| 夜间 | -5~0℃ |

### 行动与高度

| 条件 | 温度修正 |
| --- | --- |
| 泡在水中或细雪里（夏季、冬季） | -10℃ |
| 泡在水中或细雪里（春季、秋季） | -4℃ |
| 疾跑 | +4℃ |
| 非冬季，高度高于 64 格 | 每格 -0.08℃ |
| 冬季，高度高于 64 格 | 高度不影响温度 |

离开水域后体温会逐渐恢复。

### 周围方块

16 格范围内的发热与降温方块都会影响体温。

| 方块 | 温度修正 |
| --- | --- |
| 岩浆 | +22℃ |
| 火 | +16℃ |
| 营火 | +15℃ |
| 火把、灯笼 | +7℃ |
| 灵魂灯笼 | -7℃ |
| 冰、浮冰 | -6℃ |
| 灵魂营火 | -10℃ |
| 蓝冰 | -15℃ |
| 灵魂火 | -16℃ |

### 护甲

| 护甲 | 单件 | 全套 |
| --- | --- | --- |
| 皮革 | +5℃ | +20℃ |
| 铁、金、钻石 | +1.25℃ | +5℃ |
| 下界合金 | +0.75℃ | +3℃ |

皮革的保暖效果只在体温低于 25℃ 时生效。

### 食物

| 情况 | 做法 | 效果 |
| --- | --- | --- |
| 太冷 | 饥饿值满时吃饱 | +5℃ |
| 太热 | 喝水或药水 | -10℃，持续 5 分钟 |

## 温度效果

体温进入这些区间时会触发对应效果。

| 阈值 | 效果 |
| --- | --- |
| 低于 -20℃ | 冻伤，每 2 秒受到半颗心伤害 |
| 低于 -15℃ | 缓慢 |
| 低于 -10℃ | 饥饿 |
| 低于 0℃ | 呼气寒雾，仅视觉表现 |
| 15~30℃ | 舒适区间 |
| 高于 40℃ | 流汗，仅视觉表现 |
| 高于 50℃ | 无法自然回血 |
| 高于 60℃ | 缓慢 |
| 高于 65℃ | 灼烧 |

## 危险提醒

体温接近危险区间时，服务器会提醒你两次。

1. 行动栏提醒。 —— 提示文字变色。
2. 聊天框警告。 —— 发送一条警告消息。

## 应对技巧

- 去沙漠前带够水，不要穿全套厚护甲。
- 冬季外出随身带火把或营火，远离水域。
- 冬天上山反而更暖和，因为冬季高度不影响温度。
- 夜里赶路用疾跑升温，这是寒冷环境里最快的回暖方式。
