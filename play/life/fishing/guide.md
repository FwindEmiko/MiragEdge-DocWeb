# 鱼竿与鱼饵

这页说明五根鱼竿怎么升级、六种鱼饵怎么装，以及岩浆和虚空里怎么下竿。

## 鱼竿一览

| 鱼竿 | 稀有度 | 能钓到的鱼 | 特殊能力 |
| --- | --- | --- | --- |
| 初学者的鱼竿 | 普通 | 垃圾、普通 | 无 |
| 竹制钓鱼竿 | 精良 | 普通、稀有 | 无 |
| 星辉钓鱼竿 | 史诗 | 普通、稀有、史诗 | 可在虚空下竿 |
| 裂骨钓鱼竿 | 传说 | 稀有、史诗、传说 | 可在岩浆里下竿 |
| 大师钓鱼竿 | 至宝 | 全部稀有度 | 普通水域、岩浆、虚空都能下竿 |

## 鱼竿怎么获得

1. 初学者的鱼竿：找管理员领取，或用原版钓鱼竿加铁锭合成。
2. 竹制钓鱼竿：用初学者的鱼竿加竹子合成。
3. 星辉钓鱼竿：用紫水晶块和末影珍珠合成。
4. 裂骨钓鱼竿：用骨块和烈焰棒合成。
5. 大师钓鱼竿：用星辉钓鱼竿和裂骨钓鱼竿合成。

## 各根鱼竿的特点

### 初学者的鱼竿

新手入门竿，只能钓垃圾和普通品质的鱼。

### 竹制钓鱼竿

第一根升级竿，能钓到稀有品质的鱼，卖价远高于普通鱼。

### 星辉钓鱼竿

第一根带特殊能力的鱼竿，能在虚空里钓到异界鱼类。

### 裂骨钓鱼竿

能在岩浆里下竿，钓到火系鱼类。

### 大师钓鱼竿

三种环境通用，还能钓到全部稀有度的鱼。

## 鱼饵怎么装

1. 对着空鱼竿按 Shift 加右键。 —— 打开鱼饵菜单。
2. 把鱼饵拖到鱼竿上。 —— 鱼饵附着成功。
3. 下次钓鱼时鱼饵自动生效，对应鱼类的出现率提高。
4. 鱼饵有使用次数，用完就消失。

鱼饵也能在 `/emf` 主菜单的鱼饵商店里直接买到。

## 鱼饵种类

| 鱼饵 | 效果 | 附在竿上的次数 |
| --- | --- | --- |
| 虾仁 | 提升普通稀有鱼的概率，例如鲤鱼、金鱼 | 最多 100 次 |
| 线虫 | 提升普通与传说鱼的概率，万能型 | 最多 16 次 |
| 鲜活水蚤 | 提升史诗与传说鱼的概率 | 最多 64 次 |
| 史诗灵药 | 专精提升史诗鱼的概率 | 最多 64 次 |
| 传说诱饵 | 只提升传说鱼的概率 | 最多 20 次 |
| 无尽鱼饵 | 提升传说鱼的概率，不限次数 | 用不完 |

## 鱼饵的来源

- 虾仁、线虫、鲜活水蚤：鱼饵商店直接购买。
- 史诗灵药、传说诱饵：价格较高，商店有售。
- 无尽鱼饵：商店不卖，靠特定活动或极低概率钓到。

## 鱼饵的使用规则

- 每根鱼竿最多附 7 种鱼饵。
- 比赛期间鱼饵不生效。
- 附了鱼饵的鱼竿放在铁砧上会受到保护，不会被误吞。

## 特殊环境垂钓

三种环境需要的鱼竿不同，能钓到的鱼也不同。

| 环境 | 需要的鱼竿 | 能钓到什么 |
| --- | --- | --- |
| 普通水域 | 任意鱼竿 | 淡水与海鱼类 |
| 岩浆 | 裂骨钓鱼竿或大师钓鱼竿 | 火系鱼类 |
| 虚空 | 星辉钓鱼竿或大师钓鱼竿 | 末地异界鱼类 |

### 怎么开始

1. 先拿到对应的鱼竿。
2. 去对应环境。 —— 下界找岩浆池，末地找虚空边缘。
3. 拿出鱼竿抛竿。 —— 浮漂浮在岩浆表面或悬在虚空中。

岩浆与虚空各有哪些鱼，见[鱼类图鉴](./fish)。

::: tip 抛竿没有反应怎么办
浮漂直接沉下且没有任何动静，说明手里的鱼竿不支持这种环境。换裂骨钓鱼竿或星辉钓鱼竿再试。
:::
