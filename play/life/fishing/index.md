# 钓鱼系统

这页说明怎么开始钓鱼，以及鱼竿、鱼饵、图鉴和比赛分别在哪一页。

## 四步开始

1. 领一根鱼竿。 —— 找管理员领取初学者的鱼竿，或用原版钓鱼竿加铁锭合成。
2. 找一处水域，把浮漂甩进水里。
3. 等浮漂下沉，右键收竿。
4. 输入 `/emf` 打开菜单。 —— 菜单里能出售钓到的鱼，换成灵叶。

::: tip 新手竿的限制
初学者的鱼竿只能钓到垃圾和普通品质的鱼。想钓更好的鱼，得先升级鱼竿。
:::

## 核心机制

| 概念 | 说明 |
| --- | --- |
| 稀有度 | 鱼分五个等级：垃圾、普通、稀有、史诗、传说。等级越高越罕见，卖价也越高 |
| 鱼竿 | 决定你能钓到哪些稀有度的鱼。竿越好，能钓到的鱼越高级 |
| 鱼饵 | 附在鱼竿上，提升特定鱼类的出现概率 |
| 比赛 | 每天多场钓鱼比赛实时开战，按排名发奖励 |
| 特殊环境 | 中后期开放，岩浆和虚空各有专属鱼类 |
