# 经济系统

## 货币体系

**灵叶**（Spirit Leaf）— 基础流通货币
日常一切的交易、消耗、服务都离不开灵叶。挖矿、打怪、做任务、在线挂机都能获得，消耗也贯穿始终。

**星痕石**（Starscar Gem）— 高级稀缺货币
高品质附魔、重铸、特殊服务都需要星痕石。主要靠任务和在线奖励获得，也可以和其他玩家交易。

**块币**（Craft Coin Bay）— 建筑专用货币
方块银行（等价交换）的独立货币。卖给系统建筑方块获得块币，用块币在方块银行购买建筑材料。块币不足时自动从灵叶代扣。

## 灵叶怎么赚

| 方式 | 说明 |
|:----|:-----|
| 在线奖励 | 每天在线满8小时可领满 **10,000 灵叶** + 30 星痕石 |
| 每日任务 | 5个任务，做满额外奖励，日入约 5,000~12,000 灵叶 |
| 周任务 | 8个任务，做满额外奖励，周入约 40,000~65,000 灵叶 |
| 挖矿/打怪 | 掉落灵叶，勤劳致富 |
| 赏金猎人 | 击杀烬域/繁星怪物与 Boss，日入约 3,275~5,000 灵叶，每日限量跨日重置 |
| 玩家交易 | 卖给其他玩家附魔书、材料、装备等 |
| 稀有资源商店 | 出售钻石、下界合金等不可再生资源给官方商店 |

## 灵叶花在哪

| 项目 | 费用参考 | 说明 |
|:----|:-------:|:-----|
| TPA 传送 | 100/次 | 传送到其他玩家 |

| 祛魔 | 300~1,200/次 | 看品质和等级 |

| 方块银行 | 市场价 | 出售建筑材料换取等价交换货币，灵叶作为后备 |

## 星痕石怎么赚

| 方式 | 说明 |
|:----|:-----|
| 在线奖励 | 每天满勤 **30 星痕石** |
| 每日任务 | 每日约 30~40 星痕石 |
| 周任务 | 每周约 200~250 星痕石 |
| 任务委托上交 | 上交钻石、龙蛋等获得额外星痕石 |

## 稀有资源商店

官方商店买卖不可再生资源，**总量守恒**——玩家卖多少进供应池，才能买多少。

| 资源 | 卖价（玩家得） | 买价（玩家付） | 说明 |
|:----|:---:|:---:|:-----|
| 钻石 | 1,200 | 1,600 | 限供应池存量 |
| 远古残骸 | 3,000 | 4,000 | 限供应池存量 |
| 下界合金锭 | 8,000 | 10,000 | 限供应池存量 |

**运营机制**：玩家把挖到的钻石卖给商店（供应池 +1），其他玩家才能从商店买（供应池 -1）。总量不变，差价自然回收灵叶。

## 经济小贴士

- 缺灵叶？卖钻石、下界合金给官方商店，做任务，领在线奖励
- 缺星痕石？做任务上交委托，用物资换星痕石
- 死亡前30次无惩罚，记得控制死亡次数
- 想省传送费？多设几个家，少用 TPA
- 建筑需求量大？方块银行买建材比自己去挖划算
