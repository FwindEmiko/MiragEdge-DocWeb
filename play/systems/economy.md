# 经济系统

这页用来查三件事：钱从哪来、花到哪去、稀有资源卖多少。

## 三种货币

**灵叶**是日常流通货币。挖矿、打怪、做任务、在线奖励都能获得。

**星痕石**是高级货币。高品质附魔、重铸和特殊服务需要它。

**块币**是建筑货币，只在[方块银行](/features/block-bank)流通。块币不足时自动从灵叶扣。

## 灵叶怎么赚

| 方式 | 说明 |
| --- | --- |
| 在线奖励 | 每天在线满 8 小时，领 10,000 灵叶 + 30 星痕石 |
| 每日任务 | 5 个任务，做满约 12,000 灵叶 + 43 星痕石 |
| 周任务 | 8 个任务，做满约 40,000~65,000 灵叶 + 200~250 星痕石 |
| 挖矿打怪 | 掉落灵叶 |
| 每日赏金 | 击杀烬域与繁星的怪物、Boss，每天约 3,275~5,000 灵叶，跨日重置 |
| 玩家交易 | 出售附魔书、材料、装备 |
| 稀有资源商店 | 把钻石、远古残骸、下界合金锭卖给系统 |
| 任务委托 | 上交钻石、龙蛋换取灵叶与星痕石 |

## 灵叶花在哪

| 项目 | 费用参考 |
| --- | --- |
| 传送到其他玩家 | 100 灵叶/次 |
| 创建家 | 350 灵叶起 |
| 创建与扩建领地 | 2.5 灵叶/格 |
| 祛魔 | 300~1,050 灵叶/次 |
| 重铸附魔书 | 50~8,000 灵叶 |
| 增幅附魔 | 30~200 灵叶 + 材料 |

## 稀有资源商店

系统只在供应池有货时收购和出售。

| 资源 | 卖价（玩家得到） | 买价（玩家支付） |
| --- | --- | --- |
| 钻石 | 1,200 | 1,600 |
| 远古残骸 | 3,000 | 4,000 |
| 下界合金锭 | 5,000 | 7,000 |

玩家卖出多少，供应池就存多少；别人买走多少，供应池就少多少。

## 星痕石怎么赚

| 方式 | 说明 |
| --- | --- |
| 在线奖励 | 每天满勤 30 星痕石 |
| 每日任务 | 做满约 43 星痕石 |
| 周任务 | 做满约 200~250 星痕石 |
| 任务委托 | 上交钻石、龙蛋换额外星痕石 |

## 常见问题

- 灵叶不够：卖钻石、远古残骸、下界合金锭给系统，做任务，领在线奖励。
- 星痕石不够：做任务上交委托。
- 传送费太贵：多设几个家，少用传送。
- 建筑需求量大：在方块银行买建材比自己挖快。
