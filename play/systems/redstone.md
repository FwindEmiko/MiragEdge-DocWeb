# 生电与特性

搭机器前先查这一页：哪些特性能用、哪些被禁用、反作弊管到哪一步。

## 启用的特性

| 特性 | 说明 |
| --- | --- |
| TNT 复制 | 可用，只在服务器端生效 |
| 地毯复制 | 可用，用活塞推动实现 |
| 铁轨复制 | 可用，用活塞推动实现 |
| 无头活塞 | 可用 |
| 破基岩 | 可用，需要特定操作 |
| 末地门框架 | 可永久破坏 |
| 折跃门 | 可永久破坏 |

## 禁用的特性

| 特性 | 原因 |
| --- | --- |
| 重力方块复制 | 服务器底层已修复，无法复现 |
| 虚空交易 | 服务器底层已修复，无法复现 |
| 光照抑制 | 服务器底层已修复，无法复现 |
| 末影珍珠滞空 | 服务器底层已修复，无法复现 |
| RNG 附魔 | 属于可预测随机性，已禁用 |

## 破基岩与永久破坏

破基岩、末地门框架和折跃门都能被永久破坏。

这三种操作都需要特定手法，与原版的破坏顺序有关。

## 反作弊与投影

- 服务器不检测方块的放置与破坏，投影打印机可以正常使用。
- 矿透混淆较宽松。
- 服务器启用了安全种子，无法推算出原始世界种子。

## 地狱门实体限制

服务器每 3 分钟检查一次整体流畅度，单位是 TPS。

1. TPS 低于 18 时，实体无法穿过地狱门。
2. TPS 回到 18 或更高后，实体恢复通行。

大量实体集中穿门会拖慢整个服务器，所以加了这道闸。

## 末地群系与末影人

繁星改造过的末地群系里，只有部分群系会生成末影人。

建小黑塔前先确认目标群系，详见[末地群系与末影人生成指南](/play/adventure/worlds/stellarity/biomes#末影人生成指南)。

## 其他改动

- 女巫小屋的结构范围比原版更大，改造全怪塔前先确认范围。
- 本页清单核对于 2026-08-28，之后若有调整以游戏内实际表现为准。
