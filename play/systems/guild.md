# 玩家工会

工会用于把常一起玩的玩家聚成一个团体：共用一个主城、共享资金、参与工会战。

## 怎么创建工会

创建前先和游戏内管理员确认。

工会名称与铭牌有以下限制：

| 项目 | 限制 |
| --- | --- |
| 工会名称 | 不超过 7 个字符，支持原版颜色格式化码与特殊符号 |
| 工会简介 | 可选，不超过 30 字 |
| 工会铭牌 | 可选，支持自定义图片或纯文字 |

铭牌图片宽度不超过 32 像素、长度不超过 256 像素。自行设计完成后把图片发给管理员协助导入。

## 创建步骤

所有工会操作都在图形界面里完成。

1. 进服后输入 `/mc` 打开功能菜单。
2. 点击菜单右上角的【工会系统】按钮。
3. 未加入工会时，界面左下角有【创建工会】按钮，点击后输入工会名。
4. 消耗灵叶或星痕石完成创建。

## 工会管理原则

- 鼓励工会成员参与内容讨论、提出优化建议。
- 服务器为正常运营的工会提供支持。
- 禁止工会形成垄断或破坏服务器平衡，出现时服务器会采取管控措施。

## 基础管理

| 功能 | 说明 |
| --- | --- |
| 工会主城 | 会长可把游戏内任意位置设为工会主城，作为成员聚集点 |
| 工会传送 | 成员可一键传送到工会主城 |
| 成员管理 | 管理员可添加或移除成员、调整权限与职位 |

## 福利与成长

| 功能 | 说明 |
| --- | --- |
| 工会签到 | 成员每日签到可领奖励，奖励等级与工会等级和活跃度挂钩 |
| 工会银行 | 成员贡献的物资与货币统一转为工会资金，用于工会升级和功能解锁 |
| 工会称号 | 随工会等级提升解锁，支持自定义名称，解锁后附带专属增益 |
| 工会神石 | 为工会增加活跃度，降低工会等级提升门槛 |

## 工会世界

会长可消耗星痕石、灵叶或工会资金，创建带边境限制的工会专属世界，供成员集体建造或采集资源。

## 工会战

工会活动目前开放两类工会战：

| 类型 | 说明 |
| --- | --- |
| 赛季工会战 | 周期性赛季制对抗，含赛季专属奖励 |
| 匹配工会战 | 实时匹配其他工会对抗 |

工会战支持开启「公平匹配」模式，开启后自动平衡双方基础属性。

## 工会商店

工会成员可在专属商店内上架物品出售，供其他成员选购，实现工会内部物资流通。
