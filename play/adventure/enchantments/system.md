# 附魔管理

> 不想用的附魔书怎么处理？想要更好的附魔怎么搞？  
> 简单说就是：**没用的书换材料，材料换新书，新书能升级。**

## 一条龙流程

```
不要的装备 → [祛魔] → 附魔书
                            ↓
不要的附魔书 → [回收] → 魔法粉尘 / 魔法结晶
                            ↓
[融合] 粉尘合成结晶      [重铸] 材料换随机附魔
[增幅] 给附魔书升级
```

---

## 祛魔（把装备上的附魔拆下来）

主城找祛魔师，放上装备就能拆。拆下来的附魔会变成书，可以装到别的装备上。

**需要**：经验 + 灵叶 + 祛魔符文（主城有卖）
**注意**：拆附魔有成功率，越好的附魔越难拆。失败了东西不退，但同一件装备连续失败 8 次后下一次必成功。

> 拆下来的书如果自己用不上 → 拿去回收当材料

## 回收（没用的书变材料）

把不要的附魔书扔进回收台，变成**魔法粉尘**或**魔法结晶**。这是整个系统的起点。

| 书的品质 | 能产出 |
|:--------|:------|
| 普通 ~ 诅咒 | 魔法粉尘 |
| 史诗 ~ 至宝 | 魔法结晶 |

品质越高产出的数量越多。偶尔触发**暴击**的话产出翻倍。

## 重铸（材料换新书）

用粉尘或结晶，加上灵叶和星痕石，可以锻造出一本**还没打开看的附魔书**。

| 想要的品质 | 需要什么材料 |
|:---------|:----------|
| 普通 | 粉尘 ×3 + 灵叶 |
| 优良 | 粉尘 ×8 + 灵叶 |
| 稀有 | 粉尘 ×20 + 灵叶 |
| 史诗 | 结晶 ×3 + 灵叶 + 星痕石 |
| 传说 | 结晶 ×8 + 灵叶 + 星痕石 |
| 至宝 | 结晶 ×25 + 灵叶 + 星痕石 |

## 学习（把新书拆开看）

拿到还没打开的书后，**拿在手上右键**就能打开。消耗一些经验，随机得到一本同品质的附魔书。

- **品质越高，消耗经验越多**
- **开出什么全看脸**——同一品质里的附魔随机出
- **等级也随机**——1 级到满级都有可能

> 说白了就是赌人品。想要特定附魔的话多攒几本一起开。

## 融合（粉尘合成结晶）

低品质书回收得到的是粉尘，但高品质重铸需要结晶。所以你需要**把粉尘合成结晶**。

| 操作 | 消耗 | 产出 |
|:----|:----|:----|
| 一组 | 粉尘 ×16 + 灵叶 100 | 结晶 ×1 |
| 一次性合 10 组以上 | 同上 × 组数 | 有概率多送一个 |

## 增幅（给附魔书升级）

只有**只有一个附魔**的书才能升级，而且不能是满级。诅咒附魔不能升级。

**成功率**：等级越高越容易失败。

| 从→到 | 成功概率 | 失败了会怎样 |
|:----:|:-------:|:----------|
| 1级→2级 | 85% | 不变，没损失 |
| 2级→3级 | 70% | 不变，没损失 |
| 3级→4级 | 55% | 不变，没损失 |
| 4级→5级 | 40% | 不变，没损失 |
| 5级→6级 | 35% | 不变，没损失 |
| 6级→7级 | 25% | 不变，没损失 |
| 7级→8级 | 18% | 不变，没损失 |

> 失败只消耗材料，书的等级不会掉。4级以后成功率就开始看脸了。

## 铁砧没有限制了

原版铁砧操作太多次后会显示「过于昂贵」不让你继续弄。本服**取消了这条限制**——你可以放心地反复修理、合并附魔书，不用担心铁砧罢工。

> 实际消耗的经验还是以铁砧界面显示为准。

## 怎么打开

**主城**找「附魔重铸」NPC（附魔师附近），点击打开菜单。菜单里有五个按钮对应五个功能。

> 也可以直接输入 `/crucible` 打开。
