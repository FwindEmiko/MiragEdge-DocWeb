# 附魔总览

服务器附魔分两块：原版附魔和自定义附魔。原版附魔用附魔台就能弄到，自定义附魔必须去野外探索。

<SmartImage src="/images/play/adventure/enchantments/acquire-paths.svg" caption="图 1：附魔的三条来路——附魔台、祛魔、村民交易，最终汇入同一套附魔体系" width="720" />

## 新手阶段：先玩原版

附魔台和村民交易只出原版附魔。自定义附魔要去野外探索才能拿到。

先弄这些：锋利、保护、效率、耐久。

来路有三条：附魔台、村民交易、钓鱼。这三条都只出原版附魔。

::: tip 提示
前期用原版附魔就够用，不需要刻意去刷自定义附魔。
:::

## 中期阶段：附魔循环

攒下一堆不想要的附魔书之后，就可以开始跑附魔循环。

1. 摆上回收台，把不要的附魔书回收成魔法粉尘或魔法结晶。
2. 用材料重铸，换到一本还没打开看的附魔书。
3. 拿在手上右键打开，得到一本同品质的附魔书。
4. 等级不满意就增幅，给附魔书升一级。

完整规则见[附魔管理](./system.md)。

## 后期阶段：刷稀有的

传说和至宝品质的附魔非常稀有，是长期追求目标。

| 品质 | 出现概率 | 常见来路 |
| --- | --- | --- |
| 史诗 | 0.3% | 探索地牢、矿井 |
| 传说 | 0.1% | 要塞、末地城等高级地点 |
| 至宝 | 0.06% | 大量材料重铸 |
