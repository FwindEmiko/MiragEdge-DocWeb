# 附魔速览

> **本服的附魔分两块：原版附魔（和原版一样能弄到）+ 自定义附魔（需要去野外探索）。**  
> 下面简单说说不同阶段该关注什么。

## 新手阶段——先玩原版

附魔台和村民交易**只出原版附魔**。自定义附魔要去野外探索才能拿到。

```
先弄这些：锋利 / 保护 / 效率 / 耐久
从哪来：附魔台、村民、钓鱼 → 都是原版有的
```

> 先用原版附魔玩着就行，不需要刻意去刷自定义。

## 中期阶段——附魔循环

当你攒了一堆不想要的附魔书，就可以开始玩附魔循环了：

```
不要的附魔书 → 回收 → 魔法粉尘 / 魔法结晶
                       ↓
            重铸 → 新书（右键打开）
            融合 → 粉尘合成结晶
            增幅 → 给附魔书升级
```

> 详细玩法看 [附魔管理](./system.md)

## 后期阶段——刷稀有的

传说和至宝品质的附魔非常稀有，是长期追求目标。

```
史诗级  0.3%  ← 探索地牢、矿井就能碰到
传说级  0.1%  ← 得刷高级地方（要塞、末地城）
至宝级  0.06% ← 纯看脸，或者大量材料去重铸
```
