# 品质等级

附魔分成 **7 个品质等级**。品质越高效果越好，也越难弄到。

## 一眼看明白

| 品质 | 常见吗 | 回收能得什么 |
|:----|:------|:----------|
| 普通 | ⭐ 最常见 | 魔法粉尘 |
| 优良 | ⭐⭐ 常见 | 魔法粉尘 |
| 稀有 | ⭐⭐⭐ 还行 | 魔法粉尘 |
| 史诗 | ⭐⭐⭐⭐ 要碰运气 | 魔法结晶 |
| 传说 | ⭐⭐⭐⭐⭐ 很难得 | 魔法结晶 |
| 至宝 | ⭐⭐⭐⭐⭐⭐ 极稀有 | 魔法结晶 |
| 诅咒 | ⭐⭐⭐⭐ 看脸（但效果是负面的） | 魔法粉尘 |

> 魔法粉尘和魔法结晶可以在[附魔管理](./system.md)系统里用来换新的附魔。

## 哪些附魔在什么品质

| 品质 | 有哪些 |
|:----|------|
| 普通 | 亡灵杀手、节肢杀手、爆炸保护 |
| 优良 | 火焰附加、荆棘、效率、耐久 |
| 稀有 | 保护、力量、精准采集、水下呼吸 |
| 史诗 | 时运、无限、吸星、磁铁、夜伏 |
| 传说 | 经验修补、抢夺、自愈、反重力 |
| 至宝 | 追踪箭、范围挖矿、咒怨 |
| 诅咒 | 腐烂诅咒、脆弱诅咒 — 一共 9 种 |

> 全部的附魔清单看 [附魔大全](./list.md)

## 品质在游戏里什么颜色

```
普通=灰色    优良=绿色    稀有=蓝色    史诗=粉色
传说=金色    至宝=黄色    诅咒=红色
```
