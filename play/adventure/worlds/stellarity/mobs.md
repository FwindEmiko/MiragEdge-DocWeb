> 末地不再是安全通关即永别的终点。新的 Boss 与威胁让这片虚空之地成为冒险的真正挑战。

## Boss：末影龙（Ender Dragon）

> 繁星末地保留并增强末影龙战斗，不再是那个可以轻松解决的 Dragon。

### 强化机制

- **Boss 血条**：战斗时显示专属血条
- **末地水晶计数**：界面显示剩余水晶数量，所有水晶被摧毁前龙免疫伤害
- **额外攻击阶段**：俯冲、激光、火焰弹幕等多种新招式
- **特殊标记机制**：部分攻击附带特殊标记效果，需要玩家留意状态

### 主要掉落

| 掉落物 | 概率 | 说明 |
|--------|------|------|
| **生命水晶** | 必定掉落 | 静止时可快速恢复生命值 |
| **龙首** | 约 33% | 装饰性战利品 |
| **幻翼膜** | 12–38 个 | 数量随机 |
| **龙之翼** | 约 25% | 坚固但会牺牲部分飞行速度的鞘翅 |

## 其他生物

### 虚空生物（Voided Mobs）

繁星末地引入了「虚空化」生物变种——比原版对应生物更强的虚空版本，对未准备的冒险者构成更大威胁。

- **虚空僵尸**：比主世界僵尸更强、更快、更肉
- **更多虚空变种**：虚空骷髅、虚空蜘蛛等，散布在末地各处

### 末地村民（End Villager）

- **生成地点**：末地村庄
- **行为特点**：和平中立，可交易，提供与主世界不同的独家物品
- **重要交易品**：末地特色武器、特殊药水、稀有材料

### 试炼生物

新末地城的试炼刷怪笼中会生成升级版主世界生物（强化僵尸、骷髅、蜘蛛等），击败它们可以获得试炼钥匙，开启宝库获取稀有装备。

### 其他生物

- **末地鸡**：末地版的鸡，掉落末地羽毛
- **恼鬼、幻术师、蠹虫等**：在对应群系中按生成规则出现

## Boss 攻略

### 末影龙攻略

| 准备事项 | 说明 |
|----------|------|
| 装备 | 建议全套冠军盔甲或神圣盔甲 |
| 武器 | 龙刃、沙兰加（远程） |
| 药水 | 缓降、再生、力量 |
| 关键策略 | **先摧毁所有末影水晶**——龙在全部水晶被毁前免疫一切伤害 |

**打法要点**：
1. 进入末地后优先处理末影水晶，留意新增的防御机制
2. 所有水晶摧毁后，龙开始受到伤害
3. 注意躲避新的激光和火焰弹幕攻击
4. 龙血量极低时会降落在出口传送门上，跳上去给最后一击

### 光之女皇攻略

| 准备事项 | 说明 |
|----------|------|
| 装备 | 全套神圣盔甲（套装闪避效果救命） |
| 武器 | 虚空召唤（控场）+ 塔玛里斯（输出） |
| 药水 | 夜视、再生、跳跃提升 |
| 关键策略 | 保持移动——站桩必死 |

**打法要点**：
1. 找到神圣之地 → 获取并放置神圣祭坛
2. 使用星辉尘触发召唤
3. 不断移动躲避棱彩弹幕和以太长枪
4. 注意日间/夜间与 Radiant 强化状态的变化，及时调整打法

> **部分生物和 Boss 机制可能随版本更新而变化，以游戏内实际表现为准。**
