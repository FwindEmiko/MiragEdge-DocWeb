# 繁星 · 探索指南

从踏入末地到击败光之女皇，这条路线帮你规划每一步。

## 第一阶段：击败末影龙

进入末地后，第一个目标是击败强化末影龙。与以往不同，现在的末影龙战有更多挑战。

| 准备事项 | 说明 |
| --- | --- |
| 装备 | 全套下界合金盔甲，最好备好冠军盔甲或神圣盔甲 |
| 武器 | 远程武器用于摧毁水晶，近战武器用于输出龙 |
| 关键策略 | 先摧毁所有末影水晶。龙在全部水晶被毁前免疫一切伤害 |

击败后获得：生命水晶（必掉）、龙首（约 33%）、幻翼膜 12 到 38 个、龙之翼（约 25%）。

::: tip 提示
击败末影龙后约 8 秒，主岛坐标 `42 67 -48` 的诅咒祭坛会激活，并出现可取得的龙之刃。祭坛是后续所有末期装备的核心制作台。
:::

## 第二阶段：探索末地群系

繁星末地有 19 个自定义群系参与生成。以下是最值得优先探索的几个。

| 优先探索 | 为什么去 |
| --- | --- |
| 神圣之地 | 核心奇景区域，找光之圣堂和祭坛内容 |
| 棱彩沙丘 | 沙丘遗迹、村庄和沙漠遗迹集中出现 |
| 无尽沙丘 | 沙丘考古战利品，沙行附魔的来源 |
| 紫水晶森林 | 紫水晶植被和森林地物 |
| 水晶峭壁 | 水晶和紫水晶地物密集区域 |

先找末地村庄，位置在神圣之地、棱彩沙丘和神圣苔原。与末地村民交易可以拿到基础物资。沿途留意末地营地和渔夫小屋，它们提供补给和虚空钓鱼线索。

末地村民只收末影合金碎片。各职业卖什么，见[末地村庄交易大全](./trades/index.md)。

## 第三阶段：末地城探险

末地城是高级附魔和特殊装备的主要来源。

1. 找到保护水晶并攻击它：摧毁一枚水晶会生成一个宝库，并获得「水晶破坏者」进度。
2. 击败试炼刷怪笼生成的怪物：获得紫珀钥匙或镀金紫珀钥匙。
3. 用钥匙开启对应宝库：获取末影合金碎片、高级附魔书和特殊装备。

| 宝库 | 钥匙 | 主要奖励 |
| --- | --- | --- |
| 普通末地城宝库 | 紫珀钥匙 | 末影合金碎片 2 到 3 个，20 到 39 级附魔书，可能含虚空打击或虚空射击 |
| 不祥末地城宝库 | 镀金紫珀钥匙 | 末影合金碎片 4 到 7 个，30 到 45 级附魔书，可能含无星镰刀或始与末 |
| 末地船鞘翅宝库 | 翼之钥匙 | 鞘翅、烟花火箭、鞘翅附魔书 |

末地城专属高级附魔：暴击（剑，传说）、装甲飞行（鞘翅，史诗）、翱翔（鞘翅，史诗）、虚空射击（远程武器，传说）、虚空打击（近战武器，传说）。

## 第四阶段：挑战光之女皇

| 准备事项 | 说明 |
| --- | --- |
| 召唤方式 | 在神圣祭坛上使用星辉尘。手持炽金狂斧时丢出星辉尘会召唤辉耀版本 |
| 推荐装备 | 神圣盔甲、炽金狂斧、棱彩之剑或棱彩之弩 |
| 关键策略 | 保持移动，站桩必死 |

| 版本 | 核心掉落 | 概率掉落 |
| --- | --- | --- |
| 夜间 | 三选一：棱彩之剑、棱彩之弩、坠星盾 | 女皇之翼、翱翔徽章、瓶中精灵、唱片各 20% |
| 白天 | 炽金狂斧、翱翔徽章 | 女皇之翼 50%，毛绒绒正义之锤 30%，唱片 30% |
| 辉耀 | 辐光宝石、女皇之翼 | 瓶中精灵 50% |

辐光宝石是辉耀专属强化核心，放背包即可增强炽金狂斧、棱彩之剑和棱彩之弩的效果。瓶中精灵是纯装饰方块，放置后散发彩色粒子。

## 第五阶段：诅咒祭坛制作

击败末影龙后，诅咒祭坛可用于制作以下装备。

| 目标装备 | 需要收集 | 套装效果 |
| --- | --- | --- |
| 神圣盔甲 | 下界合金护甲、神圣锭 ×4、锻造模板 | 闪避一次攻击 |
| 冠军盔甲 | 下界合金护甲、紫颂覆板 ×4、锻造模板 | 连击积累龙之怒，伤害逐步提高 |
| 花卉盔甲 | 下界合金护甲、樱花树叶 ×8、锻造模板 | 箭矢增伤、爆炸花朵、隐身 |
| 潜影盔甲 | 下界合金护甲、潜影壳 ×4、锻造模板 | 潜影子弹追踪、被围攻减伤 |

核心材料的获取方式：

- 神圣锭通过神圣之地水域转化铁锭获得；
- 紫颂覆板在祭坛用铁锭加爆裂紫颂果合成；
- 末影合金碎片从末地城宝库获取。

全部配方见[繁星 · 诅咒祭坛](./altar.md)。

## 繁星成就速查

| 阶段 | 可解锁的成就提示 |
| --- | --- |
| 初入末地 | 进入末地解锁「终焉之始」；进入任意新群系解锁「末地探索者」 |
| 末地城挑战 | 摧毁一枚保护水晶解锁「水晶破坏者」；摧毁同一末地城 200 格范围内全部水晶解锁「征服者」 |
| 战斗 | 击败末影龙、光之女皇、潜影贝之王各自解锁对应战斗成就 |
| 装备收集 | 穿戴全套冠军或神圣盔甲、集齐三种特殊鞘翅、获得始与末 |
| 机制探索 | 第一次使用炼药锅合成、水域转化、染色鞘翅尾迹时解锁 |
| 终局 | 击败所有 Boss 并探索全部群系解锁「末地征服者」 |
