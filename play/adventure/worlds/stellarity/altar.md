# 繁星 · 诅咒祭坛

诅咒祭坛是末期装备的核心制作台。这页列出祭坛的全部合成配方。

<SmartImage src="/images/datapack/stellarity/biomes/altar_of_the_accursed.png" alt="被诅咒的祭坛" shadow radius="auto" caption="击败末影龙后解锁的诅咒祭坛：许多传说装备的核心制作台" />

## 怎么用

1. 击败末影龙：末地主岛坐标约 `42 67 -48` 的诅咒祭坛激活。
2. 从祭坛取下龙之刃。
3. 把材料丢在祭坛周围约 1.5 格内：满足配方后自动合成。
4. 投错材料时，潜行即可回收附近的材料。

::: tip 提示
鞘翅与任意一种染料一起丢入，可以改变鞘翅飞行尾迹的颜色。与水桶一起丢入可以洗去颜色。
:::

## 虚空吊坠灌注

在诅咒祭坛投入基础虚空吊坠、末影合金碎片 ×1，以及下表中的一种材料：

| 灌注材料 | 效果 |
| --- | --- |
| 紫水晶碎片 | 常驻夜视；潜行时附近敌人发光 |
| 铜锭 | 攻击有概率触发额外电弧伤害 |
| 钻石 | 攻击速度加 6% |
| 绿宝石 | 幸运加 1 |
| 金锭 | 挖掘速度加 15%，挖掘效率加 5% |
| 铁锭 | 受到伤害减 12% |
| 青金石 | 所有来源额外获得 1 到 3 点经验 |
| 下界合金锭 | 攻击伤害加 2，横扫伤害比例加 35% |
| 下界石英 | 移速加 4%、跳跃强度加 4%、移动效率加 40% |
