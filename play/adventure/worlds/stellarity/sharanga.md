# 繁星 · 圣弓与光灵之怒

这页讲两把进阶弓。圣弓是制作光灵之怒必需的材料，光灵之怒是诅咒祭坛合成的终极弓。

## 圣弓

圣弓是一把稀有弓，射出的光灵箭沿直线飞行，伤害比普通弓箭更高。它是制作光灵之怒的核心材料。

### 基础属性

| 属性 | 值 |
| --- | --- |
| 基础物品 | 弓 |
| 耐久 | 424 |

### 特殊效果

- 射出的光灵箭不受重力影响，沿直线飞行，可以穿透多个目标；
- 箭矢飞行速度比普通箭快约 12%；
- 以上效果只在使用光灵箭时生效，普通箭矢不触发；
- 两把圣弓可以在合成栏中合并修复耐久。

### 获取方式一：要塞幻术师掉落

主世界的要塞被重写过，里面有多个房间，会生成各种灾厄村民。幻术师就是其中之一，击败他有概率掉落圣弓。

- 约十分之一的刷怪房间会出现幻术师；
- 基础掉落概率为 7%，需要玩家亲手击杀；
- 附魔抢夺可以大幅提高掉率，抢夺 III 时约 94%；
- 同时还会掉落 7 到 22 支光灵箭。

| 抢夺等级 | 掉落概率 |
| --- | --- |
| 无 | 7% |
| 抢夺 I | 约 90% |
| 抢夺 II | 约 92% |
| 抢夺 III | 约 94% |

### 获取方式二：要塞工作坊宝箱

要塞中偶尔会出现工作坊房间，里面的宝箱有概率开出圣弓。

- 综合概率约 5%；
- 开出时耐久度随机损耗 15% 到 70%；
- 同一宝箱也可能开出铜电击盾。

### 获取方式三：末地制箭师 5 级交易

末地村庄里的制箭师升到 5 级后，可以用以下交易换取圣弓：

| 付出 | 获得 | 可交易次数 |
| --- | --- | --- |
| 弓 ×1、末影合金碎片 ×64 | 圣弓 ×1 | 2 次 |

这条途径最稳定。末影合金碎片的主要来源：

- 末地城宝库；
- 末地村民农民 1 级时有概率用 24 个小麦换 1 个末影合金碎片，最多交易 8 次。

末地村庄周围有大量干草块，可以快速合成小麦。

## 光灵之怒

光灵之怒是诅咒祭坛合成的终极弓，玩家俗称「怒灵」。蓄力拉满后射出的光灵箭会化为微光，自行追踪并攻击附近的生物。

### 基础属性

| 属性 | 值 |
| --- | --- |
| 基础物品 | 弓 |
| 耐久 | 636 |

### 特殊效果

- 蓄力拉满后射击，每支光灵箭会生成一缕追踪灵体，自动追击 16 格内的敌人；
- 灵体撞击造成较高伤害，约为 5 加箭矢基础伤害的 1.5 倍；
- 灵体最多存在约 7 秒，撞到实体或方块后消失；
- 射击和蓄力时伴有特殊音效和粒子效果。

### 诅咒祭坛配方

在诅咒祭坛上方投掷以下材料，祭坛会自动检测并合成：

| 材料 | 数量 |
| --- | --- |
| 圣弓 | 1 |
| 锻造模板 | 1 |
| 钻石 | 3 |
| 幻翼膜 | 8 |

合成方式与[诅咒祭坛](./altar.md)一致。

## 推荐获取路线

1. 前期：探索主世界要塞，重点寻找幻术师击杀，顺路开工作坊宝箱。带上抢夺 III 近乎必掉圣弓。
2. 中期：在末地村庄把村民转职为农民和制箭师。农民用 24 个小麦换末影合金碎片，制箭师升到 5 级后用弓加末影合金碎片换圣弓。
3. 后期：集齐材料后，在诅咒祭坛合成光灵之怒。

## 末影合金碎片怎么来

末影合金碎片是末地村庄的通用货币，也是日常探索的主要收获。

- 挖末地石时小概率额外掉落 1 个，约 2%；
- 末地城、末地船的箱子，以及营地帐篷的箱子里可以翻到；
- 界面上它是紫水晶碎片样式的物品，名字叫「末影合金碎片」。
