# 繁星 · 特殊装备

这页列出末地独有的特殊装备和核心材料，末尾给出按玩法风格选装备的速查表。

## 重要特殊装备

| 物品 | 已确认效果 | 主要来源 |
| --- | --- | --- |
| 龙之刃 | 末影龙首杀后从诅咒祭坛取下；通过连续攻击积累力量，蓄力后可打出强力冲拳 | 主岛诅咒祭坛 |
| 炽金狂斧 | 可蓄力释放多档太阳能冲击；手持时丢星辉尘会触发辉耀光之女皇的召唤条件 | 白天光之女皇 |
| 棱彩之剑 | 潜行蓄力后进行火焰旋转攻击，使附近敌人进入棱彩炼狱 | 夜间光之女皇，三选一 |
| 棱彩之弩 | 发射会多段爆炸的棱彩冲击，并使目标进入棱彩炼狱 | 夜间光之女皇，三选一 |
| 坠星盾 | 成功格挡后落下星辰攻击 | 夜间光之女皇，三选一 |
| 翱翔徽章 | 提供持续飞行，但速度和机动性受限；潜行时上看上升、下看下降 | 光之女皇 |
| 始与末 | 攻击时吸引灵魂；双持并注视灵魂可传送至其位置、伤害周围敌人并获得短暂增益 | 不祥末地城宝库 |
| 辐光宝石 | 辉耀专属强化核心，放在背包即可生效：炽金狂斧充能速度翻倍、棱彩珍珠冷却减半、棱彩之剑护甲穿透提升 | 辉耀光之女皇，必掉 |
| 瓶中精灵 | 纯装饰方块，四种颜色可选，放置后持续散发彩色粒子效果 | 光之女皇，概率掉落 |

## 核心材料

| 材料 | 说明 |
| --- | --- |
| 末影合金碎片 | 末地城宝库主要产出，用于制作末期装备和模板复制 |
| 神圣锭 | 通过神圣之地水域转化铁锭获得，用于神圣盔甲和其他装备 |
| 紫颂覆板 | 诅咒祭坛合成，铁锭加爆裂紫颂果，冠军盔甲的核心材料 |
| 锻造模板 | 所有末期装备的锻造材料，可通过末地城宝库获得，或复制模板 |

材料的制作方式与配方见[诅咒祭坛](./altar.md)和[炼药锅与水域转化](./cauldron.md)。
