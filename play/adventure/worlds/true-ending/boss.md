# 终焉 · Boss 攻略

这页讲强化末影龙的终局战：它比原版强在哪里，每一招怎么躲，以及从摧毁水晶到收尾的三阶段流程。

## 强化对比

| 属性 | 原版末影龙 | 终焉末影龙 |
| --- | --- | --- |
| 生命值 | 200 HP | 300 HP，加 50% |
| 攻击模式 | 俯冲、龙息 | 俯冲冲击波、龙息、连锁火球、激光 |
| 击退抗性 | 中等 | 大幅提升，不会被箭矢定在空中 |
| 末影水晶笼 | 铁笼 | 幻翼守卫铁笼，击杀幻翼后铁笼破碎 |
| 终局阶段 | 无 | 10% 生命值时免疫伤害直到栖息，栖息后需要空中最后一击 |
| Boss 音乐 | 无 | 有，全中央岛屿的玩家都能听到 |

## 攻击模式全解

### 1. 俯冲冲击波

末影龙向地面俯冲，落地时产生巨大的冲击波。站得太近会被击飞并受到高伤害。

应对：看到龙俯冲时立即跑开，落地瞬间跳跃躲避冲击波。

### 2. 三连俯冲

当龙的血量降到 75% 以下时，栖息状态下会连续俯冲 3 次。

应对：不要贪刀。每次俯冲后立刻拉开距离，等三次俯冲结束再输出。

### 3. 连锁龙息火球

龙在空中连发多枚龙息火球，落地产生持续 60 秒的滞留伤害云。原版仅 30 秒。

应对：注意脚下的紫色粒子，不要停在龙息云里。龙息火球直接命中也有伤害。

### 4. 巨型激光

龙从口中发射巨大的激光束，横扫整个战斗平台。

应对：看到龙嘴发光就立刻躲到黑曜石柱后面，或用末影珍珠快速位移。

### 5. 终局阶段

当龙的血量降到 10% 时：

- 龙免疫所有伤害，直到栖息；
- 如果 30 秒内未栖息，龙会强制栖息；
- 栖息后龙悬浮在低空，需要跳起来打最后一击。

应对：准备好缓降药水或末影珍珠，跳上空中完成最后一刀。

## 战斗流程

### 第一阶段：摧毁末影水晶

1. 进入末地，先不要管龙，直奔末影水晶塔。
2. 每座水晶塔被一只幻翼守卫，优先击杀幻翼。
3. 击杀幻翼后铁笼破碎，摧毁末影水晶。
4. 龙在所有水晶被摧毁前免疫伤害。
5. 屏幕会显示水晶剩余数量的计数器。

### 第二阶段：常规战斗

所有水晶摧毁后，龙开始受到伤害。

- 用弓箭远程消耗；
- 注意躲避俯冲冲击波和激光；
- 龙栖息在传送门时是近战输出的最佳时机；
- 小心龙息火球，它持续 60 秒，直接命中也有伤害。

### 第三阶段：终局对决

1. 龙血量降到 10% 后免疫伤害。
2. 龙会强制栖息，悬浮在低空，等待最后一击。
3. 跳起来用近战武器完成最后一击。
4. 龙被击杀后，128 格内所有玩家获得「解放末地」成就。

## 龙战记录与龙蛋

每次末影龙复活或被击败，服务器都会发布龙战通知。首条末影龙还会留下第一位进入该末地的玩家与等待时长记录。服务器重启不会抹去正在进行的龙战记录。

击败末影龙后，传送门上方会掉落龙蛋。部分早期龙蛋会以「星辉龙蛋」的形式留下编号、击杀者、时间以及首龙标记。

查询全服或当前末地的龙战、龙蛋和最近击杀记录时，使用 `/dm stats`。这项查询只用于了解进度，不会改变龙战状态。

## 常见问题

| 问题 | 解决方案 |
| --- | --- |
| 被冲击波击飞 | 用末影珍珠回平台，或喝缓降药水 |
| 龙息云太多 | 全平台跑起来，不要站桩 |
| 幻翼太难打 | 用远程先解决，它们是最优先目标 |
| 终局阶段打不到 | 用脚手架搭高，或用末影珍珠跳到龙的位置 |
