## Boss 级生物

### 炼狱游者（Hovering Inferno）

> 烬域的终极 Boss，灵感来自 Minecon Earth 2017 的 Mob D（Wildfire）和东方 Project 弹幕游戏

<SmartImage src="/images/datapack/incendium/mobs/Hovering_Inferno.png" alt="炼狱游者" shadow radius="auto" caption="700❤ 的弹幕地狱——在魔炎沙丘的炼狱祭坛献上下界之星，召唤毁灭" />

- **基础实体**：烈焰人
- **生命值**：700❤（350 颗心）
- **护甲**：20 点 | **护甲韧性**：12 点 | **攻击伤害**：20 点
- **击退抗性**：87% | **移动速度**：0.4 | **追踪范围**：70 格
- **召唤方式**：在魔炎沙丘的**炼狱祭坛**讲台上投掷**下界之星**

#### 战斗阶段

**阶段 1（常规阶段）：**
- 发射潜影弹、火球、烟花和火焰，呈波浪状精准弹幕
- 召唤炼狱仆从（4 个一组，装备下界合金剑的恼鬼）
- 召唤唤魔者尖牙和沙漠烈焰人
- 生命值耗尽后进入阶段 2

**阶段 2（终焉符卡）：**
- Boss 复活，播放东方 Project 同人曲《Border of Life》
- 传送至场地中央，**无敌**，缓慢自损生命
- 发射两道旋转激光——一道在脚部高度，一道在头顶高度（需潜行躲避）
- 同时发射发光的潜影弹
- 玩家只需存活到 Boss 自行死亡

#### 技能列表

| 技能 | 描述 |
|------|------|
| 气泡弹幕 | 射线追踪潜影弹 |
| 蝴蝶激光 | 扇形集束射线（正/反两种模式） |
| 冲锋 | 带火焰残影冲撞 |
| 火球 | 普通火球 / 强化火球 |
| 烟花弹幕 | 直射 / 扩散两种模式 |
| 护盾激光 | 半场 / 全屏旋转激光 |
| 潜影弹 | 追踪潜影贝弹药 |
| 召唤 | 烈焰人 / 恼鬼 |
| 终焉一击 | 最终阶段终极技能 |
