# 烬域 · 探索指南

> 从踏入下界到击败烈焰执政官，这条路帮你一步步走完。

## 第一阶段：初入下界

你的第一个目标是**熟悉下界的新群系**。下界不再只有荒芜的红色地狱，现在有 8 个风格各异的群系等你探索：

| 群系 | 特征 | 简单找法 |
|------|------|---------|
| 灰烬荒原（Ash Barrens） | 灰烬覆盖的开阔平原 | 进入下界后最常见的群系 |
| 魔炎沙丘（Infernal Dunes） | 红色沙丘，岩浆流淌 | 沿岩浆海寻找 |
| 倒悬森林（Inverted Forest） | 蘑菇树倒挂生长 | 灰烬荒原边缘 |
| 石英平原（Quartz Flats） | 白色石英地表 | 高处平台区域 |
| 毒化废土（Toxic Heap） | 绿色毒雾弥漫 | 红树林附近 |
| 火山三角洲（Volcanic Deltas） | 岩浆河流与火山岩 | 靠近岩浆海下方 |
| 泣泪幽谷（Weeping Valley） | 幽暗的峡谷 | 地势低洼处 |
| 凋零森林（Withered Forest） | 凋零树木，猪灵聚落 | 各群系交界处 |

**推荐装备**：防火药水、远程武器、镐子（挖石英）。

## 第二阶段：探索结构与收集装备

探索下界的 9 种新结构，获取烬域武器和装备：

| 结构 | 位置 | 为什么去 |
|------|------|---------|
| 猪灵村庄 | 凋零森林 | 安全的交易点，可获取基础装备 |
| 废弃实验室 | 毒化废土 | 可获取不稳定粉末等特殊道具 |
| 废弃哨塔 | 各群系 | 可解救小恶魂（Ghastling）——用火焰弹喂食能驯服 |
| 禁忌城堡 | 高处 | 下界核心区域，最终 Boss 所在地 |
| 管道（Pipeline） | 火山三角洲 | 运输通道，精英哨兵守卫 |
| 圣所（Sanctum） | 石英平原 | 金库内部有守卫，可获取高级装备 |
| 炼狱祭坛 | 魔炎沙丘 | 祭坛区域藏有特殊物品 |
| 下界反应堆 | 毒化废土附近 | 可激活的机制结构 |

**关键装备收集路线**：
1. 先探索猪灵村庄和废弃实验室，获取基础烬域武器
2. 前往管道和圣所，挑战精英守卫，获取更高级装备
3. 收集到足够资源后，挑战禁忌城堡

## 第三阶段：挑战 Boss

下界有两个主要 Boss 目标：

| Boss | 位置 | 准备建议 |
|------|------|---------|
| **圣所守卫**（Vault Guardian） | 圣所金库 | 中等装备即可挑战，获得圣所系列战利品 |
| **烈焰执政官**（Blaze Archon） | 禁忌城堡顶层 | 需要全套烬域装备和充足药水，下界最终挑战 |

**核心武器推荐**：赤红匕首（吸血）、雷击三叉戟（范围伤害）、诸神黄昏（终极输出）。

## 烬域成就速查

以下成就会在探索过程中自然触发，不需要刻意刷——但了解它们能帮你确认进度：

| 阶段 | 可解锁的成就提示 |
|------|----------------|
| 初入下界 | 进入新群系时自动解锁对应的探索成就（共 8 个） |
| 结构探索 | 第一次进入禁忌城堡、圣所、炼狱祭坛等结构时解锁 |
| 战斗挑战 | 击败任意 Boss 解锁「征服者」；击败烈焰执政官解锁「命运对决」 |
| 装备收集 | 获得赤红匕首、雷击三叉戟、诸神黄昏等核心武器时解锁 |
| 收集进阶 | 集齐全部三种烬域盾牌解锁「盾牌大师」；获得炼狱之翼鞘翅解锁「炼狱之翼」 |
| 趣味支线 | 用火焰弹喂食小恶魂、解救被困的 Ghastling、在魔炎沙丘使用火风暴武器 |

> 全部 39 个成就的完整列表以游戏内进度为准，上面只列出关键节点帮你规划路线。
