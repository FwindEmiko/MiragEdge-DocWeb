# 烬域 · 探索指南

> 从踏入下界到击败炼狱游者，这条路帮你一步步走完。

## 第一阶段：初入下界

你的第一个目标是**熟悉下界的新群系**。下界不再只有荒芜的红色地狱，现在有 8 个风格各异的群系等你探索：

| 群系 | 特征 | 简单找法 |
|------|------|---------|
| 灰烬荒原（Ash Barrens） | 灰烬覆盖的开阔平原 | 进入下界后常见的群系 |
| 魔炎沙丘（Infernal Dunes） | 红色沙丘，岩浆流淌 | 沿岩浆海寻找 |
| 倒置森林（Inverted Forest） | 蘑菇树倒挂生长 | 灰烬荒原边缘 |
| 石英平原（Quartz Flats） | 白色石英地表 | 高处平台区域 |
| 毒化废土（Toxic Heap） | 绿色毒雾弥漫 | 红树林附近 |
| 火山三角洲（Volcanic Deltas） | 岩浆河流与火山岩 | 靠近岩浆海下方 |
| 垂泪幽谷（Weeping Valley） | 幽暗的峡谷 | 地势低洼处 |
| 凋零森林（Withered Forest） | 凋零树木，猪灵聚落 | 各群系交界处 |

**推荐装备**：防火药水、远程武器、镐子（挖石英）。

## 第二阶段：探索结构与收集装备

探索下界的 9 种新结构，获取烬域武器和装备：

| 结构 | 位置 | 为什么去 |
|------|------|---------|
| 猪灵村庄 | 凋零森林 | 安全的交易点，可获取基础装备 |
| 废弃实验室 | 凋零森林 | 可获取防化服部件、不稳定火药 |
| 废弃哨塔 | 石英平原 | 可解救小恶魂（Ghastling）——用火焰弹喂食能驯服 |
| 石英厨房 | 石英平原 | 挑战骷髅厨师托尔特，洗劫厨房宝藏 |
| 禁忌城堡 | 灰烬荒原 | 下界核心区域，大量武器装备集中于此 |
| 管道 | 魔炎沙丘 / 毒化废土 | 管道迷宫，精英哨兵守卫疯癫火把 |
| 圣所 | 石英平原 | 灾厄村民据点，地下迷宫藏有诸神黄昏和破晓者 |
| 炼狱祭坛 | 魔炎沙丘 | 召唤终极 Boss 炼狱游者的场所 |
| 下界反应堆 | 毒化废土 | 辐射主管 + 反应堆哨兵守卫，防化服和辐射护盾在此 |

**关键装备收集路线**：
1. 先探索猪灵村庄和废弃实验室，获取基础装备和防化服
2. 挑战禁忌城堡，获取赤红匕首、冰冻之刃、雷击三叉戟等武器
3. 前往圣所和管道，挑战精英守卫，获取诸神黄昏、疯癫火把等高级装备
4. 收集到炼狱之羽后，在锻造台升级鞘翅为炼狱之翼

## 第三阶段：挑战 Boss

| Boss | 位置 | 准备建议 |
|------|------|---------|
| **圣所护卫者**（Sanctum Guardian） | 圣所地下金库 | 中等装备即可挑战，3 名守卫装备神圣之怒弩 |
| **骷髅厨师托尔特**（Torte） | 石英厨房 | 自带力量 V，攻击力极高，远程击杀更安全 |
| **辐射主管**（Radiation Director） | 下界反应堆 | 需防化服，手持下界合金剑造成凋零 |
| **反应堆哨兵**（Reactor Sentry） | 下界反应堆中心 | 10 个不死图腾的巨型恶魂炮台，爆炸保护必备 |
| **精英管道哨兵**（Prime Sentry） | 管道宝藏室 | 8 个不死图腾，掉落疯癫火把 |
| **炼狱游者**（Hovering Inferno） | 魔炎沙丘炼狱祭坛 | 700❤，需全套烬域装备和充足药水，下界最终挑战 |

### 炼狱游者挑战要点

1. **召唤**：在魔炎沙丘找到炼狱祭坛，在讲台上投掷**下界之星**
2. **阶段 1**：弹幕地狱——火球、潜影弹、烟花、护盾激光，还会召唤恼鬼和沙漠烈焰人
3. **阶段 2**：Boss 变无敌，缓慢自损生命，发射两道旋转激光（需潜行躲避），**只需存活到 Boss 死亡**
4. **掉落**：炼狱之羽、棱镜护盾/死灵护盾、火风暴/开路先锋

**核心武器推荐**：赤红匕首（吸血）、雷击三叉戟（范围伤害）、枯萎陨灭（亡灵克星）。

## 烬域成就速查

以下成就会在探索过程中自然触发，不需要刻意刷——但了解它们能帮你确认进度：

| 阶段 | 可解锁的成就提示 |
|------|----------------|
| 初入下界 | 踏入烬域；探索任意群系解锁「探索者」；走遍全部 8 个群系解锁「群系图鉴」 |
| 结构探索 | 进入禁忌城堡解锁「猪灵王殿」；进入圣所解锁「圣所疑云」；进入石英厨房解锁「不自量力」 |
| 战斗挑战 | 击杀圣所护卫者解锁「宝库猎人」；击败炼狱游者解锁「烈焰终结」 |
| 装备收集 | 获得炼狱之羽解锁「烈焰锻造」；获得炼狱之翼解锁「烈焰之翼」 |
| 趣味支线 | 用火焰弹喂食小恶魂解锁「喂养野兽」；穿锁链甲驱散不安灵魂解锁「驱灵套装」 |
| 极限挑战 | 不穿护甲直面炼狱游者最终阶段解锁「裸装挑战」 |

> 全部成就的完整列表以游戏内进度为准，上面只列出关键节点帮你规划路线。
