# 趣味彩蛋

三个小型趣味机制。它们不改变世界面貌，但给游戏添了一些意想不到的小乐趣，也添了一点小挑战。

## 落羽：鸡会掉羽毛

鸡会定期自动掉落羽毛，就像现实中的鸡一样。

| 效果 | 说明 |
| --- | --- |
| 掉落方式 | 每隔一段时间自动脱落一根 |
| 有什么用 | 不用再杀鸡取羽，羽毛农场变得可行 |
| 兼容性 | 不影响原版鸡的繁殖和正常掉落 |

养一群鸡，就能躺着收羽毛。这是箭矢自由的第一步。

## 炎爆：下界闪电苦力怕

下界也出现了苦力怕，但比主世界的更危险。

- 生成地点：下界各处。
- 特殊能力：爆炸威力比主世界苦力怕更大。
- 外观：烈焰色的特殊纹理。
- 应对方式：保持距离，用远程武器解决。

::: danger 危险
在下界挖矿时听到「嘶嘶」声就赶快跑。这可不是主世界那种小爆炸。
:::

## 护矿：挖金矿激怒猪灵

在下界挖掘金矿石或下界金矿石，会激怒附近的僵尸猪灵。

- 触发条件：挖掘金矿石或下界金矿石。
- 效果：附近的僵尸猪灵被激怒并攻击你。
- 应对方式：挖金矿前先清理周围猪灵，或者穿着金甲降低敌意。

金子在猪灵眼中是神圣的。动了他们的金子，就得面对他们的怒火。
