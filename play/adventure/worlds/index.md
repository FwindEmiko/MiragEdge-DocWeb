# 世界与结构

这里记录已经整理为玩家教程的世界、群系、结构和 Boss 内容。它回答“世界里有什么”，具体奖励和前置条件仍以对应详情页为准。

::: tip 探索前先看

野外结构中的箱子可能涉及个人战利品、领取名额和区域重置。出发前先阅读[战利品与探索区域](/play/adventure/loot)，确认领取方式与安全边界。

:::

## 内容总览

锐界幻境的世界内容分为两类：改变环境和探索路线的区域内容，以及直接影响战斗目标的特殊内容。

### 核心主题包

| 名称 | 简介 | 文档 |
|------|------|------|
| **烬域** | 下界环境、结构、生物和装备内容的集中图鉴 | [探索烬域](./incendium/biomes) |
| **繁星** | 末地环境、结构、生物和装备内容的集中图鉴 | [探索繁星](./stellarity/biomes) |

### 中型内容包

| 名称 | 简介 | 文档 |
|------|------|------|
| **地城酒馆** | 当前仅整理为五种原版结构改造：古城、矿井、沙漠神殿、沼泽小屋和海底神殿 | [查看结构](./dungeons-and-taverns/structures) |
| **筑物与塔楼** | 野外小型建筑和塔楼，补充主世界探索路线 | [查看建筑](./structory/structures) |
| **遗构与探境** | 散布在世界各处的遗迹、探索点和地下结构 | [查看结构](./exploration/structures) |

### 环境与捣怪包

| 名称 | 简介 | 文档 |
|------|------|------|
| **村庄与城市** | 翻新村庄、聚落和大型建筑，增加主世界的探索目标 | [查看详情](./rare-structures/overview) |
| **世界生成** | 主世界、下界、末地和洞穴的环境扩展 | [查看详情](./worldgen/overview) |
| **破门与沧墟** | 废弃传送门和海底废墟改造 | [查看结构](./hoppo-ruins/structures) |
| **终焉** | 强化末影龙的终局挑战 | [Boss攻略](./true-ending/boss) |
| **趣味内容** | 不改变主路线的轻量环境和生存机制 | [查看详情](./fun-packs/overview) |
