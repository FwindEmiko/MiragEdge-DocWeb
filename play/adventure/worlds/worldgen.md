# 世界生成与地形

锐界幻境的主世界和末地使用多个世界生成扩展，共同塑造你脚下的每一寸土地。

<SmartImage src="/images/datapack/worldgen/terralith/terralith_1.jpeg" alt="世界生成" shadow radius="auto" caption="从壮丽的山川到深邃的洞穴：多个世界生成扩展共同塑造了这片土地" />

## 主世界地形

### 地灵（Terralith）

主世界地形大修。新增 100 个以上群系，每个群系有独特的地表方块、植被和地貌。

| 代表群系 | 特色 |
| --- | --- |
| 雪山高原 | 高耸入云的雪山，云层在山腰飘过 |
| 樱花谷 | 樱花树遍布的山谷，全年粉色花雨 |
| 火山口 | 死火山形成的环形山，内部有独特矿物 |
| 迷雾森林 | 常年笼罩在雾气中的原始丛林 |
| 沙漠峡谷 | 被河流切割的沙漠台地 |
| 热带群岛 | 散布在温暖海洋中的小岛群 |

### 地脉（Tectonic）

地质构造重制，地形更戏剧化，海洋更深，地质特征更真实。

- 山脉更高更陡，有真实的山脊线；
- 海洋深度增加，海底地形更复杂；
- 河流走向和宽度更自然；
- 平坦的高原区域适合建造；
- 洞穴和峡谷网络更丰富。

地脉与地灵协同工作，主世界的地形会同时体现两者的效果。

## 洞穴系统

### 洞渊（Subsurface）

洞穴系统扩展，地下世界更深、更广阔。

- 洞穴延伸至更深的地层；
- 有巨大的地下空洞和穹顶；
- 洞穴之间通过通道自然连接；
- 不同深度有不同的地下生态系统。

## 末地地形

### 虚景（Nullscape）

末地地形增强，天空岛更壮丽多变。

- 末地外岛面积大幅增加；
- 地形起伏，不再平坦；
- 不同 Y 层有不同的地貌特征；
- 末地天空和虚空的视觉效果增强。

## 沙漠扩展

### 漠谷（U Desert）

沙漠结构扩展，为荒漠地区增添神秘建筑。

- 新增多种沙漠专属结构；
- 沙漠中出现罕见的绿色庇护所；
- 沙丘地貌更自然。

## 协同效果

| 维度 | 效果 |
| --- | --- |
| 主世界 | 地灵与地脉叠加，形成史诗级地形 |
| 洞穴 | 洞渊塑造深邃的地下世界 |
| 沙漠 | 漠谷带来丰富的沙漠探险内容 |
| 末地 | 虚景塑造壮丽的虚空群岛 |
