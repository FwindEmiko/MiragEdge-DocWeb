# 世界生成与地形

> 锐界幻境的主世界和末地使用了多个世界生成数据包，共同塑造你脚下的每一寸土地。

## 主世界地形

### Terralith · 地灵

**主世界地形大修** — 新增 100+ 个群系，每个群系有独特的地表方块、植被和地貌。

| 代表群系 | 特色 |
|---------|------|
| **雪山高原** | 高耸入云的雪山，云层在山腰飘过 |
| **樱花谷** | 樱花树遍布的山谷，全年粉色花雨 |
| **火山口** | 死火山形成的环形山，内部有独特矿物 |
| **迷雾森林** | 常年笼罩在雾气中的原始丛林 |
| **沙漠峡谷** | 被河流切割的沙漠台地 |
| **热带群岛** | 散布在温暖海洋中的小岛群 |

### Tectonic · 地脉

**地质构造重制** — 更戏剧化的地形、更深的海洋、更真实的地质特征。

- 山脉更高更陡，有真实的山脊线
- 海洋深度增加，海底地形更复杂
- 更自然的河流走向和宽度
- 平坦的高原区域适合建造
- 更丰富的洞穴和峡谷网络

> 地脉与地灵协同工作，主世界的地形会同时体现两者的效果。

## 洞穴系统

### Subsurface · 洞渊

**洞穴系统扩展** — 更深、更广阔的地下世界。

- 洞穴延伸至更深的地层
- 巨大的地下空洞和穹顶
- 洞穴之间通过通道自然连接
- 不同深度有不同的地下生态系统

## 末地地形

### Nullscape · 虚景

**末地地形增强** — 让末地的天空岛更加壮丽多变。

- 末地外岛面积大幅增加
- 地形起伏，不再平坦
- 不同 Y 层有不同的地貌特征
- 增强末地天空和虚空的视觉效果

## 沙漠扩展

### U Desert · 漠谷

**沙漠结构扩展** — 为荒漠地区增添神秘建筑。

- 新增多种沙漠专属结构
- 沙漠中罕见的绿色庇护所
- 更自然的沙丘地貌

## 协同效果

| 维度 | 效果 |
|------|------|
| **主世界** | 地灵（Terralith）+ 地脉（Tectonic）→ 史诗级地形 |
| **洞穴** | 洞渊（Subsurface）→ 深邃的地下世界 |
| **沙漠** | 漠谷（U Desert）→ 丰富的沙漠探险 |
| **末地** | 虚景（Nullscape）→ 壮丽的虚空群岛 |
