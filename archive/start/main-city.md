# 主城共建

::: tip 新服主城，由我们共同搭建

新服不再有预建好的主城——出生点范围就是未来的主城区，它从开服第一天起就交给全体玩家共同建设。你搭的每一座房子，都可能成为新主城的一部分。

:::

## 为什么是共建

新服取消了独立的主城世界，出生点范围被划为主城区。相比"管理员建好再开放"的旧模式，共建让主城从一开始就有玩家的痕迹：商店街、广场、车站、地标建筑，都由大家亲手完成。

这不是简单的"填方块"，而是新主城的**长期规划**：早期建设决定主城骨架，后续慢慢填充细节。你的作品会留在主城里，被后来者看到。

## 怎么参与

参与方式以游戏内提示和群公告为准，大致流程是：

1. 进入主城区，找到当前规划中的建设区域
2. 按照规划风格（或自由发挥的指定地块）进行建造
3. 完成建造后，按群公告说明申报，获得方块银行「块币」补贴

::: tip 块币是什么

块币是[方块银行](/plugins/custom/emc-shop)使用的货币，可以在方块银行兑换大量建筑方块——建得越多、补贴越多，正好形成"建设 → 块币 → 建材 → 继续建设"的循环。

:::

## 建设守则

为了让主城看起来是一个整体，而不是杂乱的拼贴，参与建设请遵守：

- **跟随规划**：主城有整体分区（商业区、休闲区、交通枢纽等），先在公告或游戏内确认自己建设的地块属于哪个区
- **风格协调**：尽量贴合该区域的规划风格；拿不准时，可以先搭小样让管理员过目
- **不占公共通道**：道路、广场、传送点周边保持通畅，给公共设施留位置
- **边界以内**：只在自己分配的地块内建造，不越界、不覆盖他人作品

## 常见问题

### 我没有建筑经验，能参与吗？

可以。主城也需要功能性建筑（商店、仓库、车站），不全是"好看"的建筑。先从小地块、功能性建筑开始，熟悉后再挑战地标。

### 补贴的块币有上限吗？

具体补贴规则（单价、上限、申报方式）以开服后的群公告和游戏内提示为准。基本原则是：合理且有质量的建设都会得到认可。

### 我在主城建的房子会被重置吗？

主城区属于保护区，不会被探索重置区刷新。但请记住：公共主城属于全体玩家，管理员保留对影响公共体验的建筑进行调整的权利。
