# 死亡回程

在非 PVP 世界死亡后，系统会记录你最后一次死亡的位置。它帮你找回路线，但不会撤销这次死亡。

## 死亡后先确认记录

Java 版玩家会收到带坐标的死亡提示，可以直接点击其中的返回选项。也可以随时输入 `/back` 返回最近一次记录的死亡点。

死亡记录会保留所在的世界。即使你已经前往别的世界，仍可返回这个最新记录点。下一次死亡发生后，记录才会更新为新的位置。

## 返回时会发生什么

成功返回后会出现这些变化：

- 减少 2 点饥饿值。
- 短暂获得失明与强力缓慢。
- 两次成功返回之间需要等待 5 秒。

返回不会删除记录，冷却结束后仍可再次回到同一个最新死亡点。没有死亡记录，或记录所在的世界已经不存在时，无法返回。

## 不同客户端的体验

Java 版可以在死亡提示中直接点击返回。

基岩版玩家会在重生约 2 秒后看到「返回死亡点 / 取消」的确认界面。表单没有出现时，手动输入 `/back`。

## PVP 世界的例外

PVP 世界中的死亡不会生成新的死亡记录。

最近记录点位于 PVP 世界时，不能通过返回功能前往那里。

这不等于身处 PVP 世界时绝对不能使用返回：能否返回取决于你最近记录点所在的世界。

## 闪电苦力怕的意外掉落

被**闪电苦力怕的爆炸**击杀时，有 30% 概率掉落自己的玩家头颅。它不是每次都会出现，遇到这种危险的战斗时先评估能否安全取回掉落物。

## 常见问题

### 为什么不能返回？

先确认是否有最新死亡记录、记录所在世界是否仍存在，以及是否还在 5 秒冷却中。记录点位于 PVP 世界时也不能返回。

### 返回会丢失什么？

减少 2 点饥饿值，并带来短暂的失明与缓慢。
