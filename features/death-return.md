# 死亡回程

在非 PVP 世界死亡后，系统会记录你最后一次死亡的位置。它帮你找回路线，但不会撤销这次死亡。

## 死亡后先确认记录

Java 版玩家会收到带坐标的死亡提示，可以直接点击其中的返回选项。也可以随时输入 `/back` 返回最近一次记录的死亡点。

死亡记录会保留所在的世界。即使你已经前往别的世界，仍可返回这个最新记录点。下一次死亡发生后，记录才会更新为新的位置。

## 返回要花多少钱

**每天前 30 次死亡，返回免费。**

从当天第 31 次死亡起开始收费，费用随当天死亡次数递增：

| 当天死亡次数 | 返回费用（灵叶） |
| --- | --- |
| 1 ~ 30 | 免费 |
| 31 ~ 40 | 100 |
| 41 ~ 50 | 102 |
| 51 ~ 60 | 120 |
| 61 ~ 70 | 150 |
| 71 ~ 80 | 158 |
| 81 ~ 90 | 160 |
| 91 ~ 100 | 165 |
| 101 ~ 110 | 170 |
| 111 ~ 120 | 175 |
| 121 ~ 130 | 180 |
| 131 ~ 140 | 185 |
| 141 及以上 | 190 |

死亡次数在每天 0 点重置，第二天重新从免费额度开始算。

> **注意**：这里的费用是**用 `/back` 或点击死亡提示返回**时才收的。它与下面「死亡掉落」是两笔独立的账——死亡本身就会扣一次（额度见下节），返回再扣一次。想少花钱，走回去捡金粒比直接返回划算。

## 死亡会掉落「遗失的灵叶」

死亡时会从你的余额中扣除一笔灵叶，并原地掉落一颗发光的金粒，名字是`遗失的灵叶 ×额度`。它代表这次扣掉的总量。

扣除额度随当天死亡次数递增。**前 30 次也算，只是额度很小（0 ~ 10，随机）**——落到 0 时这次不扣费、也不掉金粒：

| 当天死亡次数 | 掉落额度（灵叶） |
| --- | --- |
| 1 ~ 30 | 0 ~ 10（每次随机，可能为 0） |
| 31 ~ 40 | 50 ~ 100 |
| 41 ~ 50 | 100 ~ 150 |
| 51 ~ 60 | 150 ~ 200 |
| 61 ~ 70 | 200 ~ 350 |
| 71 及以上 | 350 ~ 900 |

这颗金粒**可以捡回来**，规则是：

| 谁去捡 | 结果 |
| --- | --- |
| 自己走回死亡点 | 可拾取，灵叶全额返还给自己 |
| 其他玩家拾取 | 可拾取，等额灵叶转给拾取的人 |
| 自己用 `/back` 返回后 | **不可拾取**，这次损失就坐实了 |

金粒在世界上存在 6 分钟，超时消失。想让损失回来，就走回去捡，不要直接 `/back`。

余额不足时系统有保底：扣完不会让你低于 400 灵叶；余额本来就不足 400 时，不扣费也不掉金粒。

## 返回时会发生什么

成功返回后会出现这些变化：

- 减少 2 点饥饿值。
- 短暂获得失明与强力缓慢（约 3 秒）。
- 同时获得约 3 秒的抗性提升，避免刚落地就被围攻。
- 两次成功返回之间需要等待 5 秒。

返回不会删除记录，冷却结束后仍可再次回到同一个最新死亡点。没有死亡记录，或记录所在的世界已经不存在时，无法返回。

## 不同客户端的体验

Java 版可以在死亡提示中直接点击返回。

基岩版玩家会在重生约 2 秒后看到「返回死亡点 / 取消」的确认界面，界面上会写明本次返回要花多少灵叶，30 秒不操作会自动关闭。表单没有出现时，手动输入 `/back`。

## PVP 与其他世界的例外

PVP 世界与资源世界（`zc`）中，死亡记录、`/back` 返回与死亡惩罚**全部禁用**。

最近记录点位于这些世界时，不能通过返回功能前往那里。这不等于身处其中时绝对不能使用返回：能否返回取决于你最近记录点所在的世界。

## 闪电苦力怕的意外掉落

被**闪电苦力怕的爆炸**击杀时，有 30% 概率掉落自己的玩家头颅。它不是每次都会出现，遇到这种危险的战斗时先评估能否安全取回掉落物。

## 常见问题

### 为什么不能返回？

先确认是否有最新死亡记录、记录所在世界是否仍存在，以及是否还在 5 秒冷却中。记录点位于 PVP 或资源世界时也不能返回。

### 返回会丢失什么？

减少 2 点饥饿值，并带来短暂的失明与缓慢。

### 死亡本身要花钱吗？

要。死亡时会按当天的死亡次数扣一笔灵叶并掉出金粒，前 30 次额度是 0~10（可能为 0）。这笔和返回费用是分开算的。

### 掉的金粒没捡会怎样？

超过 6 分钟原地消失，那笔灵叶就损失了。想拿回来必须走回死亡点自己捡，用 `/back` 返回反而捡不到。
