# 建筑大师

给建筑师准备的建造便利功能，包含盔甲架编辑、铁块电梯和两件建造道具。

**推荐建造世界**：「梦始之空」，奇幻地形。

## 建材兑换

建材兑换与兑换货币由[方块银行](/features/block-bank)统一处理。常用建筑材料可以在那里低价取得，多余材料也能换成交换价值。

## 盔甲架编辑器

制作各种盔甲架展示。

- Java 版：蹲下加右键。
- 基岩版：蹲下加长按。

可调整的项目：大小、姿势、无敌、发光、隐形、放置物品。

## 铁块电梯

在铁块上垂直移动。

- 两格最大间距：14 格。
- 跳跃上升，蹲下下降。

## 便捷道具

### 抹刀

抹刀用于铺设随机渐变的方块小路。右键从背包随机放置方块。

右键可在四种材料来源之间切换：

- 快捷栏
- 背包第一行
- 背包第二行
- 背包第三行

基岩版不支持切换材料来源。

### 锉刀

锉刀调整方块的形态，效果与调试棒类似。

- 操作：右键墙壁、栅栏、玻璃、楼梯等方块。
- 效果：改变方块形态。
