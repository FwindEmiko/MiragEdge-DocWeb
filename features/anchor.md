# 星辉锚点

星辉锚点保存你常去的位置，并提供玩家之间的传送请求。

## 家园：自己的落脚点

- 输入 `/sethome <名称>` 保存当前地点。
- 输入 `/home [名称]` 返回指定家园，不填名称时打开列表。
- 输入 `/homes` 查看自己的家园。
- 输入 `/delhome <名称>` 删除不再使用的家园。

第一次设置时，站在真正想保存的位置再执行命令。家园名称用容易记忆的短名称，例如 `base`、`mine` 或 `shop`。

## 公共锚点：前往大家常用的位置

- 输入 `/warp [名称]` 前往公共锚点。
- 输入 `/warps` 浏览公共锚点。

获得公开名额后，可以把家园发布为公共锚点：

- 输入 `/publish <家园名> [显示名] [费用]` 发布家园。
- 输入 `/unpublish <家园名>` 取消公开锚点。

公开名额默认是 0，已有的公共锚点可以正常浏览。

## 和朋友集合

- 输入 `/tpa <玩家>` 请求传送到对方。
- 输入 `/tpahere <玩家>` 请求对方传送到你这里。
- 输入 `/tpaccept [玩家]` 接受请求。
- 输入 `/tpdeny [玩家]` 拒绝请求。
- 输入 `/tpaui` 打开传送请求管理界面。

## 当前规则

| 项目 | 当前规则 |
| --- | --- |
| 默认家园数量 | 1 个 |
| 家园名称长度 | 最多 16 个字符 |
| 不能设置家园的世界 | PVP 世界 |
| 传送冷却 | 5 秒 |
| 传送预热 | 3 秒 |
| 预热期间移动或受伤 | 会取消传送 |
| 创建第一个家园 | 350 灵叶 |
| 额外家园 | 每个额外增加 300 灵叶 |
| 删除家园 | 按当前规则返还 60% |
| TPA 请求有效期 | 60 秒 |
| TPA 成功费用 | 100 灵叶 |

传送成功后会出现短暂的缓慢和失明效果。这是传送的固定代价，不是传送失败。

::: tip 战斗中不能靠传送脱身
预热期间移动或受到伤害都会取消传送。
:::

## 常见问题

### 为什么 `/sethome` 失败？

先确认当前世界不是 PVP 世界，再检查是否已经达到家园数量上限。

### 传送时能不能走动？

不能。预热期间移动或受到伤害都会取消传送。

### 基岩版能不能用？

核心功能与 Java 版一致。Java 版使用菜单，基岩版使用对应表单；按钮布局差异见[基岩版兼容说明](/start/bedrock)。
