# 方块银行

方块银行把暂时用不上的基础材料转成交换价值，再用这些价值兑换或购买已经开放的物品。箱子里的多余材料因此有了去处。

它的常用货币是**块币**。

## 操作入口

- 输入 `/emcshop purchase` 查看商店和可购买内容。
- 输入 `/emcshop view` 预览物品和价格。
- 输入 `/emcshop convert` 把背包里的材料转成交换价值。
- 输入 `/emcshop item` 查看手持物品的价值。

## 第一次使用

1. 打开预览，确认目标物品是否已经解锁以及需要多少交换价值。
2. 查询手中材料的价值，不要直接把仍有用途的材料全部转换。
3. 确认数量和结果后再执行转换或购买。

## 当前规则

- 物品价值不是按现实价格计算，而是服务器为生存资源设定的统一交换值。
- 购买时存在 **3.8%** 的损耗，确认前先看界面显示的最终到账数量。
- 部分物品也可以使用灵叶支付，商店页面会标出每件物品使用的货币。

## 转换前要确认的事

- 已经确认的交易不能当作临时仓库。
- 看不到某个物品时，先确认它是否已经解锁，或是否在当前价值表内。
- 价值表与可购买内容由服务器控制，不是所有物品都能无限互换。

## 常见问题

### 转换后能反悔吗？

转换前先用预览和物品价值查询确认。转换完成后，材料不会自动退回。

### Java 和基岩版操作一样吗？

功能目标相同，菜单样式不同。基岩版的按钮布局和输入方式见[基岩版兼容说明](/start/bedrock)。
