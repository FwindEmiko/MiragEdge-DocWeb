# 战利品与探索区域

探索箱为每位玩家分别保存一份战利品，区域规则则把安全区、自由生存区和高风险探索区分开。你可以放心探索，但不要把会被重置的区域当作长期仓库。

::: tip 先记住

- 关箱后，自己还没有取完的内容会保留，下次可以继续领取。
- 箱子附近的粒子和区域进入提示只是辅助信息；不确定时，以聊天提示、实际开箱结果和 `/hfcl zone` 查询为准。
- 探索重置前，先取走箱中物品，并把自己的物品放进安全的私人仓储。

:::

## 这套规则想解决什么

战利品箱的核心是“同箱不同份”：同一个探索箱可以让不同玩家各自完成一次探索，不会因为别人先开过就直接失去自己的内容。

区域规则负责让风险提前可见：主城区保护日常活动，缓冲区给新玩家一个过渡，常规生存区适合长期建设，探索重置区则把新地形和新战利品留给愿意承担风险的玩家。

## 一次完整的探索流程

1. 找到自然生成的探索箱并打开。
2. 看到的内容属于你自己；其他玩家打开同一个箱子时，会看到自己的内容。
3. 取走想要的物品后再关箱。没有取完的内容会留在你的探索记录中。
4. 如果想把私人物品暂时放进箱子，系统会提醒你：刷新或永久拆除时，这些物品可能一起消失。可以放入，但不要把它当作保险箱。
5. 遇到有限名额探索箱时，先确认自己是否已经领取过，不要把“名额”理解成箱子保护。

## 箱子附近的状态提示

粒子只会在箱子附近约 3 格内显示，属于近距离辅助提示，不是全图标记，也不是物品保管承诺。

| 颜色 | 可以理解为 |
| --- | --- |
| 绿色 | 你还没有领取这份个人内容 |
| 青色 | 已有个人记录，可能有未取物品 |
| 紫色 | 这是有限名额探索箱，目前仍有领取名额 |
| 红色 | 有限名额已经用完，后来者无法领取 |

没有看到粒子时，不代表附近没有箱子；粒子也不会替代区域提示和世界边界警告。

## 有限名额探索箱

部分高价值探索箱采用有限领取名额：**每个箱子最多由 3 位不同玩家领取一份内容**。达到名额后，后来者无法继续领取。

这项限制只针对领取名额，不是防破坏保护：

- 名额用尽只代表无法领取，不会把箱子锁定成特殊保护方块。
- 已经领取过名额的玩家，仍然可以查看自己尚未取完的专属内容。
- 有些与独特首领挑战绑定的高价值箱，仍按原本的宝箱方式处理，不属于上面的个人战利品箱。

## 破坏箱子前先看提示

### 普通可刷新箱

普通自然战利品箱被玩家首次破坏时，会先拦截这次破坏并提醒你。**10 秒内对同一个箱子再次破坏**，才会确认永久移除。

确认永久移除后：

- 箱子不会再按普通可刷新箱处理；
- 该箱子所有玩家尚未领取的个人内容会被清掉；
- 箱子里暂存的私人物品也可能一起丢失。

第一次提示后不再破坏，箱子会继续留在原处；永久移除后不会自行恢复。

### 爆炸和火灾

如果箱子被爆炸或火灾破坏，它可能失去系统接管，之后不会自动回来。重要箱子附近不要依赖爆炸保护，也不要把它当作会自我修复的容器。

有限名额探索箱的领取限制与箱子破坏是两套规则；看到“名额已满”只表示无法领取。

## 四类区域

主世界和下界都以 **0,0** 为中心，按方形边界从内向外划分。判断时看 X、Z 坐标中离 0 更远的那一边，所以四个角属于外侧方形范围，不是圆形半径。

下表是主世界坐标范围。下界的区域查询和保护以你在下界的实际坐标为准；不要用主世界坐标换算来猜测当前区域，直接使用 `/hfcl zone` 确认。

在下界，区域提示、保护和 `/hfcl zone` 会按下界自身坐标直接判断这四段范围；这些数字不要再额外除以 8。

| 区域 | 主世界范围 | 玩家能感受到的规则 |
| --- | --- | --- |
| 主城区 | 0 - 800 格 | 普通玩家不能破坏、放置、使用容器或进行 PVP；爆炸破坏、火焰蔓延、液体流动等环境改动也会受保护。 |
| 缓冲保护区 | 800 - 1600 格 | 累计在线时间超过 40 小时后，才可进行正常建造和使用容器；未达到门槛时相关操作会被拦截。 |
| 常规生存区 | 1600 - 400384 格 | 适合自由生存、建设和探索；箱子仍按战利品规则处理。 |
| 探索重置区 | 400384 - 500000 格 | 可以探索和建设，但地形、箱子记录和未领取内容可能随管理员安排的重置刷新。 |

当前定时重置方案没有启用，服务器可以在需要时开启定时方案，但当前主要由管理员安排，并以服务器公告为准。

## 世界边界与越界风险

主世界和下界的中心都是 **0,0**，外围有原版红色世界边界：

- 靠近边缘时会出现原版警示；
- 越过边界后会受到原版边界伤害；
- 下界的红色世界边界按 1:8 缩小，不要把主世界坐标直接套到下界；
- 进入探索重置区不代表可以无限向外探索，边界前要留出余量。

::: warning 下界的两类范围不要混淆

区域提示与保护按当前世界坐标判断；红色世界边界和主世界/下界重置范围才按 1:8 对应。探索时以游戏内提示和 `/hfcl zone` 查询为准。

:::

末地不套用这四类区域保护提示，也不使用这面红色世界边界墙。末地的刷新由末地外岛规则单独处理。

## 刷新和重置会影响什么

刷新与重置都由管理员发起，玩家不需要也不能通过本页的查询命令触发它们。

### 战利品刷新

管理员可以单独刷新某些箱子、范围或全服的个人战利品。刷新通常不改变箱子所在的地形，但受影响玩家的未领取内容会被清掉，下次打开时重新生成一份新的内容。

因此，看到刷新通知后应先取走当前战利品；放在战利品箱里的私人物品也不保证保留。

### 主世界和下界重置

管理员确认后，主世界或下界探索重置会在**下次服务器重启**时执行；下界对应的重置范围按 1:8 缩小。受影响范围由管理员安排，具体区域和方位以公告为准。

重置可能带来这些结果：

- 探索重置区的地形重新生成，区域内的建筑、方块容器和地面掉落物不保证保留；
- 受影响箱子的个人探索记录会清空，未领取的内容会消失；
- 普通可刷新箱和有限名额箱需要按新地形重新探索，有限名额也会随对应记录刷新；
- 你的个人背包不是区域地形记录，但不要把物品放在会被重建的建筑、箱子或地面上；
- 如果你离线时位于受影响区域，重新上线时可能被送到安全位置。

管理员发起重置后，请尽快离开探索重置区，不要在其中存放唯一物品或建设不能接受丢失的设施。

### 末地外岛重置

末地外岛是独立的**即时重置**，不等待下次服务器重启：

- 末地主岛及其周边会保留；
- 外岛地形会重新生成；
- 外岛相关箱子的个人探索记录和有限领取名额会刷新；
- 外岛中尚未领取的个人内容会消失；
- 重置执行时，身处末地的玩家会先被送离末地。

之后再次前往外岛，就是一次新的探索。主岛、外岛和四类区域之间不要混用提示或风险判断。

## 你会看到的提示

- 跨过主城区、缓冲保护区、常规生存区或探索重置区时，会收到区域进入提示；
- 探索重置区会额外保留醒目的顶部风险提醒，离开后消失；
- 破坏普通可刷新箱时，第一次会收到二次确认提醒；
- 有限名额箱在名额用尽后会直接提示无法领取；
- 红色世界边界会用原版视觉提示和边界伤害提醒越界风险。

这些提示帮助你判断风险，但不会替你保存物品。重要物品仍应放在安全的私人仓储中。

## 玩家可用的查询命令

```text
/hfcl zone
```

查看自己当前所在的世界、坐标、区域名称、范围和简短规则说明。它只用于查询，不会刷新战利品，也不会触发任何重置。
