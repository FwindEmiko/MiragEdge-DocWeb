# 缚灵钢符

猪灵离开下界进入主世界后会逐渐僵尸化，变成僵尸猪灵而失去以物易物的能力。缚灵钢符可以永久固定猪灵，让它在主世界保持原形态，同时仍然支持以物易物——但会失去生物 AI，不再四处走动。

需要 **2 个铁锭** 和 **1 个下界之星**，在工作台中合成。产物外观为下界合金锄，带有自定义纹理。

## 使用方法

1. 将缚灵钢符拿在主手
2. 右键点击一只**未固化的猪灵**（非猪灵蛮兵、非僵尸猪灵）
3. 猪灵身上会浮现附魔粒子效果，表示固化成功
4. 固化后的猪灵不再僵尸化，也不会移动

## 固化效果

| 效果 | 说明 |
|------|------|
| 免疫僵尸化 | 在主世界不会变成僵尸猪灵 |
| 生物 AI 关闭 | 不再四处走动、不会主动攻击或逃跑 |
| 以物易物保留 | 仍可以右键给它金锭换取交换物 |
| 永久存在 | 不会因距离过远而消失 |
| 粒子标记 | 身上持续显示附魔粒子，便于辨认 |

## 注意事项

- 固化后的猪灵**无法恢复**，请谨慎操作
- 每只缚灵钢符只能固化一只猪灵，使用后消耗耐久
- 猪灵蛮兵无法被固化
- 固化猪灵不会影响其他猪灵的正常行为

> 适合在主世界建立固定的以物易物交易站——把猪灵固定在一个位置，随时可以丢金锭换取物资。
