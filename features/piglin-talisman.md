# 缚灵钢符

猪灵离开下界进入主世界后会逐渐僵尸化，变成僵尸猪灵并失去以物易物的能力。缚灵钢符永久固定猪灵，让它在主世界保持原形态并保留以物易物，但不再四处走动。

需要 **2 个铁锭**和 **1 个下界之星**，在工作台合成。产物外观为下界合金锄，带有自定义纹理。

## 使用方法

1. 将缚灵钢符拿在主手。
2. 右键点击一只**未固化的猪灵**。
3. 猪灵身上浮现附魔粒子，表示固化成功。
4. 固化后的猪灵不再僵尸化，也不会移动。

猪灵蛮兵和僵尸猪灵不能用缚灵钢符固化。

## 固化效果

| 效果 | 说明 |
| --- | --- |
| 免疫僵尸化 | 在主世界不会变成僵尸猪灵 |
| 停止移动 | 不再四处走动，不会主动攻击或逃跑 |
| 保留以物易物 | 右键给它金锭可以换取交换物 |
| 永久存在 | 不会因距离过远而消失 |
| 粒子标记 | 身上持续显示附魔粒子，便于辨认 |

固化后的猪灵无法恢复，请谨慎操作。每只缚灵钢符只能固化一只猪灵，使用后消耗耐久。

固化一只猪灵不会影响其他猪灵的正常行为。

适合在主世界建立固定的以物易物交易站：把猪灵固定在一个位置，随时可以丢金锭换取物资。
