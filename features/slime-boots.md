# 史莱姆靴

> 弹哪儿着陆哪儿，妈妈再也不用担心我摔死了！

## 基本属性

| 属性 | 数值 |
|------|------|
| **护甲** | 1 点 |
| **耐久** | 91 |
| **修复材料** | 粘液球 |
| **特殊效果** | 弹跳落地、免疫摔落伤害、降低地面摩擦 |

## 获取方式

在工作台中使用粘液球和粘液块合成即可获得。

## 使用提示

- 穿戴上后，从高处落下不再受伤，落地时会弹跳一下
- 地面摩擦力降低，在冰面上会滑得更远
- 耐久耗尽后可在铁砧上用粘液球修复

## 常见问题

### 基岩版能用吗？

可以。基岩版玩家也能正常穿戴和弹跳，纹理和功能均已完成适配。
