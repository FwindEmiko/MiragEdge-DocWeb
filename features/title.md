# 称号与入服消息

称号放在聊天身份前，入服消息决定你进出服务器时的展示。两者都只影响展示，不提高攻击、防御或资源产量。

## 称号：拥有和佩戴

- 输入 `/mt` 打开称号主界面。
- 输入 `/mt shop` 查看称号商城。
- 输入 `/mt storage` 查看已拥有的称号。
- 输入 `/mt equip <ID>` 装备指定称号。
- 输入 `/mt unequip` 卸下当前称号。

只想创建自己的文字称号时，输入 `/mt custom <内容>` 提交。

创建前先确认文字长度和当前账号可用的称号券。自定义称号最长 12 个字符。

拥有和装备是两件事：可以保留多个称号，同时只装备其中一个。

## 入服消息：选择现在展示的内容

- 输入 `/mtmessage` 打开入服消息展示台。
- 输入 `/mtmessage equip <ID>` 装备入服消息。
- 输入 `/mtmessage unequip` 恢复默认消息。

展示台会区分已解锁和未解锁内容。未解锁的消息需要先完成对应条件。

默认入服消息为 `[+] 玩家名`，默认退服消息为 `[-] 玩家名`。装备其他消息后才会替换它们。

## 当前规则

- 称号相关消费使用服务器经济余额。
- 自定义称号、单色升级和渐变升级各消耗 1 张对应称号券。
- 称号券的剩余数量显示在称号商城界面里。
- 在线时间达标后，解锁状态在下一次检查时更新。

## 常见问题

### 为什么我拥有称号但聊天里没有显示？

先打开仓库选中称号并装备，再检查客户端是否已经重新进入服务器。

### 为什么不能创建彩色称号？

彩色或渐变属于升级能力，需要对应的升级券。

### Java 和基岩版界面一样吗？

功能目标相同，Java 版使用菜单，基岩版使用表单。按钮位置见[基岩版兼容说明](/start/bedrock)。
