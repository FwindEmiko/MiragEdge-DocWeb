# 幻空翼

幻空翼消耗账号中的飞行时间，让你在符合规则的地点短暂飞行。时间余额、所在区域和高度都会影响能否起飞。

## 先学会开启

- 输入 `/tf` 开启或关闭幻空翼。
- 输入 `/tf on` 开启幻空翼。
- 输入 `/tf off` 关闭幻空翼。
- 输入 `/tf time` 查看剩余飞行时间。

优先使用 `/tf`。`/tempfly` 和 `/tfly` 也可以使用；部分账号的 `/fly` 会被其他功能接管，不能作为固定入口。

有可用时间且当前位置允许飞行时，站在地面开启后双击跳跃即可起飞。在空中开启时，系统会尝试直接起飞。余额不足、处于战斗、进入禁飞地点、手持重锤或长矛、超过高度限制时都不能飞行。

## 飞行时间

飞行时间属于账号余额，上限默认是 24 小时。只有实际处于飞行中才会消耗。

站在地面、关闭幻空翼、乘坐载具、离线，或处于创造和旁观状态时不会扣除。

不同区域可以有不同规则，包括禁飞、不消耗时间、不同耗时倍率与速度限制。进入这些区域时，聊天栏或状态提示会给出当前规则。

## 别把开启状态当作保命

已经开启幻空翼但还没有实际起飞时，从高处跌落会正常受到摔落伤害。停止实际飞行后也一样。

主动关闭、武器限制、进入区域限制或长时间无操作而结束飞行时，有一次短暂的安全降落缓冲。

时间耗尽、进入战斗或超过高度限制而中断时，没有这层缓冲。起飞前先确认剩余时间和下方落点。

## 高度与提示

高度上限默认是 Y=320。超过后停止飞行。降回限制高度之内并满足其他条件后，可以再次使用。

末地外岛不在默认禁飞范围内。

飞行时间显示在快捷栏上方，剩余时间较少时会额外提醒。

- 输入 `/tf trails` 选择或移除飞行轨迹。
- 输入 `/tf display on` 或 `/tf display off` 控制时间显示。
- 输入 `/tf speed <数值>` 调整飞行速度；输入 `/tf speed reset` 恢复默认值。所在区域的速度上限优先。

## 转赠时间

输入 `/tf pay 玩家名 30m` 可以把飞行时间转赠给其他玩家。

时长支持秒、分、时、天及组合写法，例如 `30s`、`30m`、`2h`、`1d` 或 `1h30m`。

## 常见问题

### 为什么开启后飞不起来？

先输入 `/tf time` 确认余额。再检查是否处于战斗、手持重锤或长矛、超过高度限制，或进入禁飞区域。

### 为什么飞行突然结束，还摔伤了？

时间耗尽、进入战斗和超过高度限制导致的中断没有安全降落缓冲。主动关闭、武器限制、区域限制和长时间无操作有短暂保护，但仍应在安全高度操作。

### 为什么时间没有减少？

只有实际飞行时才会消耗。站在地面、关闭幻空翼、乘坐载具或离线时不会扣除。

::: warning 战斗中的飞行限制
持重锤或长矛不能飞行，攻击或被攻击后也会暂时禁飞。完整规则见[飞行武器限制](/features/flight-guard)。
:::
