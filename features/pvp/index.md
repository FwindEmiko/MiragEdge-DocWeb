# 竞技系统总览

竞技系统提供单挑、团队竞技与饥饿游戏三种对战玩法。输入 `/fepvp` 打开竞技大厅，从大厅进入各玩法。

## 进入大厅

输入 `/fepvp` 打开竞技大厅。大厅里的按钮分别是：

- 单挑：进入单挑房间列表，支持免费与押注两种模式。
- 饥饿游戏：进入单人求生房间列表。
- 团队竞技：进入团队房间列表，支持 2v2、3v3 与 4v4。
- 快速匹配：自动创建一个随机竞技场的单挑房间。
- 排行榜、我的数据、装备库、观战：查询与浏览入口。

大厅会显示当前在线人数与正在进行的比赛场数。

## 单挑（1v1）

方式一：房间列表

1. 点击「单挑」，打开单挑房间列表。
2. 点击已有房间加入，或点击「创建房间」自建。
3. 创建房间时依次选择竞技场与装备，房间创建成功后等待对手。
4. 房间满 2 人自动开赛；房主也可以输入 `/fepvp room start` 手动开赛。

方式二：快速匹配

1. 点击「快速匹配」。
2. 系统自动创建一个随机竞技场的单挑房间。
3. 等待其他玩家加入。

## 团队竞技（2v2 / 3v3 / 4v4）

1. 点击「团队竞技」，打开团队房间列表。
2. 点击已有房间加入，或点击「创建房间」自建。
3. 创建房间时依次选择竞技场与装备。
4. 在队伍界面选择红队或蓝队加入，也可以输入 `/fepvp team join red` 或 `/fepvp team join blue`。
5. 队伍界面实时显示双方人数与成员。
6. 房主点击「开始比赛」，双方各至少 1 人即可开赛；房间满员后也会自动开赛。

## 比赛流程

1. 选择装备，限时 5 秒。
2. 倒计时 12 秒，期间不能移动和攻击。
3. 进入战斗，一方死亡或超时即比赛结束。
4. 结算 5 秒后，所有人传送回大厅。

单挑与团队竞技的超时时间为默认 800 秒。比赛中死亡后自动转为旁观状态。

## 如何选装备

比赛开始时系统打开「选择装备组合」界面。

1. 界面里列出适用于当前竞技场类型的装备组合。
2. 点击选择一个组合，5 秒后自动进入倒计时。
3. 没有选择的玩家使用默认装备。

组合按适用类型区分。单挑组合只在单挑房间出现，团队组合只在团队房间出现，通用组合在两边都出现。

饥饿游戏不使用装备组合，开局直接使用场地补给箱里的装备，详见[饥饿游戏](./hunger-games)。

## 背包保护与方块复原

比赛前系统会自动记录你的背包内容，比赛结束后按记录归还。中途断线重连后，系统会检测并恢复背包。

多数竞技场不允许破坏和放置方块。允许破坏与放置的场地会在赛后自动复原，并清理场地内的掉落物、箭矢和经验球。

## 观战

1. 在大厅点击「观战」。
2. 或输入 `/fepvp spectate <竞技场名>`。
3. 你会以旁观者模式传送到观战点。

输入 `/fepvp spectate` 或 `/fepvp leave` 退出观战。不是每个竞技场都开放观战。

## 离开房间与退出比赛

- 输入 `/fepvp room leave` 离开当前房间。
- 输入 `/fepvp leave` 离开当前比赛或退出观战。
- 房主离开房间时，房间自动转交给下一位玩家。
- 房间所有人离开后，房间自动解散。
- 比赛中退出视为投降，对手获胜。押注局中退出视为弃权。
