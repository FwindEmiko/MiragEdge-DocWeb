# 押注决斗

押注决斗是单挑专属玩法。建房时选择免费局或押注局，押注局由双方押上相同金额，胜者拿走押金池。

## 模式与货币

| 模式 | 说明 |
| --- | --- |
| 免费局 | 没有金钱往来，与普通单挑完全一致 |
| 押注局 | 双方对押，输家的押金归赢家 |

押金可以用**灵叶**或**星痕石**，在创建押注房时选择其中一种。

押金档位为 500、1,000、2,000、5,000、10,000、20,000。你也可以自定义金额，单方押金范围是 500 到 100,000。

## 资金流向

单方押金记作 X。

| 局终结果 | 你的押金 | 说明 |
| --- | --- | --- |
| 你获胜 | 收回双方押金，共 2X | 赢家拿走整个押金池 |
| 对手获胜 | 失去 X | 押金转给对手 |
| 平局 | 退回 X | 全额退还 |
| 开局前取消 | 退回 X | 比赛未开始，没有输赢 |
| 开局后退出或掉线 | 扣除 X | 视为弃权 |
| 服务器异常导致比赛未完成 | 退回 X | 重启后自动退还 |

## 创建押注局

1. 在大厅点击「单挑」，打开房间列表。
2. 点击「创建押注房间」。
3. 在创建界面选择货币与金额档位，然后完成建房。

也可以直接指定金额建房：输入 `/fepvp bet 2000` 以 2,000 灵叶创建押注房。输入 `/fepvp bet` 打开押注创建界面。

## 加入押注局

1. 点击押注房条目，进入二次确认界面。
2. 确认界面显示房主或对手、地图、装备、押金、胜者可得的金额，以及你自己的余额。
3. 确认无误后加入房间。

加入时会先检查余额。房间满员或房主开赛时，系统会再检查一次余额。

## 等待与锁定

- 等待界面中央显示当前的押金池总额。
- 房间满员或房主开赛后，双方押金自动锁定托管，界面会提示押金已托管。
- 开局前退出不扣款。

## 结算

| 结果 | 到账 |
| --- | --- |
| 获胜 | 押金池 2X |
| 失败 | 扣除押金 X |
| 平局 | 退回押金 X |
| 对手弃权 | 退回你的押金 X |
| 自己弃权 | 扣除押金 X |

结算瞬间就算你处于离线状态，金额也会到账。

押注局计入战绩与段位积分，但不发放[每日奖励](./ranking)。
