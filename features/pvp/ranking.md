# 段位与排行榜

每场比赛都会改变你的竞技积分，积分决定段位。这页说明 8 档段位、排行榜怎么看，以及每日奖励怎么发。

## 查看数据

- 在大厅点击「我的数据」。
- 或输入 `/fepvp stats` 查看自己的战绩。
- 或输入 `/fepvp stats 玩家名` 查看其他玩家。

战绩中包含当前积分、历史最高积分、胜场与段位。

## 段位档位

| 段位 | 积分区间 |
| --- | --- |
| 传奇 | 3000 起 |
| 宗师 | 2400~2999 |
| 大师 | 1800~2399 |
| 钻石 | 1200~1799 |
| 白金 | 700~1199 |
| 黄金 | 350~699 |
| 白银 | 150~349 |
| 青铜 | 低于 150 |

新玩家的初始积分是 100。

## 排行榜

1. 在大厅点击「排行榜」。
2. 排行榜分页显示名次、玩家、积分、胜场与段位。
3. 你自己的名次会单独标记出来。

排行榜按积分从高到低排列。

## 每日奖励

- 胜利或平局发放每日奖励，奖励包含星痕石与灵叶。
- 具体数量按段位权重与以弱胜强加成计算。
- 每日上限为星痕石 50、灵叶 10,000。
- 上限在每天凌晨 0 点刷新。
- 押注局不发放每日奖励。
