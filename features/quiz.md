# 知识问答

服务器会不定期向全服发出问题，你在聊天栏直接抢答即可。答对后获得经验、灵叶、星痕石和等级经验。

参与知识问答不需要装备，适合在整理背包、等待队友或探索间隙进行。

## 抢答步骤

1. 等待聊天栏出现新的问答消息。
2. 直接在聊天中发送答案，不需要额外命令。
3. 先答对的人获得奖励；同一题结束后等待下一题。

需要帮助时，输入 `/feabcq help` 查看当前问答的帮助说明。

## 当前规则

- 周期提问的间隔约为 15 分钟。
- 在线人数少于 4 人时不会触发周期提问。
- 答案不区分大小写。
- 答题模式会持续到下一题出现。
- 题目覆盖 Minecraft 知识、常识、科学、历史、数学和趣味内容。

## 常见问题

### 我答对了但没有奖励？

确认自己发送的是完整答案，并留意是否已经有人先答对。

### 为什么没有题目？

在线人数不足或上一题刚结束时，等待时间会更长。

### 基岩版可以参加吗？

可以。答题通过聊天完成，基岩版不需要额外安装 Java 专用内容。
