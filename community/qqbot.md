# 群服互通机器人

在 QQ 群里就能绑定游戏账号、转发服务器消息、查看自己的游戏数据。

<SmartImage
  src="/avatars/QQ的星玖.png"
  alt="狐魇星玖"
  caption="图 1：群服互通机器人狐魇星玖"
  maxWidth="180px"
/>

## 快速上手

在 QQ 群 **523914625** 内发送下面的指令：

| 你要做什么 | 发送指令 |
| --- | --- |
| 绑定游戏账号 | 进服务器获取验证码 → 群内发 `绑定xxxx` |
| 查看帮助菜单 | `菜单` |
| 和星玖聊天 | `@星玖` + 你想说的话 |
| 查自己信息 | `我的信息` |
| 发送群服消息 | `#` + 你要说的话 |

## 绑定管理

绑定需要先在游戏内拿到 4 位验证码，再回群发送绑定指令。完整步骤见[账号绑定](/start/account)。

### 解绑

在原绑定群内发送：

```
解绑
```

## 聊天对话

在群聊里 @ 星玖即可触发对话。她会回复简单的日常对话和游戏相关问题。

## 群服消息互通

## 背包预览

在群内查看**自己**的背包物品，以渲染图片呈现。

**指令：**

```
我的背包
```

## 末影箱预览

查看**自己**末影箱中的全部物品，以渲染图片展示。无论在线与否都能查询。

**指令：**

```
我的末影箱
```

支持 54 格的大末影箱。

## 潜影盒预览

查看**自己**背包中潜影盒内的物品。

**指令：**

```
我的盒子
```

背包中有多个潜影盒时，机器人会列出全部潜影盒供你选择：

- **不超过 10 个**：可以点击表情或发送数字序号选择。
- **多于 10 个**：只能发送数字序号选择。

支持显示铁砧重命名后的自定义名称，也支持 54 格的大潜影盒。

## 解封申诉

在游戏内因违规被封禁时，解封需要**私聊服主申诉**（群内解封指令已停用）。

私聊服主 QQ：2011857087，发送被封的游戏 ID 并说明解封理由。管理员审核后，会在 2 个工作日内反馈。

## 注意事项

- 不要把绑定验证码告知他人。
- 排行榜数据尽可能实时更新。
- 背包、末影箱、潜影盒的渲染图片需要几秒生成时间。
