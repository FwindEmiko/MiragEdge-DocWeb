# 常见问题

下面列出玩家最常遇到的 5 个问题。先按对应条目处理，仍未解决时再在群内求助。

## 无法连接服务器

1. Java 版 确认地址是 `mc.miragedge.top`；基岩版确认地址是`be.miragedge.top`，端口是 `52051`。
2. 确认客户端版本符合[客户端安装](/start/install)页面的要求。
3. 确认自己的账号已经完成绑定。

仍然连不上时，重新阅读一遍[连接服务器](/start/join)。

## 进服后被踢出

首次进入服务器会被踢出一次，并弹出绑定提示框。

这是绑定流程，不是故障。记下提示框里的 4 位验证码，按[账号绑定](/start/account)在群内发送绑定指令，之后即可自由进出。

## 基岩版界面或操作异常

基岩版与 Java 版互通，下面这些差异属于已知限制：

- 弓、弩、三叉戟、钓竿、翅膀、盾牌换上自定义外观后会失去部分功能。
- 部分自定义模型和方块不可见。
- 只支持左键或长按；含交互提示的消息无法点击。
- 部分盔甲显示为默认铁盔甲外观。

完整清单见[基岩版兼容](/start/bedrock)。

## 群内查询没有返回结果

1. 确认已经完成账号绑定。
2. 确认指令写法与[群服互通机器人](./qqbot)页面一致。
3. 背包、末影箱、潜影盒的渲染图需要几秒生成，稍等再查。

个人数据需要游戏端成功登录后才会更新。

## 仍无法解决

在[玩家交流群组](./groups)内求助。说明客户端版本、所在世界、现象截图和已经尝试过的操作，可以明显缩短排查时间。
