# DragonMiao 使用文档

DragonMiao 是面向长期生存服的末影龙生态插件。它会记录每个末地世界的龙战状态与历史，在击杀后生成可追溯的龙蛋，并向 Java 与基岩版玩家发送适配后的龙战消息。

## 功能概览

- 跟踪末影龙复活、存活时长、击杀者与击杀记录；重启后会恢复并校正状态。
- 新末地世界的首条龙会从首位玩家进入末地开始计时，并发送单独的首龙消息。
- 末影龙死亡后在出口传送门上方掉落龙蛋；前若干枚可显示为带编号与战绩的特殊龙蛋。
- 多个末地世界独立统计龙战与龙蛋，服务器全局编号连续累加。
- 提供复活、击杀和龙蛋掉落消息与音效；安装 Floodgate 时自动为基岩版玩家使用适配消息。

## 环境与安装

| 项目 | 要求 |
| --- | --- |
| 服务端 | Paper 1.21+ 或其兼容分支 |
| Java | 使用目标 Paper 版本要求的 Java 运行时 |
| 可选依赖 | Floodgate，用于基岩版消息适配 |
| 存储 | 本地 YAML 文件，无需数据库 |

1. 将 `DragonMiao` 的 JAR 放入服务器 `plugins/` 目录。
2. 启动服务器，确认已生成 `plugins/DragonMiao/config.yml` 与 `data.yml`。
3. 按需修改配置中的消息、音效和龙蛋样式。
4. 使用 `/dragonmiao reload` 重载配置，或重启服务器后确认效果。

DragonMiao 使用 Paper 1.21+ 的 API，不支持 Spigot 或 CraftBukkit。不要在服务器运行时手动编辑 `data.yml`；需要调整玩法时编辑 `config.yml`。

## 配置要点

| 区域 | 用途 |
| --- | --- |
| `enabled` | 插件总开关 |
| `egg` | 普通龙蛋数量、前若干枚特殊龙蛋的名称与掉落偏移 |
| `messages` | 复活、击杀、首龙和龙蛋掉落消息；可分别设置 Java 与基岩版文案 |
| `sounds` | 复活、击杀、掉落和重载提示音的名称、音量与音调 |
| `storage` | 数据文件名与首龙兜底记录开关 |

特殊龙蛋默认从全服编号靠前的龙蛋开始生成，带有龙蛋编号、击杀者、时间和首龙标记。普通龙蛋数量、特殊龙蛋数量及其名称都由 `config.yml` 决定。

## 命令与权限

主命令为 `/dragonmiao`，可使用别名 `/dm`。

| 命令 | 默认权限 | 说明 |
| --- | --- | --- |
| `/dragonmiao reload` | 管理员 | 重载 `config.yml`，不重置记录 |
| `/dragonmiao stats [world]` | 所有玩家 | 查看全服或指定末地世界的龙、龙蛋与近期击杀记录 |
| `/dragonmiao egg [index]` | 管理员 | 获取指定编号的龙蛋，用于检查样式与掉落 |
| `/dragonmiao reset ` | 管理员 | 重置指定世界数据；需要在 30 秒内再次确认，全服编号不受影响 |

管理员命令分别由 `dragonmiao.admin` 控制；统计查询由 `dragonmiao.stats` 控制；`dragonmiao.notify` 控制龙战广播与音效接收。默认配置中，统计与通知对普通玩家开放。

## 世界与数据

每个末地世界独立保存龙计数、龙蛋计数、当前存活状态、首入末地记录和击杀历史；额外的末地维度可以正常参与追踪。全服龙蛋编号与全服龙计数跨世界连续，用于确保特殊龙蛋不会重复编号。

对于已经有过击杀记录的服务器，DragonMiao 首次启动会识别既有末地状态并初始化记录，避免把旧世界误判为从未挑战过首龙。

## 日常检查与排错

- 收不到基岩版适配消息：确认 Floodgate 已启用；未安装 Floodgate 时，所有玩家会收到 Java 版文案。
- 龙战在异常重启后显示不一致：重启完成后插件会扫描末地内是否仍有末影龙并校正状态；再次复活或击杀前可用 `/dm stats` 查看记录。
- 龙蛋没有出现在预期位置：检查出口传送门上方是否有可用空间，以及 `egg.drop-offset` 的偏移配置。
- 多末地世界数据混淆：每个世界均独立记录；使用 `/dm stats ` 指定世界核对。
