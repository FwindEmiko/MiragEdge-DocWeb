# 主城共建

新服的出生点范围就是主城区，没有预建好的主城。这页说明怎么参与建造、怎么拿到块币补贴，以及建设时需要遵守的规则。

## 为什么是共建

新服取消了独立的主城世界，出生点范围被划为主城区。相比「管理员建好再开放」的旧模式，共建让主城从第一天起就有玩家的痕迹。商店街、广场、车站、地标建筑，都由大家亲手完成。

主城建设是长期规划：早期建设决定主城骨架，后续慢慢填充细节。

## 怎么参与

1. 进入主城区，找到当前规划中的建设区域。
2. 按规划风格建造，或在指定地块内自由发挥。
3. 完成建造后，按群内公示的方式申报，领取方块银行「块币」补贴。

::: tip 块币是什么
块币是[方块银行](/features/block-bank)使用的货币，用来在方块银行兑换建筑方块。建设、补贴、建材、继续建设，形成循环。
:::

## 建设守则

- **跟随规划**：主城有整体分区，例如商业区、休闲区、交通枢纽。先确认自己的地块属于哪个区。
- **风格协调**：贴合该区域的规划风格；拿不准时，先搭小样给管理员过目。
- **不占公共通道**：道路、广场、传送点周边保持通畅，给公共设施留位置。
- **不越界**：只在自己分配的地块内建造，不覆盖他人作品。

## 常见问题

### 我没有建筑经验，能参与吗？

可以。主城也需要商店、仓库、车站这类功能性建筑，不全是「好看」的建筑。先从小地块、功能性建筑开始，熟悉后再挑战地标。

### 我在主城建的房子会被重置吗？

不会。主城区属于保护区，不会被探索重置区刷新。公共主城属于全体玩家，管理员保留调整影响公共体验的建筑的权利。
