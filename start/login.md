# 登录与注册

第一次进服务器要先注册一个账号，之后每次进服用同一个账号登录。

  src="/images/start/login/register-login-flow.svg"
  caption="图 1：注册与登录——第一次进服先注册，之后每次进服登录，忘密码可走邮箱找回"
  width="720"
/>

## 第一次进服：注册

1. 启动客户端并连接服务器，你会先进入一个等待区，暂时看不到主城。
2. 在聊天框输入 `/register 密码 密码`，两个密码要完全一致。
3. 系统提示注册成功，随后把你送入主城。

## 以后进服：登录

1. 连接服务器后仍在等待区。
2. 在聊天框输入 `/login 密码`。
3. 系统提示登录成功，把你送入主城。

## 忘密码：用邮箱找回

前提是你已经绑定过邮箱。没绑邮箱时，只能请管理员帮你重置。

1. 输入 `/hfc setemail 你的邮箱` 绑定邮箱。
2. 到邮箱里收验证邮件，输入 `/hfc verifyemail 邮件里的验证码`。
3. 输入 `/hfc resetpassword 新密码` 设置新密码。

## 改密码

在游戏内输入 `/hfc pass-change`，按提示输入当前密码和新密码。

## 关于密码

| 项目 | 说明 |
| --- | --- |
| 长度与复杂度 | 服务器内置弱密码黑名单，过于简单的密码会被拒绝，换一个更复杂的 |
| 大小写 | 区分大小写，输入时注意大小写锁定 |
| 保存 | 自己记住密码，服务器无法告诉你原密码 |

## 不用重复登录的情况

| 情况 | 表现 |
| --- | --- |
| 同一网络、短时间重连 | 在一段时间内免登录，直接进服 |
| 使用正版账号 | 打开正版自动登录后，正版账号进服免输密码 |
| 手机版（基岩版） | 基岩版玩家跳过登录流程 |

打开正版自动登录的方法：输入 `/hfc premium`。

## 常见问题

**进服后被踢出，提示要登录。**
这是正常流程。在等待区聊天框输入 `/login 密码` 就能进主城。

**忘记密码，也没绑过邮箱。**
联系管理员重置。解封与账号类问题只走私聊服主 QQ，见[玩家守则](/start/rules)。

**输入 `/login` 没反应。**
确认你已经注册过。没注册过先打 `/register 密码 密码`。

**换了电脑或换了网络要重新登录吗。**
要。免登录只在同一网络的短时间内有效。
