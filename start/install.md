# 客户端安装指南

服务器当前版本：`26.2`。

::: tip 选择哪个版本
基岩版与 Java 版在同一个服务器里游玩，但部分界面和操作方式存在差异。第一次游玩或需要完整操作时，优先使用 Java 版。
:::

## Java 版

### 电脑端

1. 进入交流群文件，找到「Java启动器资源」文件夹。

<SmartImage
  src="/images/JEGameFile.png"
  alt="Java 版群文件目录"
  caption="图 1：交流群文件里的「Java启动器资源」文件夹"
/>

2. 下载该文件夹中的启动器安装包。
3. 首次运行启动器：
   - 创建纯英文命名的文件夹（推荐路径：`D:\Minecraft`）。
   - 把启动器文件解压到该文件夹。
   - 双击启动器，等待自动完成初始化。
   - 完成引导设置，登录正版或离线账户。

<SmartImage
  src="/images/NewText.png"
  alt="新建文件夹"
  caption="图 2：新建纯英文文件夹，把启动器解压进去"
/>

4. 下载游戏本体：
   - 点击启动器顶部的「下载」。
   - 选择正式版（推荐 `26.2`）。
   - 保持默认安装配置，安装完成后启动游戏。

::: warning 提示缺少 Java 运行环境
下载交流群文件中的 Java 运行环境安装包，并完成安装。
:::

::: tip Mac 系统
使用交流群文件中的 Mac 版启动器。
:::

### 手机端

仅针对安卓用户，iOS 没有 Java 版的便捷安装方案。

1. 下载交流群文件中的安卓 Java 启动器安装包。
2. 解压文件，完成启动器安装。
3. 打开启动器，依次完成下面三项：
   - 安装游戏文件。
   - 下载 `1.21.x` 游戏本体。
   - 选择离线登录模式完成登录。

## 基岩版

### 电脑端

仅支持通过微软商店购买正版，没有其他安装途径。

### 手机端

#### 安卓用户

1. 进入交流群文件，找到基岩版安装包所在的文件夹。
2. 也可以从 [MCDL 下载站](https://mc.minebs.com/) 获取安装包。
3. 下载 `MCBE-1.21.xx.zip` 安装包。
4. 使用压缩工具解压文件，完成安装。
5. 登录微软账户。

<SmartImage
  src="/images/web_image/msreg/tutorial/BEGame.png"
  alt="基岩版群文件目录"
  caption="图 3：交流群文件里的基岩版安装包目录"
/>

#### iOS 用户

1. 获取外区 Apple ID。
2. 通过充值卡购买正版游戏。

::: tip 通用提示
低版本基岩版客户端支持覆盖更新。苹果手机基岩版长时间不更新时，可能出现登录异常。
:::

## 微软账户注册

**必备材料**：

- 有效邮箱或手机号
- 连通国际互联网

::: warning 注意
所有年龄选项必须填写已成年，否则游戏会出现各种奇怪的限制
:::

### 游戏内注册

1. 进入游戏，在游戏主界面点击设置。

<SmartImage src="/images/web_image/msreg/tutorial/msreg1.png" alt="游戏主界面设置入口" caption="图 4：在游戏主界面点击「设置」" maxWidth="400px" />

2. 点击「通用」中的「档案」部分。

<SmartImage src="/images/web_image/msreg/tutorial/msreg2.png" alt="通用设置中的档案" caption="图 5：在「通用」里找到「档案」部分" maxWidth="400px" />

3. 进入档案设置后，点击「免费」注册。
4. 开启「使用移动数据」选项，避免另外一些问题。

<SmartImage src="/images/web_image/msreg/tutorial/msreg3.png" alt="免费注册与使用移动数据" caption="图 6：点击「免费」注册，并开启「使用移动数据」" maxWidth="400px" />

5. 点击免费注册后，会弹出一个提示框；没有弹窗时跳过这一步。
6. 选择「保存至 Microsoft 账户」。

<SmartImage src="/images/web_image/msreg/tutorial/msreg4.png" alt="保存至 Microsoft 账户" caption="图 7：弹窗选择「保存至 Microsoft 账户」" maxWidth="400px" />

7. 进入登录界面后点击登录。已有账户直接登录，没有账户按提示注册。

<SmartImage src="/images/web_image/msreg/tutorial/msreg5.png" alt="登录界面" caption="图 8：在登录界面登录已有账户，或按提示注册" maxWidth="400px" />

### 网页注册

1. 浏览器访问[微软官网](https://account.microsoft.com/)。
2. 点击右上角头像图标。
3. 选择「创建账户」，按引导完成注册。

<SmartImage src="/images/web_image/msreg/tutorial/msreg6.png" alt="创建账户" caption="图 9：在微软官网点击头像，选择「创建账户」" maxWidth="400px" />

客户端装好后，继续看[连接服务器](/start/join)。
