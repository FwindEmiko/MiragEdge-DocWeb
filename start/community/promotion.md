# 宣传支持

::: tip 一点点支持就够了

新服开荒期，服务器最缺的不是玩法，是"让更多人知道它"。

如果你愿意帮锐界幻境做宣传，非常感激——不要求专业，也不要有压力，选择你舒服的方式就好。

:::

## 最简单的方式：转发与邀请

- 把新服公告页面分享给喜欢 MC 的朋友，介绍锐界幻境的核心特色
- 在 QQ 空间、朋友圈、游戏群里转发开服消息
- 邀请认识的朋友一起入服——生存游戏人多才热闹

不需要配图、不需要写文案，一次转发就是帮助。

## 有精力的话：内容创作

如果你喜欢录视频、写图文，可以做：

- **入服实况**：新玩家视角记录第一天的体验
- **玩法介绍**：介绍某个你喜欢的功能（附魔、钓鱼、星辉锚点等）
- **建筑展示**：主城共建里你参与的建筑、你的基地
- **新手教程**：帮完全没接触过服务器的人快速上手

发布后可以把链接发到玩家群里，好的内容会得到群友和管理员的认可。

## 可以使用的素材

宣传时可以参考这些页面，它们都是公开信息：

- [开始游戏](/start/)：入服步骤与新玩家引导
- [生存玩法](/play/)：玩法总览
- [特色功能](/plugins/)：服务器专属玩法

::: tip 宣传时请这样做

- 客观介绍，不要夸大或承诺未上线的内容
- 素材以文档站为准，不确定的先问管理员
- 尊重其他玩家，不做拉踩其他服务器的事

:::

## 说明

宣传是自愿行为，服务器目前不设强制宣传任务，也不以宣传量作为入服或游戏权益的门槛。你的每一次分享，都是对新服的支持。

如果对宣传有任何想法或疑问，欢迎在玩家群里提出。
