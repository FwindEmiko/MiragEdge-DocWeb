# 玩家交流群组

按自己的目的加入对应群组。新玩家优先处理入服审核，再进入日常交流。

## 入服审核

[新玩家审核群](https://qm.qq.com/cgi-bin/qm/qr?k=tbtwjTewaVOjweHtzwTn34C_i8iIOyyO&jump_from=webapi&authKey=Kn7tHTIMbxnR2HCuDTbSAWDlvAyh/zwYX6uhCVQoMM3SdH9nsom4fKtvUYL/HUi4)用于入服咨询和审核结果反馈。

## 日常交流

[玩家一群](https://qm.qq.com/cgi-bin/qm/qr?k=qcqQFSg6RFm9RVobpbz1-7i6BPemTehu&jump_from=webapi&authKey=Uh0BellBFXLGxIRTXteUSZiJvG37RIDPK5lp2kjtXr9FTL38fCoMhjrici8WwHXj)是公告、日常交流和问题求助的主入口。

主群满员或暂时无法加入时，可进入[玩家二群](https://qm.qq.com/cgi-bin/qm/qr?k=Tz-88rQ0PNQn6DFOpB5Hz3Y9AHU_lHJX&jump_from=webapi&authKey=+vBvpdU5YqKUEFCKZeSw4c7d5fxq14W6BOjCCXSTaSoiR8//clWlKRqtDrrQ9oww)。

## 休闲聊天

[inpart 群](https://qm.qq.com/cgi-bin/qm/qr?k=-mJ4alsnYeVP3uLCcKAtmfAbbVswgW9w&jump_from=webapi&authKey=v4QUgQGNJy8hl25wFSJSTY4lL3uFOpFGDkpkKjgd4c+75zlfmGwuApN9xJ2zV/Jw)适合非服务器相关的日常聊天和交友。

## 加群前

请遵守群规并避免公开账号验证码、订单信息或其他个人数据。服主与开发人员的协作入口不放在玩家群组页面，相关资料请查看[开发者文档](/developer/)。
