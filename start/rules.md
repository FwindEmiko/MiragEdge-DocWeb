# 玩家行为守则

> 🦊 每一位玩家都应遵守的基本准则喵~

## 适用范围

本守则适用于锐界幻境 MC 生存服务器内**所有游戏行为**，以及官方 QQ 交流群、官方语音频道的**所有交流行为**，是所有玩家/群成员必须遵守的基本准则。

- **游戏内行为**：见下方「游戏内行为规范」
- **QQ 交流群**：见下方「QQ 交流群行为规范」
- **官方语音频道**：同样适用本守则中的禁止内容与文明交流底线

管理员将依据本守则公平处理违规行为。本守则会随运营需要调整，调整后将在服务器和群内公示，以最新公示内容为准。

::: tip 沟通建议（通用）

- 服务器建议/投诉请私聊管理员
- 与玩家产生争议优先私聊沟通，避免公开争吵
- 文明交流，共同维护友好游戏氛围

:::

## 游戏内行为规范

### 聊天与内容发布

**禁止内容**（含聊天发言、告示牌、书籍、物品命名、皮肤、建筑等所有传播载体）：

- 政治、色情、暴力、恐怖类文字/图像
- 纳粹符号、地域/性别/民族/宗教等歧视性言论
- 其他服务器的宣传、拉人、对比类内容

**限制行为：**

- 禁止无意义刷屏（连续 5 条及以上相同/重复消息）
- 禁止散布服务器关闭等虚假谣言
- 禁止泄露他人游戏 ID、手机号、住址、照片等隐私
- 禁止恶意引战、钓鱼（挑事、欺骗他人物资等）

### 核心游戏规则（严重违规，从严处理）

::: warning 说明

以下行为严重破坏游戏公平与服务器秩序，一经查实将**从严处理**：优先封禁相关小号，并对主号采取临时封禁（1-7 天）；多次违规或情节特别严重的，可升级至永久封禁。

:::

**作弊相关：**

- 使用飞行、加速、穿墙等作弊外挂/模组
- 启用矿透（X-ray）、生物雷达等透视工具
- 运行自动挖矿、打怪、挂机刷物等脚本/插件
- 使用含非法功能的修改版客户端

**财产与权益侵犯：**

- 盗取他人物资、装备、建筑
- 恶意破坏他人建筑、农田、红石机器、养殖生物
- 未经允许击杀他人生存用生物（村民、家畜等）
- 劫掠他人基地、放置陷阱等恶意攻击行为

**服务器环境破坏：**

- 放置高频红石、卡服机器导致服务器卡顿/崩溃
- 在主城/公共区域滥用爆炸物破坏环境
- 恶意制造区块卡顿、刷怪塔泛滥等影响服务器运行的行为

### 账号与多开管理（经济与公平类）

::: danger 重点提醒

**多开小号绕过经济限制属于严重违规，涉及的小号将一律封禁。**

:::

- 禁止为绕过商店每日购买/出售限额、每日任务、在线奖励等经济限制，注册或使用多个账号（多开小号）
- 禁止通过多开小号刷取灵叶、星痕石、块币等货币/物资后，转账、转移给主号或其他账号
- 禁止利用小号囤货、倒卖、垄断市场，或批量参与活动/比赛套取奖励
- 上述行为一经查实：**封禁全部涉及小号**，并回收违规所得（含已转移至其他账号的部分）
- 情节严重或多次违规者（如规模化刷取、倒卖牟利、扰乱市场秩序），将对关联主号采取临时封禁（1-7 天），直至转为永久封禁
- 亲友共用设备、Java/基岩双端互通等正常的同人多账号，如无经济滥用行为，不在此列；被误判可依本守则申诉

### 机器/设施使用规范

**跨维度大型设施：**

- 运行时必须有玩家值守，禁止无人挂机
- 需配置产物自动销毁/限制机制，避免物资泛滥
- 使用区块加载器强制加载区块必须在使用后关闭

**公共区域设施：**

- 使用公共传送、农田等设施后需保持整洁，禁止破坏

## QQ 交流群行为规范

### 发言与内容发布

**禁止内容**（含文字/图片/视频/链接）：

- 政治、色情、暴力、恐怖类内容
- 纳粹符号、地域/性别/民族等歧视性言论
- 低俗、恶心、血腥类图片/视频

**限制行为：**

- 禁止无意义刷屏（连续 5 条及以上相同消息）
- 禁止泄露群成员 QQ 号、手机号、照片等隐私
- 禁止恶意钓鱼、引战（挑事、欺骗他人等）
- 禁止宣传其他 MC 服务器/QQ 群/微信群，或私自拉人建群
- 禁止发布未经允许的广告、砍价、投票、拼单等链接
- 禁止散布服务器/群聊相关虚假谣言

**沟通建议：**

- 群内优先交流 MC 游戏相关内容，保持话题积极健康
- 群管理建议可私聊群主/管理员，理性反馈
- 共同维护整洁、友好的群聊环境

### 群内行为规范（违规移出/封禁）

**账号安全与骚扰类：**

- 盗用他人 QQ 账号在群内发布违规内容
- 利用漏洞批量加群成员为好友，或频繁私信骚扰
- 恶意举报群成员/群聊，干扰群正常运行

**群管理破坏类：**

- 私自修改群昵称模仿管理员，误导他人
- 未经允许乱修改群公告、相册、文件等内容
- 管理员不得违规操作、恶意踢除成员；普通成员不得恶意举报他人

**群活动规范：**

- 发起群投票等活动需提前报备管理员
- 活动内容需合法合规、积极健康，无商业盈利目的
- 禁止利用群活动诈骗、拉人头等

## 违规处理说明

::: tip 处理原则

处罚以纠正与教育为先。现阶段服务器人力与氛围下，一般违规优先采取**警告、临时禁言或短期封禁（1-7 天）**，为玩家保留继续游戏的机会；**永久封禁仅用于多次违规或情节特别严重**的情形。

:::

1. 违规行为按情节轻重，采取 **警告 → 临时禁言 → 临时封禁（1-7 天，含封禁小号）→ 永久封禁**（游戏/群聊）等处理
2. 经济类违规（如多开小号刷取、转账）除封禁账号外，还将**回收违规所得**
3. 涉及多开小号的违规，首个处理动作是**封禁全部涉及小号**；主号视情节给予警告、临时封禁（1-7 天）或更重处理
4. 对处理结果有异议，可私聊服主申诉，管理员将在 2 个工作日内反馈
5. 管理员可根据运营需要补充/调整本守则，调整后将在服务器和群内公示

### 常见违规处理对照

| 违规类型 | 处理 |
| --- | --- |
| 使用外挂/透视/脚本等作弊 | 封禁相关小号 / 临时封禁 1-7 天；多次或情节严重转为永久封禁 |
| 盗取、破坏他人财产与建筑 | 临时封禁 1-7 天，视情节回收所得；多次或情节严重升级处理 |
| 多开小号绕过经济限制、刷钱转账 | 封禁全部涉及小号，回收违规所得；情节严重或多次连坐主号（1-7 天 → 永久） |
| 放置卡服机器、破坏服务器环境 | 警告 → 临时封禁 1-7 天 → 永久封禁 |
| 游戏/群内刷屏、引战、谣言、泄露隐私 | 警告 → 临时禁言 |
| 群内违规广告、拉人、仿冒管理员 | 警告 → 临时禁言 → 移出群聊 |
| 恶意举报、骚扰他人 | 警告 → 临时禁言/封禁 1-7 天 → 移出群聊/永久封禁 |

## 举报与申诉入口

- **游戏内举报**：私聊在线管理员，说明时间、地点与违规行为
- **群内举报**：私聊群主/管理员，提供截图与上下文
- **解封与申诉**：解封渠道已调整，**仅支持私聊服主申诉**（群内解封指令已停用）。请私聊服主 QQ：2011857087，发送游戏 ID 并说明解封/申诉理由，管理员将在 2 个工作日内反馈
