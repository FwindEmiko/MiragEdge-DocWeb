# 基岩版玩家指南

> 手机玩家的专属指南喵~

## 简介

基岩版通过 Geyser 实现与 Java 版互通，让手机/平板也能加入服务器。但因技术限制，部分功能无法完美兼容。

## 🚀 稳定性与性能

- **网络**：UDP 协议对网络要求高，手机网络丢包/断连属正常现象
- **粒子**：粒子效果优化差，粒子多时严重掉帧
- **地图**：大地图发包优化不足，易卡顿
- **反作弊**：基岩版玩家可能出现误判，已针对性放宽阈值

## 🎮 基础设置

- **副手切换**：发送表情按钮
- **UI档案**：经典（避免界面错位）
- **攻击**：不可连点（有攻击冷却）
- **皮肤**：更换后可能延迟显示，正常现象

## ✅ 已兼容功能

### 核心系统
- **铁砧/锻造台**：自定义界面
- **菜单系统**：基岩版专用表单界面
- **粒子过滤**：基岩版可单独开关粒子效果
- **耐久警告**：个性化设置中可切换
- **死亡返回**：基岩版专用死亡表单

### 自定义物品
- **物品图标与名称**：自定义材质正常显示
- **武器握持姿势**：剑、斧、弓等武器拿在手上正确显示
- **盔甲穿戴**：冠军/繁花/神圣/潜影四套盔甲及翅膀可穿戴显示
- **宝库钥匙**：三种钥匙（紫珀/镀金/羽翼）图标正确区分
- **特殊物品**：虚空之唤、星陨斩、龙刃等 132 件自定义物品全部可见

### 繁星末地（Stellarity）内容
- **自定义物品**：全部 132 个物品可在基岩版正常使用
- **武器系统**：29 把武器/工具握持姿势正确
- **盔甲系统**：4 套护甲 + 3 种翅膀可穿戴（纹理暂时使用默认铁甲外观）
- **食物/药剂**：可正常食用和使用
- **方块放置**：使用物品时可放置（显示为基座物品材质）

## ⚠️ 部分兼容

- **菜单GUI贴图**：需重写映射，工作量极大
- **物品模型**：Java/基岩模型体系差异大
- **背包自定义头颅**：需手动编写每个编码
- **盔甲自定义纹理**：自定义纹理显示为默认铁盔甲，可通过 Bedrock 纹理包修复
- **生物外观**：末影猫/末影鸡等变体生物显示为原版外观

## ❌ 无法兼容

### 通用限制
- **右键操作**：基岩版仅支持左键/长按
- **点击消息**：含交互提示的消息无法点击
- **附魔简介**：无法替换名称词条，显示可能错位

### 繁星末地（Stellarity）Boss 与方块
- **光之女皇模型**：使用 Java 版 Display Entity 构建，基岩版不可见（Boss 战斗正常进行，可受伤害、有掉落物）
- **潜影贝之王棒子/尖刺/射线**：同样使用 Display Entity，不可见
- **诅咒祭坛/神圣祭坛**：放置后不可见（功能正常，可交互）
- **末地土/末地草方块**：显示为基座物品材质

> 这些限制源自 Geyser 不支持 Java 版 Display Entity 系统，属于已知硬限制，等待 Geyser 后续更新。

> 建议：优先使用 Java 版体验更佳喵~
