# 基岩版玩家指南

> 手机玩家的专属指南喵~

## 简介

基岩版通过 Geyser 实现与 Java 版互通，让手机/平板也能加入服务器。但因技术限制，部分功能无法完美兼容。

## 稳定性与性能

- **网络**：UDP 协议对网络要求高，手机网络丢包/断连属正常现象
- **粒子**：粒子效果优化差，粒子多时严重掉帧
- **地图**：大地图发包优化不足，易卡顿
- **反作弊**：基岩版玩家可能出现误判，已针对性放宽阈值

## 基础设置

- **副手切换**：发送表情按钮
- **UI档案**：经典（避免界面错位）
- **攻击**：不可连点（有攻击冷却）
- **皮肤**：更换后可能延迟显示，正常现象

## 已兼容功能

### 核心系统
- **铁砧/锻造台**：自定义界面
- **菜单系统**：基岩版专用表单界面
- **粒子过滤**：基岩版可单独开关粒子效果

### 自定义物品（100+ 件）
- **普通武器/工具**：剑、斧、镐、锹、锄等全部正常显示自定义纹理
- **盔甲穿戴**：冠军/繁花/神圣/潜影四套盔甲可穿戴，显示自定义纹理
- **翅膀显示**：3 种翅膀（龙翼/女皇翼/幻翼）可穿戴
- **宝库钥匙**：三种钥匙（紫珀/镀金/羽翼）图标正确区分
- **特殊物品**：虚空之唤、星陨斩、龙刃等 100+ 件物品全部可见
- **史莱姆靴**：弹跳靴子正常穿戴，功能完整

### CraftEngine 农场作物
- 绯红香菇、诡异发光菇、黄瓜、番茄、茄子、辣椒、葡萄、玉米等 10 种作物
- 每个作物有 6 个生长阶段，基岩版可正常看到生长动画
- 温室玻璃、湿花盆、干花盆、稻草人等装饰方块正常显示

### 繁星末地（Stellarity）内容
- **自定义物品**：全部物品可在基岩版正常使用
- **武器系统**：29 把武器/工具握持姿势正确
- **盔甲系统**：4 套护甲 + 3 种翅膀可穿戴
- **食物/药剂**：可正常食用和使用
- **方块放置**：物品放置功能正常

### 下界（Incendium）内容
- **自定义武器**：炽焰手斧、血之匕首、凋零克星等 14 件武器有自定义纹理
- **物品功能**：符咒、余烬之羽、归途卷轴等物品正常使用

## 部分兼容

- **菜单 GUI 贴图**：需重写映射，工作量极大
- **物品模型**：Java/基岩模型体系差异大，部分物品显示为平面图标而非 3D 模型
- **背包自定义头颅**：需手动编写每个编码
- **盔甲自定义纹理**：部分盔甲显示为默认铁盔甲纹理
- **生物外观**：末影猫/末影鸡等变体生物显示为原版外观

## 无法兼容

### 硬限制：外观与功能不可兼得的物品

基岩版有 6 类物品的**行为动画硬编码在原版物品 ID 上**，无法同时拥有自定义外观和原版功能。如果给它们换上自定义纹理，就会出现以下问题：

| 物品 | 自定义纹理后的问题 |
|------|------------------|
| **弓**（虚空之唤、自然之怒、沙兰加、幽魂之怒） | 可以射箭但**没有拉弓动画**，手感奇怪 |
| **弩**（棱镜冲击、屠杀者、发条弩） | **完全无法射击** |
| **三叉戟**（沙暴三叉戟） | 可以投掷但**没有投掷动画** |
| **钓竿**（虚空钓者） | 可以抛竿但**手持角度歪斜** |
| **鞘翅/翅膀**（龙翼、女皇翼、幻翼） | **无法飞行** |
| **盾牌** | **无法格挡** |

**解决方案**：这些物品在基岩版使用**原版纹理**，功能正常但外观为默认样式。这是 Geyser 的已知硬限制，无法绕过。

### 繁星末地 Boss 与方块

- **光之女皇模型**：使用 Java 版 Display Entity 构建，基岩版不可见（Boss 战斗正常进行，可受伤害、有掉落物）
- **潜影贝之王棒子/尖刺/射线**：同样使用 Display Entity，不可见
- **诅咒祭坛/神圣祭坛**：放置后不可见（功能正常，可交互，可通过声音判断使用状态）
- **末地土/末地草方块**：显示为基座物品材质

### 通用限制

- **右键操作**：基岩版仅支持左键/长按
- **点击消息**：含交互提示的消息无法点击
- **附魔简介**：无法替换名称词条，显示可能错位
- **自定义生物模型**：Java 版的自定义生物模型（OptiFine CEM）在基岩版不可见

> 这些限制源自 Geyser 的桥接协议限制和基岩版客户端的硬编码行为，属于已知硬限制，等待 Geyser 后续更新。

> 建议：优先使用 Java 版体验更佳喵~
