# 账号绑定指南

首次进入服务器必须绑定 QQ 号，否则无法正常游玩。绑定后即可自由进出服务器，并使用群服互通功能。

<SmartImage src="/images/start/account/bind-flow.svg"
  alt="账号绑定三步流程图：进服拿 4 位验证码、回群发送「绑定 + 验证码」、绑定生效" caption="图 1：绑定三步——进服拿到 4 位验证码，回群发送「绑定 + 验证码」，绑定成功后即可自由进出" width="720" />

::: warning 隐私声明
服务器会收集你的 QQ 号、关联的游戏 ID 和连接 IP 属地。这些信息仅用于服务器功能。
为处理纠纷，服务器会记录聊天消息和部分游戏内操作；非必要不向第三方提供。
:::

## 绑定步骤

### 第一步：加入官方群

审核通过后，加入官方 QQ 交流群：

[点击加入交流群](https://qm.qq.com/cgi-bin/qm/qr?k=r_yUquo3bQwX3bL97RwG1aVj41WIEOI3&jump_from=webapi&authKey=A76pYGWh45XBe5V4kV5m3LWyR3XRpIl30FETYB0/scIEMeRGhIEDlQWmD5HVjSbj)

### 第二步：进入服务器触发绑定

1. 成功进入服务器，完成游戏登录账号注册。
2. 被踢出后，会弹出绑定提示框。
3. 记下提示框里的专属验证码（4 位数字）。

<SmartImage
  src="/images/web_image/msreg/tutorial/GameQQ.png"
  alt="服内绑定提示"
  caption="图 2：进服后被踢出时弹出的绑定提示框与验证码"
  maxWidth="400px"
/>

### 第三步：群内发送指令完成绑定

1. 回到官方 QQ 交流群。
2. 发送 `绑定 3528`，把 3528 替换成你的验证码。

<SmartImage
  src="/images/web_image/msreg/tutorial/QQLink.png"
  alt="交流群发送绑定验证码"
  caption="图 3：在交流群内发送绑定指令"
  maxWidth="400px"
/>

## 查询绑定

在官方 QQ 交流群内发送 `我的绑定`，查看当前 QQ 号绑定的全部游戏 ID。

## 解绑说明

单个 QQ 号最多绑定 3 个游戏 ID。需要绑定新账号时，先解绑旧的游戏 ID。

具体指令参考群内公示的「查、解绑指令示例」，或 @ 群机器人获取指引。
