# 新服速览

::: tip 新服已开放

本页汇总新服与旧服差异最大的改动，帮助老玩家快速适应、新玩家快速入手。详细玩法请从[开始游戏](/start/)或[生存玩法](/play/)进入。

:::

## 世界合并：一个世界承载全部玩法

新服最大的变化是**取消了独立的主城世界和资源世界**，所有玩法统一在「梦始之空」进行。旧服里"主城一个世界、挖矿一个世界、生存一个世界"的割裂感没有了，玩家、建筑和市场都在同一片大陆上。

世界的边界不是世界墙，而是**区域划分**。从出生点向外，按距离分成四类区域：

| 区域 | 距离 | 你能做什么 |
| --- | --- | --- |
| 主城区 | 0 - 400 格 | 公共活动中心，保护严格，不可随意破坏放置 |
| 缓冲保护区 | 400 - 1200 格 | 新玩家过渡区，累计在线超过 40 小时才可正常建造 |
| 常规生存区 | 1200 - 40万格 | 自由生存、建设、探索，适合长期安家 |
| 探索重置区 | 40万格以外 | 高风险探索区，地形与战利品会不定期重置刷新 |

::: warning 建家前先确认区域

在探索重置区建造或存放物品，可能随管理员安排的重置一起消失。重要建筑请放在**常规生存区**以内。可以用 `/hfcl zone` 随时确认自己所在的区域。

:::

## 定制内容：下界与末地的新世界

除了世界结构，新服还加入了大量定制化数据包玩法，探索体验与旧服完全不同：

- **下界大修**：全新的群系与结构，危险与宝藏并存的「烬域」等待探索
- **末地大修**：重制的「繁星」世界，新的地形、生物与终局挑战
- **新武器装备**：多套新武器与装备，配合锻造与附魔体系形成新的成长路线
- **结构 Boss**：大量新结构与 Boss 战，高回报伴随高风险

想详细了解，可以从[世界与结构](/play/adventure/worlds/)进入，或直接看[烬域](/play/adventure/worlds/incendium/biomes)和[繁星](/play/adventure/worlds/stellarity/biomes)。

## 主城共建：你的建筑就是新主城

新主城不是预先建好的，而是**由玩家共同建设**。开服后参与主城区域建设的玩家，会获得方块银行「块币」补贴，块币可用于方块银行兑换建材，形成"建设 → 获得块币 → 兑换建材 → 继续建设"的循环。

- 参与方式、补贴规则以游戏内提示和群公告为准
- 你的优秀建筑有机会成为新主城的永久地标
- 详细规则见[主城共建](/start/main-city)

## 老玩家需要重新适应的改动

| 改动 | 说明 |
| --- | --- |
| 随机传送 | 价格调整为 800 灵叶一次；新人有免费随机传送补贴 |
| 连锁采集 | 现在需要完成解锁条件才能使用 |
| 方块银行 | 货币更名为「块币」，需要解锁条件 |
| 随身背包 | 需要完成解锁条件 |
| 铁块电梯 | 需要完成解锁条件，且增加 1 秒冷却 |
| 免幻翼 | 新增功能：击杀 15 只幻翼后解锁，个人周围 48 格不再生成幻翼 |

::: tip 解锁条件以游戏内为准

解锁类功能的具体条件会在游戏内提示。老玩家也不会自动获得这些功能，需要按新规则重新解锁。

:::

## 新玩家快速上手

1. 完成[入服审核](https://miragedge.top/review)，获取群号和验证码
2. 加入官方 QQ 群，阅读群公告获取服务器地址
3. 阅读[新玩家须知](/start/welcome)，完成[账号绑定](/start/account)
4. 进入游戏后，先熟悉[基础系统](/play/systems/)（经济、领地）
5. 用[星辉锚点](/plugins/custom/miragedge-home)设置家园，方便随时回来

新手福利：新玩家有免费随机传送补贴，用来探索世界、寻找合适的安家地点。
