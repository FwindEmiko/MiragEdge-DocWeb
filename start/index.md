# 开始游戏

第一次来锐界幻境，按顺序完成下面四步即可。已经能正常进入服务器的玩家，可直接前往[生存玩法](/play/)。

## 第一次入服

1. [新服速览](/start/new-server)：了解新服与旧服的核心差异，快速上手。
2. [新玩家须知](/start/welcome)：确认入服前需要了解的内容。
3. [客户端安装](/start/install)：准备 Java 版所需的客户端环境。
4. [连接服务器](/start/join)：获取地址并完成第一次连接。
5. [账号绑定](/start/account)：完成账号关联，正常使用服务器服务。

## 社区与支持

需要交流、绑定账号、使用群服互通或排查异常时，从[社区与支持](/start/community/)进入。这里集中放置交流群、语音频道、机器人和常见问题，不再单独占用顶栏分区。

## Java 与基岩版

主要玩法在两个版本间保持一致。基岩版玩家请先阅读[基岩版兼容](/start/bedrock)，连接时以页面给出的地址和端口为准；遇到资源包、界面或操作差异，再查看[客户端扩展](/start/compatibility)。

## 遇到问题

先查[常见问题](/start/community/faq)。仍未解决时，前往[玩家交流群组](/start/community/groups)说明客户端版本、出现的问题和已尝试的步骤，方便更快定位。

## 长期游玩

准备和朋友长期定居时，可以阅读[玩家工会](/start/guild)；想建设自动化机器或确认技术特性边界时，查看[生电与特性](/start/redstone)。

## 内容边界

玩家页面只记录当前已经整理并核对的功能。尚未确认的玩法设计会留在[开发者文档](/developer/)或开发归档，不作为入服后的功能承诺。
