# 开始游戏

第一次来锐界幻境，按顺序完成下面四步即可。已经能正常进入服务器的玩家，可直接前往[生存玩法](/play/)。

## 第一次入服

<SmartImage src="/images/start/index/onboarding-four-steps.svg"
  alt="入服四步流程图：看新玩家须知、安装客户端、连接服务器、绑定账号" caption="图 1：入服四步——先看须知，再装客户端，然后连接服务器，最后绑定账号" width="720" />

1. [新玩家须知](/start/welcome)：确认入服前需要了解的内容。
2. [客户端安装](/start/install)：准备 Java 版所需的客户端环境。
3. [连接服务器](/start/join)：获取地址并完成第一次连接。
4. [账号绑定](/start/account)：完成账号关联，正常使用服务器服务。

## 社区与支持

需要交流、绑定账号、使用群服互通或排查异常时，从[社区与支持](/community/)进入。交流群、语音频道、机器人和常见问题都放在那里。

## Java 版与基岩版

主要玩法在两个版本间保持一致。基岩版玩家先阅读[基岩版兼容](/start/bedrock)；界面、操作或外观有差异时，再查看[客户端扩展](/start/compatibility)。

## 遇到问题

先查[常见问题](/community/faq)。仍未解决时，在[玩家交流群组](/community/groups)说明客户端版本、现象和已经尝试过的步骤。

## 长期游玩

准备和朋友长期定居时，阅读[玩家工会](/play/systems/guild)。想建设自动化机器、确认技术特性的边界时，查看[生电与特性](/play/systems/redstone)。
