# 皮肤更换

上传一张 PNG 皮肤文件，复制页面生成的指令，在游戏里执行就能换皮肤。

## 上传皮肤

1. 打开[皮肤上传页](https://skinsrestorer.net/upload)。
2. 拖入或点击上传 PNG 皮肤文件（仅限 PNG，最大 5 MB）。
3. 确认预览效果后，点击上传。
4. 页面生成一句形如 `/skin url https://...` 的指令。

## 游戏内更换

1. 复制上传后生成的指令。
2. 在游戏聊天框粘贴并发送。

```
/skin url https://textures.skinsrestorer.net/xxx
```

执行后皮肤立即生效，不需要重启游戏。

## 小贴士

- Java 版与基岩版都支持；基岩版更换后可能延迟几秒显示。
- 上传的皮肤会缓存，以后直接用 `/skin url` 再次应用。
- 执行 `/skin clear` 恢复默认皮肤。
