# 新玩家须知

锐界幻境是 Java 版与基岩版互通的 Minecraft 生存服务器。按下面的顺序完成审核、加群和绑定，就能进入服务器。

## 服务器概况

电脑玩家使用 Java 版，手机和平板玩家使用基岩版，所有人在同一个世界里游玩。

## 入服前阅读

1. [客户端安装](/start/install)：准备 Java 版或基岩版客户端。
2. [连接服务器](/start/join)：查看连接步骤和服务器地址。
3. [账号绑定](/start/account)：完成首次进入后的账号关联。
4. [玩家守则](/start/rules)：了解社区内的基本行为边界。

进入游戏后，再从[玩法指南](/play/)选择基础系统、冒险探索或田园生活。

## 填写审核试题

::: warning 审核说明
我们使用 AI（星玖）自动初审你提交的内容。发现异常时，请立即联系服主 QQ：2011857087。
:::

### 审核表入口

[锐界幻境新玩家审核表（点击跳转）](https://miragedge.top/review)

1. 打开审核表，按提示填写。
2. 提交前再次核对填写内容。
3. 审核通过后页面会显示群号和代码。
4. 在加群验证中填写代码。

- 预计完成时间：3 分钟。
- 自动审核未通过时，联系服主 QQ 复审。
