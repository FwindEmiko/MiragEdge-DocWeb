# 新玩家须知

锐界幻境是一个 Java 与基岩版互通的 Minecraft 生存服务器。入服前不需要读完所有玩法，但建议先完成基础连接和账号绑定，再按兴趣阅读玩法指南。

##  服务器概况

**锐界幻境**希望提供一个可以长期生活、探索和合作的生存世界。玩法较多，因此文档按玩家遇到问题的顺序拆分，而不是把所有系统堆在一页。

## 入服前阅读

- [客户端安装](/start/install)：准备 Java 或基岩版客户端。
- [连接服务器](/start/join)：查看连接步骤和服务器地址。
- [账号绑定](/start/account)：完成首次进入后的账号关联。
- [玩家守则](/start/rules)：了解社区内的基本行为边界。

进入游戏后，再从[玩法指南](/play/)选择基础系统、冒险探索或田园生活。
