# 入服指南

还不会安装客户端时，先看[客户端安装](/start/install)。

## 服务器地址

服务器地址是 `miragedge.top`。Java 版不需要填写端口，基岩版端口是 `19132`。

## 账号绑定

首次进入服务器需要绑定 QQ 号。不会绑定？查看[账号绑定](/start/account)。

## Java 版入服流程

### 准备工作

1. 安装启动器客户端。
2. 准备账户：正版用户直接登录，离线用户创建一个纯英文 ID 的离线账户。

::: danger 危险
游戏 ID 会影响服务器数据存储，改名会导致数据丢失。起名前先想好。
:::

### 连接服务器

1. 启动游戏，进入主界面。
2. 选择「多人游戏」→「添加服务器」。
3. 在地址栏输入 `miragedge.top`，端口留空。
4. 双击服务器列表中的条目，完成连接。
5. 提示需要加载服务器材质时，点击同意，否则影响正常游玩。

## 基岩版入服流程

### 准备工作

安装基岩版客户端，并成功注册或登录微软账户。

### 添加服务器

1. 进入游戏主界面，选择「服务器」。
2. 左侧列表滑动到底部，点击「添加服务器」。

<SmartImage src="/images/web_image/msreg/tutorial/BEGame.png" alt="添加服务器" caption="图 1：在服务器列表底部点击「添加服务器」" maxWidth="400px" />

3. 填写连接信息：
   - 服务器名称：我爱狐狸[自定义备注]
   - 地址：miragedge.top
   - 端口：19132

<SmartImage src="/images/BEJoin.png" alt="连接信息" caption="图 2：填入服务器名称、地址与端口 19132" maxWidth="400px" />

4. 保存后加入游戏。

连接遇到问题时，查看[基岩版兼容](/start/bedrock)，或在[玩家交流群组](/community/groups)内求助。
