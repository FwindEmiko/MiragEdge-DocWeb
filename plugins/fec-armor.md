# 🦸 巨像胸甲与灵影护腿

两款趣味盔甲，分别改变玩家体型与移动速度，适合探索、逃跑或整活。穿上胸甲变大变慢，穿上护腿变小变快。

## 获取方式

### 工作台合成

两款盔甲均通过**工作台**合成，非锻造台或附魔台。

#### 巨像胸甲

| 合成配方 | 材料说明 |
|:--------:|:--------:|
| 烈焰棒 重型矿镐 烈焰棒 | **烈焰棒** ×4 — 下界基础材料 |
| 烈焰棒 下界合金胸甲 烈焰棒 | **重型矿镐** ×1 — 烬域·废弃实验室 |
| 下界合金锭 死灵盾牌 下界合金锭 | **下界合金胸甲** ×1 — 原版 |
| | **死灵盾牌** ×1 — 烬域·圣所/禁忌城堡 |
| | **下界合金锭** ×2 — 原版 |

**材质**：下界合金甲（穿上显示下界合金护甲纹理）

**效果**：穿上后体型放大至 200%，移动速度降低 30%。

#### 灵影护腿

| 合成配方 | 材料说明 |
|:--------:|:--------:|
| 紫颂覆板 幻翼膜 紫颂覆板 | **紫颂覆板** ×2 — 繁星·诅咒祭坛合成 |
| 末影合金碎片 下界合金护腿 末影合金碎片 | **幻翼膜** ×1 — 原版幻翼掉落 |
| 末影珍珠 星辉尘 末影珍珠 | **末影合金碎片** ×2 — 繁星·末地城宝库 |
| | **下界合金护腿** ×1 — 原版 |
| | **末影珍珠** ×2 — 原版末影人掉落 |
| | **星辉尘** ×1 — 繁星·全境 |

**材质**：钻石护腿（穿上显示钻石护腿纹理）

**效果**：穿上后体型缩小至 50%，移动速度提升 40%。

## 设计思路

| 道具 | 主题维度 | 核心材料 | 设计理念 |
|:----|:--------|:--------|:---------|
| 巨像胸甲 | 烬域·下界 | 重型矿镐 + 死灵盾牌 | 沉重如山，巨像之力 |
| 灵影护腿 | 繁星·末地 | 紫颂覆板 + 末影合金碎片 + 星辉尘 | 轻如幻影，星光之速 |

两款盔甲各对应一个维度，鼓励玩家探索两边的内容。获取难度适中，属于趣味收集向装备，非战斗必需品。

## 注意事项

- 巨像胸甲穿在**胸甲**槽位，灵影护腿穿在**护腿**槽位
- 脱下后立即恢复体型和速度
- 效果可叠加：同时穿戴两件时，体型变化为 `2.0 × 0.5 = 1.0`（正常），但速度变化为 `-30% + 40% = +10%`
- 盔甲槽位限制意味着无法同时穿戴保护附魔的对应部位
