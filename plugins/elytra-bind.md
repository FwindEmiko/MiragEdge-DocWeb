# 契约之翼

契约之翼让每一件正式鞘翅都和主人同行。你可以从原版鞘翅一路升阶、随时调整路线，也不用担心它在日常操作中被误放或随手丢掉。

## 一人一翼

一名玩家同时只能拥有一件已经绑定的正式鞘翅。首次取得原版鞘翅时，契约会交给取得者；通过幻翼觉醒得到原版鞘翅时也是一样。

已有契约后，不能再拾取普通或高阶鞘翅，也不能拾取其他玩家已经绑定的鞘翅。只有**幻翼之翼**不受此限制：它是升级材料，不会绑定，可以重复拾取和保存，也不占用正式鞘翅名额。

如果状态显示异常，请联系管理员处理。解除契约属于管理员的兜底操作，普通玩家没有自行解除的入口。

## 从原版鞘翅一路升阶

正式鞘翅的阶位固定如下：

1. <McItem id="elytra" size="lg" /> **原版鞘翅**：从末地城开始你的飞行旅程。
2. **下界合金鞘翅**
3. **炼狱之翼**
4. <McItem name="龙翼" texture="/mc-textures/item/elytra/dragon-wings.png" size="lg" /> **龙翼**
5. <McItem name="光翼" texture="/mc-textures/item/elytra/light-wings.png" size="lg" /> **光翼**

每次只能换成严格更高的阶位；同级或更低的鞘翅不能作为升阶目标。更高阶鞘翅来自服务器的探索、首领或既有锻造内容；拿到合适的目标后，再通过下面的 Q 跃迁完成替换。

## 在地面上完成 Q 跃迁

Q 跃迁是高阶鞘翅进入你契约的唯一方式。操作前，请将自己的低阶、已绑定鞘翅拿在手上，并靠近地面上的更高阶鞘翅。

1. 走到目标 **3 格内**。
2. 动作栏会显示最近、且可以升阶的目标名称，并提示“按 Q 升级”。
3. 按下 Q 扔出后，手中的鞘翅会与地上的高阶鞘翅交换；新鞘翅直接回到背包。

附近有多件高阶鞘翅时，系统只会选择最近的一件。想换目标时，先走近你真正想要的那一件。

::: tip 契约会完整继承
跃迁后会保留契约、已有附魔和耐久损耗比例。例如原鞘翅已经损耗约 30%，升阶后的鞘翅也会保持约 30% 的损耗比例。
:::

背包没有空位时，先清出位置再试。目标超过 3 格、目标同级或更低，或手中不是自己的绑定鞘翅时，Q 都不会触发升级；绑定鞘翅在平时也不能直接 Q 丢弃。

## 用星辉解缚符调整路线

如果想从一条高阶路线换到另一条，先把当前高阶鞘翅还原为原版鞘翅，再选择新的高阶目标。制作星辉解缚符：

<CraftingTable
  shaped
  size="sm"
  :grid="[
    [{name:'末影合金碎片'}, {id:'dragon_breath'}, {name:'末影合金碎片'}],
    [{id:'phantom_membrane'}, {name:'幻翼之翼', texture:'/mc-textures/item/elytra/phantom-wings.png'}, {id:'phantom_membrane'}],
    [{id:'phantom_membrane'}, {id:'experience_bottle'}, {id:'phantom_membrane'}]
  ]"
  :result="{name:'星辉解缚符'}"
/>

然后在锻造台放入：

- 模板槽：星辉解缚符
- 装备槽：当前的高阶鞘翅
- 材料槽：末影合金碎片

结果是一件原版鞘翅。契约、已有附魔和耐久损耗比例会保留；高阶鞘翅原有的特殊外观或效果则回到原版鞘翅。幻翼之翼不走还原流程，想得到正式鞘翅请使用觉醒。

## 日常使用与保管

正常飞行、装备、附魔、铁砧修理、研磨、附魔台、工作台、锻造台，以及放在自己的背包、末影箱和已识别的随身背包中，都可以正常使用。

为防止鞘翅被转交、丢失或被公共系统吞掉，绑定鞘翅不能放入普通箱子、潜影盒、漏斗、熔炉、未知菜单、展示框、盔甲架和公共垃圾桶，也不能直接 Q 丢弃。

死亡时系统会保护并返还绑定鞘翅；极端情况下如果它落在死亡点，也只有契约主人可以拾取。若没有按预期返还，请及时联系管理员。

## 常见问题

### 为什么拾取不了鞘翅？

你已经拥有正式契约，或这件鞘翅属于其他玩家。幻翼之翼不受这项限制。

### 为什么 Q 没有升级？

确认手持的是自己的绑定鞘翅，目标在 3 格内且阶位更高；附近有多件目标时，靠近想选的那一件，让它成为最近目标。

### 为什么不能放进箱子或垃圾桶？

这是契约保护的一部分。请将鞘翅放在自己的背包、末影箱或可用的功能台中。

### 怎么更换升阶路线？

先制作星辉解缚符，将当前高阶鞘翅还原为原版鞘翅，再向新的更高阶鞘翅进行 Q 跃迁。

### 如何查询自己的契约？

使用 `/elytrabind`。
