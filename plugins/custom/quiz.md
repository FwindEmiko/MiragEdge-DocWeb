# 知识问答

## 聊天里出现问题时

服务器会不定期向全服发出问题。你可以在聊天中直接抢答，答对后获得经验、灵叶和其他当前配置的奖励。

它是一个不依赖装备的短时活动，适合在整理背包、等待队友或探索间隙参与。

## 抢答就像这样

1. 等待聊天栏出现新的问答消息。
2. 直接在聊天中发送答案，不需要额外命令。
3. 先答对的人获得答题奖励；同一题结束后等待下一题。

## 当前服务器规则

以下内容来自当前服务器配置索引（2026-07-26）：

- 当前启用周期提问，间隔约为 15 分钟。
- 在线人数少于 4 人时不会触发周期提问。
- 答案当前不区分大小写。
- 当前答题模式会持续到下一题出现；若服务器后续切换为限时模式，以题目提示为准。
- 答对的基础奖励包含经验、灵叶、星痕石和等级经验，具体数量可能随服务器活动调整。
- 题目覆盖 Minecraft 知识、常识、科学、历史、数学和趣味内容，不保证每题都来自游戏本身。

## 给每种游玩方式一点回报

问答把“知道一些东西”转成一种轻量的生存收益，让不擅长战斗或挖矿的玩家也能通过注意聊天、参与社区获得反馈。奖励不绑定单一职业，也不会改变主线玩法。

## 常见问题

### 我答对了但没有奖励？

确认自己发送的是完整答案，并留意是否已经有人先答对。奖励关闭、题目结束或服务器调整时，聊天提示会给出原因。

### 为什么没有题目？

当前在线人数不足、活动暂时关闭，或上一题刚结束都可能导致等待时间变长。

### 基岩版可以参加吗？

可以。答题通过聊天完成，基岩版不需要额外安装 Java 专用组件。
