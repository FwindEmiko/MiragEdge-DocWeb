# 死亡回程

在非 PVP 世界死亡后，系统会记录你最后一次死亡的位置。它帮你找回路线，但不会撤销这次死亡，也不会免除连续冒险带来的每日惩罚。

## 死亡后先确认记录

Java 版玩家会收到带坐标的死亡提示，可以直接点击其中的返回选项。也可以随时使用：

<CommandPanel title="返回死亡点">
  <CommandEntry command="/back" description="返回最近一次记录的死亡点" />
</CommandPanel>

死亡记录会保留所在的世界。即使你已经前往别的世界，仍可返回这一个最新记录点；下一次死亡发生后，记录才会更新为新的死亡位置。

## 返回时会发生什么

当前返回免费，不消耗灵叶。成功返回后会减少 2 点饥饿值，并短暂获得失明和强力缓慢；两次成功返回之间需要等待 5 秒。

返回不会删除记录。因此，冷却结束后仍可再次回到同一个最新死亡点。若你还没有死亡记录，或记录所在的世界已经不存在，则无法返回。

## 每日死亡惩罚

惩罚按当天的累计死亡次数计算，新的一天会从第一次重新开始。前 3 次死亡不会损失灵叶；从第 4 次开始，灵叶会在死亡时直接结算。

- 第 4-6 次：随机损失 100-250 灵叶。
- 第 7-10 次：随机损失 250-500 灵叶。
- 第 11-15 次：随机损失 500-800 灵叶。
- 第 16-20 次：随机损失 800-1200 灵叶。
- 第 21 次及以后：随机损失 1200-1500 灵叶。

这套阶梯主要针对连续死亡。偶发失误不会立刻触发灵叶损失，但当天反复冒险失败时，风险会逐步提高。

## 死亡点的发光金粒

进入惩罚档位的死亡点会出现一颗发光的“野生灵叶”金粒，作为这次损失的视觉标记。它不能被玩家、生物或漏斗拾取，也不会返还、转移或再次结算灵叶。

这颗金粒最多大约保留 6 分钟；即使它提前消失，也不会改变已经结算的灵叶损失。

## 不同客户端的体验

Java 版可以在死亡提示中直接点击返回。通过基岩版连接的玩家会在重生约 2 秒后看到“返回死亡点 / 取消”的确认界面；如果表单没有出现，仍可手动使用 `/back`。

## PVP 世界的例外

PVP 世界中的死亡不会生成新的死亡记录，也不计入每日死亡惩罚。若最近记录点位于 PVP 世界，也不能通过返回功能前往那里。

这不等于身处 PVP 世界时绝对不能使用返回：能否返回取决于你最近记录点所在的世界。

## 闪电苦力怕的意外掉落

如果你被**闪电苦力怕的爆炸**击杀，有 **30% 概率**会掉落自己的玩家头颅。它不是每次都会出现，遇到这种危险的战斗时记得先评估能否安全取回掉落物。

## 常见误解

### 灵叶能走回死亡点捡回来吗？

不能。进入惩罚档位后，灵叶已经在死亡时结算；发光金粒只是标记，不是可以领取的掉落物。

### 为什么不能返回？

先确认是否有最新死亡记录、记录所在世界是否仍存在，以及是否还在 5 秒冷却中。若记录点位于 PVP 世界，也不能返回。

### 返回需要付费吗？

当前不需要。返回免费，但会带来饥饿、失明和缓慢等短暂影响。
