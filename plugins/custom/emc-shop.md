# 等价交换商店

## 把多余材料换成下一步所需

你可以把暂时用不上的基础材料转成服务器认可的交换价值，再用这些价值兑换或购买已经开放的物品。

它适合处理“箱子里有很多材料，但暂时不知道拿来做什么”的情况，也让不同类型的生存玩家有一条互相转换资源的路线。

### 第一次使用

1. 先打开预览，确认目标物品是否已经解锁以及需要多少交换价值。
2. 再查看手中材料的价值，不要直接把仍有用途的材料全部转换。
3. 确认数量和结果后再执行转换或购买。

## 当前规则

以下内容来自当前服务器配置索引（2026-07-26）：

- 当前主要使用独立的 EMC 交换模式，界面中显示的货币名称为 **cc币**。
- 部分场景可以使用服务器的普通经济余额作为备用支付方式，是否可用由账号权限和界面提示决定。
- 物品价值不是按现实价格计算，而是服务器为生存资源设定的统一交换值。
- 重构购买存在 **3.8%** 的损耗；确认前请看界面最终到账数量。

## 它是资源周转，不是创造模式

生存服中不同玩家的资源来源不同：有人大量挖矿，有人建造或探索。等价交换提供的是“把多余资源变成下一步材料”的中间路线，而不是替代玩家交易和正常生产。

因此，价值表和可购买内容由服务器控制，不能把它理解成所有物品都能无限互换的创造模式菜单。

## 常见问题

### 转换后能反悔吗？

转换前先用预览和物品价值查询确认。已经确认的交易是否能撤回，以界面提供的操作为准，不要把转换当作临时仓库。

### 为什么看不到某个物品？

可能是物品尚未解锁、当前商店没有开放，或该物品不在当前价值表中。先查看商店页面和自己的解锁状态。

### Java 和基岩版操作一样吗？

功能目标相同，但菜单样式可能不同。基岩版的按钮布局和输入方式见[基岩版兼容说明](/start/bedrock)。
