## 10. 不产出星痕石的插件

以下插件经全量扫描确认不涉及星痕石产出，审查时无需检查。

| 插件 | 结论 |
| :--- | :--- |
| BountyHunter 赏金猎人 | 只发灵叶（Vault） |
| ajParkour 无尽跑酷 | 只发灵叶 |

| RTP 与传送类 | 无星痕石产出 |
