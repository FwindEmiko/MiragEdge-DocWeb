## 严重度分级

| 严重度 | 定义 | 处理时限 |
| :--- | :--- | :--- |
| 严重 | 会导致经济崩溃、套利或死循环 | 必须修复后才能上线 |
| 中等 | 长期可能导致失衡 | 修复后观察，或先上线再调整 |
| 优化 | 不影响平衡但有改进空间 | 可选优化 |
