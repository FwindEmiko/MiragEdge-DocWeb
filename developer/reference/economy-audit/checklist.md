# 经济审查检查清单

对每个被审查的数值逐项跑这 10 项检查，任何一项触发即标记为潜在问题，进入影响分析。

检查流程见 [经济审查工作流](/developer/reference/economy-audit/index)。

## ① 通胀源

该功能是否持续向系统注入货币而无对应回收？

检查方法：

- 该货币来源是否有对应的回收渠道？
- 如果是奖励，玩家付出了什么：时间、物品还是技能？
- 只是登录就给的，是否有每日上限？

触发条件：无上限加无回收 → 通胀风险。

## ② 回收缺口

货币回收渠道是否充足？

检查方法：

- 该货币是否有消费渠道：商店、消耗、手续费？
- 回收量是否不小于注入量的 60%？
- 回收渠道是否多样化，单一渠道容易被玩家回避。

触发条件：回收与注入之比小于 60% → 回收缺口。

## ③ 套利路径

玩家是否能低价买入、高价卖出获利？

检查方法：

- 从官方商店 A 买入，在官方商店 B 卖出，是否盈利？
- 从官方商店买入后交任务，奖励是否大于买入价？
- 玩家间市场价与官方收购价之间是否有套利空间？

检查模板：

```text
路径 1：商店买入 X → 商店卖出 X
  买入价: ___ 灵叶
  卖出价: ___ 灵叶
  差额: ___（应为负值才安全）

路径 2：商店买入 X → 交任务（要求上交 X）
  买入价: ___ 灵叶
  任务奖励: ___ 灵叶 + ___ 星痕石
  净额: ___（应不大于卖商店的价才安全）

路径 3：自己获取 X → 卖商店
  获取成本: 时间与肝度
  卖出价: ___ 灵叶
  结论: 合理（玩家用时间换钱）
```

触发条件：任一路径净额大于 0 → 套利风险。

## ④ 垄断与刷取

该资源是否能被个别人无限刷取？

检查方法：

- 该资源可再生吗：红石农场、刷怪塔、龙蛋循环？
- 如果可再生，是否有每日限量？
- 是否需要高门槛（技能、装备、权限）才能刷？
- 是否需要全服限量，防止一家独大？

触发条件：可再生加无限量 → 垄断风险。

## ⑤ 限量缺失

需要限量的地方是否有限量？

检查方法：

- 列出所有系统给钱的渠道：任务、签到、竞技场等。
- 每个渠道是否有每日或每周上限？
- 上限是否合理，既不低到无聊，也不高到膨胀。

触发条件：系统注入渠道无限量 → 严重。

## ⑥ 死循环

解锁条件是否依赖该解锁本身提供的能力？

检查方法：

1. 画出解锁路径：A → B → C。
2. 检查 B 的解锁条件是否包含 B 本身提供的能力。

典型反例：钓到传说鱼才能解锁传说鱼权限。玩家没有权限就钓不到，永远无法解锁。

触发条件：解锁链中出现循环依赖 → 严重。

## ⑦ 货币混用

一个商店或系统中是否混用多种货币，造成混乱？

检查方法：

- 该系统所有物品是否用统一货币？
- 如果混用，是否有充分理由，例如基础品用灵叶、精品用星痕石？
- 混用时玩家是否能直观理解换算关系？

触发条件：混用货币且无统一逻辑 → 待查。

## ⑧ 经验门槛

玩家是否有足够的经验等级来消费该功能？

检查方法：

- 该功能消耗多少经验等级？
- 玩家一天能获得多少经验：打怪约 1~3 级/小时，烧炼约 0.5~1 级/小时。
- 经验消耗是否在玩家一天能达到的范围内？

触发条件：消耗大于玩家两天收入的经验 → 待查。

## ⑨ 付费玩家平衡

月卡或付费玩家与免费玩家的货币差距是否过大？

检查方法：

- 月卡玩家日收入比免费玩家多多少？
- 差距是否大于 3 倍，3 倍以上会导致体验割裂。
- 付费产出是否影响星痕石这类稀缺货币的稀缺性？

当前基准（星痕石月卡）：

| 档位 | 日额外星痕石 | 占免费日收入比 |
| :--- | :--- | :--- |
| 新秀 | +28 | +28% |
| 精英 | +55 | +55% |
| 大师 | +110 | +110% |

大师月卡翻倍，需确认是否为设计意图。

触发条件：付费差距大于 3 倍 → 待查。

## ⑩ 交叉影响

该数值变动是否影响其他插件或系统？

检查方法：

1. 搜索所有引用该货币的插件配置。
2. 比对价格排序，变动后相对排序是否合理？
3. 检查任务奖励是否仍然有吸引力，不应被商店价格碾压。

触发条件：变动后相对排序不合理 → 待查。
