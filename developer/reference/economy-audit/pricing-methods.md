# 经济定价方法

不知道一个新物品该卖多少时，按本页的方法推导，不要凭感觉给数。

基准锚点数值见 [经济基准参考](/developer/reference/economy)。

## 定价区间表

### 灵叶

| 占日收入 | 对应灵叶 | 定性 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 1~5% | 220~1,100 | 廉价 | 消耗品、基础服务 |
| 5~15% | 1,100~3,300 | 合理 | 常用消耗品 |
| 15~30% | 3,300~6,600 | 中等 | 稀有材料 |
| 30~60% | 6,600~13,200 | 昂贵 | 高级消耗品 |
| 60~100% | 13,200~22,000 | 重度 | Boss 材料、顶级附魔 |
| 大于 100% | 大于 22,000 | 奢侈 | 收藏品、终极大件 |

### 星痕石

| 占日收入 | 对应星痕石 | 定性 | 适用场景 |
| :--- | :--- | :--- | :--- |
| 1~10% | 1~15 | 廉价 | 基础消耗 |
| 10~30% | 15~45 | 合理 | 中等消耗 |
| 30~60% | 45~90 | 中等 | 稀有材料 |
| 60~100% | 90~150 | 昂贵 | 高级附魔 |
| 大于 100% | 大于 150 | 奢侈 | 顶级收藏 |

## 方法一：定价五步法

```text
步骤 1：确定货币种类
    日常消耗 → 灵叶
    高级或稀缺 → 星痕石
    建筑材料 → 块币

步骤 2：确定肝度
    登录即得 → 1 级
    随手可做 → 2 级
    专门花时间 → 3 级
    高难度 → 4 级
    几乎不可重复 → 5 级

步骤 3：查定价区间表
    按肝度对应到日收入占比区间
    取区间中位值作为初始价格

步骤 4：防套利验证
    能否从其他渠道低价买入再卖？
    任务上交奖励是否低于卖商店？
    交叉检查所有相关价格链

步骤 5：限量评估
    资源可再生 → 需要限量
    资源不可再生 → 不需要限量，供应池自然调节
```

## 方法二：供应池模式

适用于稀有资源交易所这类玩家卖入进池、玩家买入出池的商店。

```text
卖价（玩家得） = 基准锚 × 肝度系数
买价（玩家付） = 卖价 × (1 + 差价率)
差价 = 买价 - 卖价  → 这部分被系统回收
```

| 参数 | 取值 | 说明 |
| :--- | :--- | :--- |
| 基准锚 | 1,200 灵叶/钻石 | 全服最硬锚点 |
| 肝度系数 | 0.3~1.0 | 3~5 级对应 |
| 差价率 | 25~33% | 官方回收率 |

实例：远古残骸定价

```text
肝度: 4 级（下界挖矿，需要钻石镐）
基准锚: 1,200（钻石卖价）
远古残骸与钻石的稀有度比: 2.5 倍
卖价 = 1,200 × 2.5 = 3,000
买价 = 3,000 × 1.33 = 4,000
差价 = 1,000，回收率 33%
```

## 方法三：任务委托定价

适用于上交物品换奖励的任务，本质是变相回收。

```text
灵叶奖励 ≤ 卖商店价格（防止套利）
星痕石奖励 = 额外吸引力，补偿灵叶低于卖价的损失
总价值 ≈ 卖商店价 × 0.6~0.8
```

实例：每日宝石商会任务

```text
上交: 8 颗钻石
卖商店可得: 8 × 1,200 = 9,600 灵叶
任务奖励: 3,000 灵叶 + 15 星痕石 + 15min 飞行
灵叶占比: 3,000 / 9,600 = 31%，远低于卖价，防套利
星痕石价值: 15 × 45 = 675 灵叶等价
飞行价值: 15min ≈ 500 灵叶
总价值: 3,000 + 675 + 500 = 4,175，约为卖价的 43%
结论: 玩家缺星痕石才交任务，缺灵叶则卖商店
```

## 方法四：珍材商店定价

适用于用星痕石购买的特殊物品商店。

```text
价格（星痕石） = 肝度系数 × 目标占比 × 星痕石日收入
星痕石日收入取 100~150
```

| 肝度 | 系数 | 目标占日收入 |
| :--- | :--- | :--- |
| 2 级 | 0.3 | 10~20% |
| 3 级 | 0.5 | 20~40% |
| 4 级 | 1.0 | 40~80% |
| 5 级 | 1.5~2.5 | 80~200% |

实例：经验修补附魔书

```text
肝度: 4 级（稀有附魔，需大量钓鱼与交易）
系数: 1.0
目标占比: 200%，即 2 天收入
价格 = 1.0 × 200% × 150 = 300 星痕石
```

## 方法五：龙蛋委托定价

龙蛋可循环获取，每条龙掉一颗，能打龙的玩家可能垄断。

设计要点：

1. 不走官方商店买卖，无限可再生品无法定价。
2. 走任务委托加全服限量。
3. 奖励锚定打龙一次的时间成本，约 1 天收入。

```text
龙蛋委托: 20,000 灵叶 + 50 星痕石
灵叶: 20,000 约为 1 天收入（打龙约需半天到 1 天）
星痕石: 50 约为半天收入
全服日限: 2 颗，防垄断
结论: 不会无限印钞，也不鼓励垄断
```

## 方法六：死循环预防

设计任何阶梯或条件解锁机制前，必须检查解锁链。

```text
1. 列出所有解锁条件: A 需要 X, X 需要 Y, Y 需要 Z
2. 反向追溯: Z 的获取是否依赖 A？
3. 如果是 → 死循环
4. 解决方案: 在链条中插入一个不依赖该系统的入口
```

通用安全模式：

```text
入口: 不需要任何权限的基础活动（钓鱼、挖矿、杀怪）
  → 积累基础货币
  → 购买或解锁第一级权限
  → 该权限提供新的获取渠道
  → 积累更多货币
  → 解锁下一级
```

关键原则：链条的入口必须是人人可做的基础活动，不能依赖任何上级解锁。
