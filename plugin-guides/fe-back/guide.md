# 01 — 玩家指南

## 死亡后会发生什么

每次死亡（非排除世界）系统都会：

1. 记录死亡点（默认最新一次覆盖旧的）
2. 今日累计死亡次数 +1（每日零点重置）
3. 当累计次数进入惩罚档位时：从你账户扣除对应灵叶，并在死亡点掉落一颗发光金粒「遗失的灵叶 ×N」
4. Java 版玩家收到一条可点击的死亡提示（含坐标与「立即返回」）

死亡次数在前 30 次（默认 `tier-0`）时几乎不惩罚；档位越高掉得越多。

> 通过 `/febsuicide` 造成的死亡**不计入**当日死亡次数、不扣费、不掉金粒，但死亡点仍会记录。

## 返回死亡点：/back

```
/back
```

别名：`/feback`、`/backpack`。传送回最近一次记录的死亡点。

### 费用

按 `return-cost` 配置（默认）：

| 今日死亡次数 | 返回费用 |
|:---:|:---:|
| ≤ 30 次 | 免费 |
| 31 次起 | 按阶梯 100 ~ 190 灵叶（越死越贵，141 次以上封顶 190） |

拥有 `feback.free` 权限的玩家永远免费。余额不足无法传送。

### 返回后的副作用

- 饥饿值 **-2**
- 失明约 3 秒
- 缓慢约 3.6 秒（强度 8）
- 抗性提升约 3.6 秒（强度 4，防返回后被围殴）

### 冷却

两次返回之间需间隔 **5 秒**（`cooldown-seconds`）。冷却在开始扣费前记录：扣费失败或传送失败同样会消耗冷却（传送失败会**退款**）。

### 跨世界

默认允许跨世界返回。若服主开启 `require-permission-for-cross-world`，则跨世界需要 `feback.bypass.world` 权限。

### 无法返回的情况

- 死亡点所在世界在排除列表中
- 记录的世界已不存在（被删除）
- 没有死亡记录

## 灵叶金粒的拾取规则

死亡掉落的金粒**不会进背包**，拾取时由系统直接结算货币：

| 拾取者 | 结果 |
|--------|------|
| 走回死亡点的**本人** | 全额返还灵叶到你的账户，金粒消失 |
| **其他玩家** | 灵叶入账给拾取者；是否通知你由服主配置（`notify-on-pickup-others`） |
| 本人使用 `/back` 返回后再拾取 | 被拦截（ActionBar 提示），金粒保留，仍可被他人拾取 |
| 生物 / 漏斗 | 无法拾取（原版层禁止 + 事件层兜底） |

这个设计的目的是防止「传送回去直接捡钱」的套利：想要回灵叶，就得自己走过去。

### 金粒存在时间

金粒掉落 25 tick 后才可触发拾取；默认 **6 分钟**（`lifespan-seconds: 360`）后由插件清理消失。超时没人捡，损失就坐实了。

### 为什么死亡后没看到金粒？

- 还在免罚档位（默认 1~30 次掉落 0~10，随机到 0 就不生成）
- 余额不足以全额支付惩罚：会扣到保留额度（默认 400 灵叶）为止，且**不生成金粒**
- 服务器未启用经济（Vault / PlayerPoints 未挂载）

## 基岩版玩家

通过 Geyser / Floodgate 连接的基岩版玩家：

- 死亡重生约 **2 秒**后自动弹出「返回死亡点 / 取消」表单
- 表单 **30 秒**无操作自动关闭
- 表单没弹出时可直接输入 `/back`
- 不想要表单可用 `/febtoggle` 永久关闭（写入数据库，跨重启保留）

## 常见问题

### /back 要钱吗？

默认：当日死亡 ≤ 30 次免费，之后按阶梯收费；`feback.free` 玩家永久免费。服务器可关闭收费（`return-cost.enabled: false`）。

### 为什么 /back 后捡不起自己的金粒？

因为使用 `/back` 返回会被视为套利，系统标记本次死亡的金粒为「本人不可拾取」；走回死亡点才能拾回。

### 金粒会被别人捡走吗？

会。他人拾取后灵叶进入对方账户，你的损失已经结算且不会退还。

### 为什么提示余额不足？

返程扣费来自 Vault（灵叶）或 PlayerPoints（星痕石），余额不足时无法传送；也可能是服务器没有挂载对应经济插件。
