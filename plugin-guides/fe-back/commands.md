# 02 — 命令参考

全部命令支持 Tab 补全。管理类子命令对「控制台」的支持情况见各节说明。

## /back — 返回死亡点

| 项目 | 内容 |
|------|------|
| 别名 | `/feback`、`/backpack` |
| 权限 | `feback.use`（默认所有人） |
| 用途 | 传送到最近一次记录的死亡点 |

行为细节：

- 无参数，仅玩家可用（控制台使用会提示无权限）
- 默认 5 秒冷却（`cooldown-seconds`；`feback.bypass.cooldown` 可跳过）
- 按今日死亡次数解析费用（`return-cost`）；`feback.free` 玩家免费
- 成功后扣除饥饿值并施加失明/缓慢/抗性，同时把死亡点附近 6 格内「本次死亡」的金粒标记为本人不可拾取（防套利）
- 传送失败自动退款；但冷却仍已消耗

## /feb — 管理命令

| 项目 | 内容 |
|------|------|
| 别名 | `/febbackadmin` |
| 权限 | `feback.admin`（默认 OP） |
| 用途 | 重载 / 状态 / 清理 / 设置死亡点 / 查看阶梯 |
| 无参数 | 输出用法帮助 |

| 子命令 | 用法 | 说明 |
|--------|------|------|
| `reload` | `/feb reload` | 重读 config.yml / messages.yml，重连外部 hook（Vault / PlayerPoints / Floodgate / ProtocolLib）并重启定时任务，无需重启服务器 |
| `status` | `/feb status [玩家]` | 查看死亡记录：世界、坐标、死亡时间、今日累计死亡、当前惩罚阶梯；不带玩家查自己；支持离线玩家 |
| `clear` | `/feb clear <玩家>` | 清除指定玩家的死亡记录（可离线） |
| `setpoint` | `/feb setpoint <玩家>` | 把指定玩家的死亡点设置为**执行者当前位置**；仅玩家可用（控制台无法设置坐标） |
| `tiers` | `/feb tiers` | 列出当前所有惩罚阶梯（阶梯号、掉落区间、次数区间） |

## /febsuicide — 自杀（不计入每日死亡）

| 项目 | 内容 |
|------|------|
| 别名 | `/fbsuicide` |
| 权限 | `feback.suicide`（默认玩家**无**权限；控制台默认拥有所有权限） |
| 用途 | 自杀，或（控制台 / 其他插件）指定玩家自杀 |

- `/febsuicide` — 自己自杀（仅玩家）
- `/febsuicide <玩家>` — 指定玩家自杀（控制台必须带参数）

规则：

- 本次死亡**不计入**当日死亡次数、不扣费、不掉金粒
- 死亡点**仍然记录**，玩家之后可 `/back` 返回
- 创造 / 旁观模式玩家无法自杀；已死亡（未重生）玩家不会重复触发
- 被强制自杀的玩家会收到一条通知

## /febtoggle — 基岩版返回表单开关

| 项目 | 内容 |
|------|------|
| 别名 | `/backtoggle` |
| 权限 | `feback.toggle`（默认所有人） |
| 用途 | 切换自己死亡后是否自动弹出返回表单（基岩版专用） |

开关状态写入数据库（`fe_player_prefs`），跨重启保留。
