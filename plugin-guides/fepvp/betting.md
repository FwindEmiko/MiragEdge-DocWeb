# 押注局（Bet Duel）

押注局是 FE_PVP 单挑（1v1）专属的可选玩法：建房时选择免费局或押注局，双方押相同金额，**胜者通吃押金池**。

> 团队竞技 / 饥饿游戏暂不开放押注；押注局仅限单挑。

## 玩法规则

### 模式与货币

| 项目 | 取值 | 说明 |
|------|------|------|
| 免费局 | FREE | 无金钱往来，与普通单挑完全一致 |
| 押注局 | BET | 双方对押，输家给钱 |
| 灵叶 | Vault | 推荐主货币 |
| 星痕石 | PlayerPoints | 可选副货币 |

### 资金流向（单方押金 X）

| 局终结果 | 玩家1 | 玩家2 | 说明 |
|----------|-------|-------|------|
| 玩家1 胜 | **+2X** | -X | 赢家拿回自己的 X + 对方的 X |
| 玩家2 胜 | -X | **+2X** | 同上，镜像 |
| 平局（超时/同归） | +X | +X | 全额退还 |
| 开局前取消（退出/解散/强停） | +X | +X | 未开赛，无输赢 |
| 开局后退出/掉线（弃权） | -X（充公） | +X | 弃权方押金扣除，未弃权方退回 |
| 服务器崩溃，比赛未完成 | +X | +X | 重启后自动退押（可配置） |

### 资金托管（Escrow）

为什么赛前锁定，而不是赛后输家转账？

- **防弃权赖账**：赛前双方押金已进托管池，弃权=判负且押金被扣，无需追讨
- **防负余额**：余额不足根本无法开赛
- **防崩溃丢账**：托管记录落库，重启可恢复（`bet_sessions` 表）

## 玩家操作

### 创建押注局

1. 大厅 → **⚔ 单挑** → 房间列表 → **创建押注房间**
2. 在押注创建界面选择模式（免费/押注）、货币（灵叶/星痕石）、金额档位
3. 也可以自定义金额直接建房：

```
/fepvp bet 2000     # 以 2000 灵叶创建押注房（跳过 GUI）
/fepvp bet          # 打开押注创建 GUI
```

### 加入押注局

点击押注房条目 → 二次确认界面（房主/对手、地图、装备、押金、胜者获得、你的余额）→ 确认加入。

> 加入时先做余额预检；开局锁定前还会再校验一次（双保险）。

### 等待与锁定

- 等待界面中央显示**押金池**（如 2,000 灵叶）
- 满员/房主开赛后，双方押金自动锁定托管，ActionBar/BossBar 提示"押金已托管"
- 开局前退出不扣款

### 结算

| 结果 | 金额反馈 |
|------|----------|
| 胜 | +2X（押金池） |
| 负 | -X（已转给对手） |
| 平 | +X（押金退还） |
| 对方弃权 | 退回你的押金 X（对方押金充公） |
| 自己弃权 | -X（押金被扣除） |

> 结算瞬间玩家离线也能到账（Vault/PlayerPoints 支持离线发放）。
> 押注局默认仍计入 ELO / 战绩，但**不发放**每日低保奖励（防"押金+低保"双收，可配置）。

## 管理员操作

```
/fepvp admin bet stats               # 今日押注流水统计（笔数/押金总额/胜利/弃权/净变动）
/fepvp admin bet pending             # 查看未结算（锁定）的押注会话
/fepvp admin bet refund <玩家> <金额> # 人工退款（异常处理兜底）
```

需要权限 `fepvp.bet.admin`（默认 OP）。

## 配置

```yaml
bet:
  enabled: true                # 总开关（经济插件未装时自动禁用）
  currency: vault              # vault(灵叶) | playerpoints(星痕石)
  min-stake: 500               # 单方押金下限
  max-stake: 100000            # 单方押金上限
  default-stakes: [500, 1000, 2000, 5000, 10000, 20000]  # 预设档位
  allow-custom-amount: true    # 允许 /fepvp bet <金额>
  apply-daily-rewards: false   # 押注局是否仍发每日低保
  count-elo: true              # 押注局是否计入 ELO/战绩
  forfeit-on-quit: true        # 开局后退出=弃权判负（默认 true）
  refund-on-cancel: true       # 开局前取消/强停=退押
  cooldown-seconds: 0          # 个人押注冷却（防刷钱，0=关闭）
  crash-refund: true           # 崩溃未完成局自动退押（false=转人工）
```

## 风控机制

1. 三处余额校验（创建/加入/锁定），锁定失败自动解散不扣款
2. 结算幂等（内存集合 + DB status 双保险），杜绝重复发钱
3. 押注局默认不发每日低保，防双收；`cooldown-seconds` 防脚本连刷
4. `min/max` 限额防洗钱/通胀
5. 全程 DB 留痕（`bet_sessions` + `bet_records`），管理员可对账
6. 崩溃恢复默认自动退押（宁退不错）

## 权限

| 节点 | 默认 | 说明 |
|------|------|------|
| `fepvp.bet` | `true` | 可创建/加入押注局 |
| `fepvp.bet.create` | `true` | 可创建押注房 |
| `fepvp.bet.custom` | `true` | 可用 `/fepvp bet <金额>` 自定义押金 |
| `fepvp.bet.admin` | `op` | `admin bet` 管理命令 |
