# 04 — 玩家指南

## 大厅

进入服务器后，使用 ```/fepvp``` 打开主大厅 GUI：

```
┌────────────────────────────────────────────┐
│  ⚔ 锐界竞技场                               │
├────────────────────────────────────────────┤
│  [⚔ 单挑]  [🥣 饥饿游戏]  [👥 团队竞技]     │
│  [🎲 快速匹配]  [🏆 排行榜] [📊 我的数据]    │
│  [🎒 装备库]  [👁 观战]                     │
├────────────────────────────────────────────┤
│  在线 N 人 / 比赛中 N 场                     │
└────────────────────────────────────────────┘
```

- **⚔ 单挑**：进入单挑房间列表（支持免费 / 押注两种模式）
- **🥣 饥饿游戏**：进入 FFA 求生房间列表
- **👥 团队竞技**：进入团队房间列表（2v2/3v3/4v4）
- **🎲 快速匹配**：一键自动创建随机地图单挑房间
- **🏆 排行榜** / **📊 我的数据** / **🎒 装备库** / **👁 观战**：查询与浏览

## 单挑（1v1）

### 方式一：房间列表

1. 在大厅点击 **⚔ 单挑** → 打开单挑房间列表
2. 点击已有房间加入，或点击 **创建房间** 自建
3. 创建房间流程：选竞技场 → 选装备 → 房间创建成功
4. 房间满员（2人）后自动开赛，或房主点击 **开始比赛**（```/fepvp room start```）手动开赛

### 方式二：快速匹配

1. 在大厅点击 **🎲 快速匹配**
2. 自动创建一个随机竞技场的单挑房间
3. 等待其他玩家加入

## 团队竞技（2v2/3v3/4v4）

1. 在大厅点击 **👥 团队竞技** → 打开团队房间列表
2. 点击已有房间加入，或点击 **创建房间** 自建
3. 创建房间流程：选竞技场 → 选装备 → 房间创建成功
4. 进入队伍选择界面：
   - 点击红队或蓝队加入（也可用 ```/fepvp team join red/blue```）
   - 实时显示双方人数和成员
5. 房主点击 **⚔ 开始比赛**（双方各至少 1 人）
6. 或等房间满员后自动开赛

### 团队模式

| 模式 | 说明 |
|------|------|
| **淘汰制** | 队员全部阵亡即淘汰，默认模式 |
| **击杀数制** | 死亡后 5 秒复活（保留装备 + 短暂无敌），先达到目标击杀数的队伍获胜 |

模式由管理员在创建竞技场时设置，使用 ```/fepvp arena setmode```。

## 饥饿游戏（单人求生）

1. 在大厅点击 **🥣 饥饿游戏** → 打开 FFA 房间列表
2. 选择一张 FFA 类型的地图，**跳过装备选择**直接建房
3. 开局前自动**扫描场地补给箱并把物品均匀分散**（每局随机位置）
4. 死亡自动转观战，**活到最后 1 人获胜**
5. 赛后场地与补给箱内容自动复原

- 至少需要 `hunger-games.min-players`（默认 3）名玩家才能开局
- 玩家初始清空背包（可配置保留自带装备）
- 超时按击杀数判定，无击杀则平局

详见[饥饿游戏模式](./hunger-games)。

## 押注决斗

押注局是单挑专属玩法：建房时选择免费局或押注局，双方押相同金额，**胜者通吃押金池**。

1. 在大厅点击 **⚔ 单挑** → 房间列表 → **创建押注房间**（或在选图前用 ```/fepvp bet <金额>``` 自定义金额）
2. 在押注创建界面选择货币（灵叶 / 星痕石）、金额档位
3. 加入押注房需先确认余额与规则
4. 开赛时双方押金**自动锁定托管**；胜者 +2 倍押金，平局退押，弃权方押金被扣除

- 押注局默认仍计入 ELO / 战绩（可配置关闭）
- 押注局默认**不发放**每日低保奖励（防双收）
- 具体资金规则与配置见[押注局](./betting)

## 比赛流程

```
选装备（5秒）→ 倒计时（12秒）→ 战斗 → 结算（5秒）→ 传送回大厅
```

- 倒计时期间玩家被冻结（无法移动/攻击）
- 战斗中是否允许破坏/放置方块由**竞技场创建时选择**（不破坏默认禁止）
- 比赛结束自动分批复原方块、归还背包
- 一方死亡或超时（默认 800 秒）即比赛结束
- 死亡后自动变为旁观者（淘汰制）或 5 秒后复活（击杀数制）

## 背包保护

- 比赛前自动备份背包（精确到 NBT 级别）
- 比赛结束自动归还原物品
- 断线重连后自动检测并恢复背包（崩溃恢复）
- 击杀数制复活时：自带装备保留，装备组合重新发放

## 方块复原

管理员开启 ```protection.auto-restore``` 后，被允许破坏/放置的场地会在赛后自动复原：

- 方块原始状态（含箱子/告示牌等 tile 数据）被记录并节流写盘
- 比赛结束按 tick 分批复原，不卡服
- 服务端崩溃重启时自动扫描残留文件补恢复
- 恢复完成自动清理场地内掉落物/箭矢/经验球

## 排行榜与数据

在大厅点击 **🏆 排行榜**，或执行：

```
/fepvp stats          # 查看自己
/fepvp stats 玩家名   # 查看他人（需 fepvp.stats.others）
```

排行榜显示：

```
═══════════ 段位排行榜 (1/3) ═══════════
🥇 #1 PlayerA  ELO: 2100 | 胜: 80 | 传奇
🥈 #2 PlayerB  ELO: 1950 | 胜: 65 | 宗师
🥉 #3 PlayerC  ELO: 1800 | 胜: 50 | 大师
→ #7 You       ELO: 1500 | 胜: 30 ← 你
════════════════════════════════════════
```

## 观战

大厅点击 **👁 观战**，或执行：

```
/fepvp spectate <竞技场名>
```

- 以旁观者模式传送至观战点
- 再次执行 ```/fepvp spectate``` 退出观战（或 ```/fepvp leave```）
- 管理员可通过 ```game.allow-spectators / max-spectators``` 控制观战

## 离开房间 / 退出比赛

```
/fepvp room leave     # 离开当前房间
/fepvp leave          # 离开当前比赛 / 退出观战
```

- 离开房间：房主离开则自动转移给下一位玩家
- 房间所有人离开后自动解散
- 比赛中退出视为投降（对手获胜）；押注局中退出视为弃权
